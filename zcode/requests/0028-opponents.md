## 任务

产出 `docs/analysis/对手轨迹.md`：

1. **全队轨迹表**：从 `/api/leaderboard` 与 `intel/raw/leaderboard_*.json` 历史快照里，提取每支队伍的所有 attempt（时刻 + 成绩），按队伍分组，算「最好成绩 / 提交次数 / 首次提交时间 / 最后提交时间 / 最好成绩出现时刻 / 相邻最好成绩的改进幅度」。
2. **重点分析前 3 名**（我不想写实验报告、Catnet、大肥鱼）：
   - 他们的改进节奏（每次降多少）
   - 提交时间分布（是否集中在某个时段 → 是否利用安静窗口）

4. **威胁评估**：按他们的改进速度，11/16 前可能到多少？我们必须在什么时间点前超过多少？
5. **一句话结论**。
