## §1 香农信道容量与 BDP 管道认证下界（可证明的部分）

1. **香农层（唯一无条件认证）**：评测瓶颈是确定性比特管道 C=100 Mbps；任何策略的净荷 goodput ≤ C。
   T ≥ D/C = 5040 Mbit / 100 Mbps = **50.4s**（份额 s=1、零损、零背景的幻想极限）。
   Shannon 定理在此的角色：底层物理信道必须具备 ≥100 Mbps 的信道容量管道才存在（平台已固定）；
   对我方而言容量上限即管道速率本身，背景流是「干扰用户」而非「噪声」——其挤压量 s_bg 是排队/博弈
   结果量，物理只认证 s_own ≤ 1，不认证任何 s_own 的下界可被绕过。

2. **BDP 管道与慢启动爬坡**：BDP = C·RTT = 875 KB = 729.2 pkt。
   窗口从 IW 爬到 BDP 需 log2(729/IW)·RTT：IW=10 → 433ms，IW=32 → 316ms。
   最小 bin（10MB）满足 10MB = 11.4×BDP ≫ 爬坡期传输量 → 爬坡被 L_i/C 完全吸收（爬坡期发送量
   受 cwnd 限制小于管道速率，但 L_i/C > 爬坡时间，管道充满后仍按 L_i/C 下界走）。

3. **逐段认证下界**：T_i ≥ L_i/C + τ_1w（末字节单向传播 35ms；官方口径剔除任务间隙，0088）。

## §5 判决（分层认证链）

**结论**：

1. 香农/BDP 映射认证的是 **50.4–50.8s**，不是 105.592s——「105.592s 绝对不可超越」作为物理定理
   **不成立**（同一构造法在 n=405 已给出 94.0s）。
2. 105.592/106.597 的正确身份：**n 依赖的跨构型极值复合量**（AGENTS.md 禁止的 min-of-N 红利口径），
   只能作诊断书挡，不能作提交目标或承诺。
3. 单构型可达性：六段极值来自六个参数区（剪刀差机理）+ 六段 ±1% 邻域联合概率 3.3e-14 + 405 场实测 0 命中，
   单场穿 105.592 的可达性物理条件在现役参数空间内**不成立**。
4. 真正的不变量（可写进答辩的物理条件）：逐段管道下界 Σ(L_i/C+35ms)=50.61s、份额机制 s_own∈(0,1)
   由背景需求（平台固定 ≈C）与我方节奏共同决定、以及官方「重复取平均」口径下的均值语义（0097）。
