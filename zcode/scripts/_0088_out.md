## A4 理论界（socket/内核层，每 bin 边界）

| 开销项 | 冷连接假设 | 持续连接假设 | 是否进入官方计时 | 依据 |
|---|---|---|---|---|
| QUIC 握手（Initial+Handshake） | 1 RTT = 70 ms | 0（复用）/ 0-RTT ≈ 0 | **是**（含在 per-bin 内） | RFC 9002；RTT=70ms 官方拓扑 |
| TLS/证书验证 | 并行于握手窗内 | 0 | 是（同上） | 已含 1 RTT 口径 |
| 请求-响应首字节（服务端 pacer 重配后首包） | ≤1 RTT | ≤1 RTT | 是 | 官方：配置写入不计入，但生效后首包计入 |
| 连接关闭（QUIC CONNECTION_CLOSE drain） | 1 RTT | 1 RTT | **否**（末字节后） | 计时止于最后数据字节 |
| TCP TIME_WAIT | 不适用 | 不适用 | 否 | QUIC/UDP 无 TIME_WAIT；连接 ID 状态由空闲超时管理（≈30s 量级，不阻塞新连接） |
| 内核 socket buffer 回收（skb free） | O(µs) | O(µs) | 否（与下一连接并行） | 批量释放，不占关键路径 |
| 端口/四元组复用冲突 | 0（QUIC CID 机制） | 0 | 否 | 无 TCP 四元组耗尽问题 |

**每 bin 残余上界：**

- 冷连接假设：握手 70ms + 首字节 ≤70ms → **≤ 140 ms/bin**（保守双计）；现实单 RTT 内完成握手+请求 → **70 ms/bin**
- 持续连接假设：仅 1.bin 冷启动 70ms，其余 ≈ 0 → **全程 ≤ 70 ms**
- 全程合计（冷连接 6 bin）：≤ 420 ms（保守）/ 70 ms（现实）；相对官方锚点 133.086s 占比 **≤ 0.32%**
- 相对官方单发噪声 σ_d≈7.0s（0084）：残余 ≤ σ_d 的 6% —— **在官方分辨率下不可辨识**
