# 0257 输出：MTU 分片临界点与浅缓冲性能边界（纯本地计算）

## A. 分片计数临界点表

convention A（0249 已裁决）：1200B = IP 满包，载荷 1180B；每片净载荷 = MTU-20，
分片数 k = ceil(1180/(MTU-20))，线材字节膨胀 = 1200 + 20*(k-1)（每片重加 IP 头）。

| MTU (B) | k 分片数 | 线材总量 (B) | 判定 |
|---|---|---|---|
| 9000 | 1 | 1200 | k=1 无分片 |
| 1500 | 1 | 1200 | k=1 无分片 |
| 1228 | 1 | 1200 | k=1 无分片 |
| 1200 | 1 | 1200 | k=1 无分片 |
| 1199 | 2 | 1220 | 分片 x2 |
| 1000 | 2 | 1220 | 分片 x2 |
| 900 | 2 | 1220 | 分片 x2 |
| 610 | 2 | 1220 | 分片 x2 |
| 420 | 3 | 1240 | 分片 x3 |
| 315 | 4 | 1260 | 分片 x4 |
| 576 | 3 | 1240 | 分片 x3 |

- **临界点（convention A）：MTU* = 1200 B**——MTU>=1200 恰好单片；1199 即 2 片。
- convention B 敏感性（1200B=QUIC 净荷，IP/UDP 在外，0249 已否决但留档）：线材 1228B，MTU* = 1228 B。
- Ethernet 1500 在双口径下均为 k=1：**结论对口径不敏感**。

## B. 脉冲链精确解（B=40 浅队列，节奏保持 leak 40/4ms 的每 100µs 一报文）

分片发生在服务端 egress 分片点（拓扑固定，仅理论审计）；每报文在队列中变为 k 片批量。
服务率按片均字节取指数近似（异构服务需 phase-type，此处为中性近似，已声明）。

| k | 场景 | 片均服务 (µs) | ρ | E[overflow]/tick | 丢包占比 (片) | 报文级丢失率 |
|---|---|---|---|---|---|---|
| 1 | MTU>=1200 无分片（现状） | 96.0 | 0.960 | 0.0016 | 0.157% | 0.157% |
| 2 | MTU 900（1200B→900+340 两片） | 48.8 | 0.976 | 0.0083 | 0.413% | 0.649% |
| 3 | MTU 420（1200B→420+420+400 三片） | 33.1 | 0.992 | 0.0276 | 0.920% | 1.850% |

**锚点检验**：k=1 丢包占比 = 0.157%，0085 已发布值 0.157%（同构 D/M/1/40 脉冲链）。
M/M/1/40 Poisson 到达上界 0.962%（0085 §三）> 确定性节奏值 —— 方向一致。

## E. 浅缓冲槽位经济学与 1200B 安全边界

- 队列以「包槽」计量（B=40）：分片后同字节量占用更多槽——
  - k=1：字节容量 40 x 1200 = 48000 B
  - k=2（MTU 900）：片均 610 B → 40 x 610 = 24400 B（**字节容量 -49.2%**）
  - k=3（MTU 420）：片均 ~413 B → 40 x 413 = 16533 B（-65.6%）
- 突发容忍度按字节近似减半/三分一：浅缓冲区对分片的惩罚是双重的（批量 b=k 跳变 + 字节容量收缩）。

| 口径 | 临界 MTU* | Ethernet 1500 余量 | 判定 |
|---|---|---|---|
| A: 1200B=IP 满包（0249 裁决） | 1200 B | 300 B = 25.0% | k=1 安全 |
| B: 1200B=QUIC 净荷（敏感性） | 1228 B | 272 B = 22.1% | k=1 安全 |
| L1 成帧计费（+38B/帧, 0249） | 1238 B | 262 B = 21.2% | k=1 安全 |

- QUIC 标准行为（RFC 9000 §14.1）：端点禁止依赖 IP 分片，最小数据报 1200B；MTU<1200 时 DPLPMTUD
  收缩或握手失败（显式故障，非静默丢包）——分片放大律是「天真 UDP 栈」假想支路。
- 巨型帧 MTU 9000：对本链路无收益（我方报文恒 1200B，k 本来就是 1），且 9000B 串行化 720µs
  的队头阻塞会恶化浅缓冲下我方 paced 报文的排队时延——巨型帧在共享 100Mbps 汇聚上是纯风险。
- MTU 不是提交杠杆（pacer.txt 无 MTU 参数）：本审计为防御性确认 + 答辩弹药。

## F. 结论

1. **分片丢包临界点：MTU* = 1200B**（convention A，0249 裁决口径）；convention B 敏感性 1228B；
   平台 Ethernet 1500 下 k=1 恒成立，余量 25.0%（L1 计费口径 21.2%）。
2. 一旦 MTU<1200，浅缓冲惩罚双重：批量跳变 b=k（精确脉冲链：报文级丢失率 k=1 0.157% → k=2 0.649%
   [x4.13，独立片假设下界仅 x2.00——队列相邻相关性再翻倍] → k=3 1.850% [x11.8]）+ 字节容量 -49.2%（k=2）。
   独立片下界律 1-(1-p)^k 在 0085 梯子上的读数：4.513%→8.82%（k=2）；36.342%→59.48%（tb 倾泻，k=2）。
3. **1200B 安全边界量化完成：全部口径下 MTU>=1200 ⟹ k=1 ⟹ 零分片开销**；
   1200B 恰好是 QUIC 协议最小数据报与 Ethernet 1500 之间的最宽安全带内点。
4. 锚点：k=1 脉冲链复现 0085 的 0.157%，MC 独立验证偏差见 C 表。
