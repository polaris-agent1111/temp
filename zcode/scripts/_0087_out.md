## T1 解耦定理验证：cwnd 轨迹由丢包流唯一决定，与发射调度无关

- growth=reno: 批量调度 vs 平滑调度 cwnd 轨迹 max|Δ| = 0.0e+00 → 逐点相同 ✓
- growth=cubic: 批量调度 vs 平滑调度 cwnd 轨迹 max|Δ| = 0.0e+00 → 逐点相同 ✓

定理陈述：cwnd 状态机的输入是（丢包, ACK）事件流；pacing 模式仅决定发射时刻表，
不进入状态更新方程。模式切换对 cwnd 的**全部**影响都必须经由丢包流介导；
而 0085 已证平滑发射的丢包流严格更稀（批量 1/40/60 → 尾损 0.157%/4.51%/36.3%），
故切换到平滑模式对 cwnd 是**单向利好**（更少减半事件），不存在降速重置通道。

## H1 每 bin 新连接假设下的模式无关基线

- 5.bin (10416.7 pkt/s): BDP=729 pkts，IW=10 → 7 轮倍增 ≈ 0.49s（无损慢启动），爬坡字节缺口 ≈ 4.60 MB ≈ 0.37s 折算——**这是所有 bin 共享的基线，与边界前模式无关**
- 6.bin (10000 pkt/s): BDP=700 pkts，IW=10 → 7 轮倍增 ≈ 0.49s（无损慢启动），爬坡字节缺口 ≈ 4.36 MB ≈ 0.35s 折算——**这是所有 bin 共享的基线，与边界前模式无关**

推论：若每 bin 新建连接，模式切换的微分代价恒等于 0（两种假设下边界前后连接状态
完全同分布）；若连接持续，T1+T2+B2 给出代价 ≤ 0.35s（Reno 书挡）/ ≈10ms（CUBIC/BBR 族）。
两种假设下，「切换限速模式需要降速重置 cwnd」均不成立。
