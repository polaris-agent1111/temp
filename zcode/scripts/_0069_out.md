## D. 解析验证

1. **BtlBw 最大滤波收敛**：冷启动 log2(729/32)≈4.5 轮=0.32s 到达 BDP；钳位 R 下样本上界 = min(R, (1-rho_t)*mu)，10 轮（~0.7s）窗口过期后旧峰值失效。
2. **泵幅恒等式**：独占链路且 BtlBw 锁 C 时泵相超额 = 0.25*mu*RTT = 182 包 > Q_lim=100 -> 必然自致尾丢；模块钳位后泵速率 = min(1.25*BtlBw, R)，超额重写为 (min(1.25*BtlBw,R) - 可用排水)*RTT。
3. **泵相安全带**：不钳位且 BtlBw=mu 时安全条件 1.25*mu - mu ≤ (Q_lim-q_bg)/RTT => Q_lim ≥ 182 包（不满足，BBRv1 在浅缓冲独占链路必然泵丢）；钳位 R ≤ mu 时泵被钳，风险退化为持续超额 R-share。
4. **RTprop 偏置定理**：仅当队列 10s 窗口不排空才偏置（偏置=q_min/mu）；此时 ProbeRTT 每 10s 强制 cwnd<=4 约 200ms，窗口期吞吐代价 2.0%；队列间歇排空时 min 滤波被续签、ProbeRTT 不触发（C1/C2 对照）。
5. **G 量化偏差**：BtlBw 上偏因子 T/(T-G) = 1.061（+6.1%）；RTprop 为 min 滤波，对量化噪声不敏感。
6. **fidelity 声明**：轮级流体模型（非逐包）；FIFO 尾丢按到达比例分摊；PTO/ACK 细节由 0070 承担；背景为三态近似（10% 空闲 / 65% 小流 30-55% / 25% 大流 55-95%）；样本语义为 delivered/RTT（真实 BBR 用 send-phase 区间，本模型在稳态等价、DRAIN 相有半轮偏差）。
