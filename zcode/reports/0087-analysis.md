# 0087 报告：精确控速与令牌桶混部边界处 TCP/QUIC 拥塞窗口平稳过渡证明

- 完成时间：2026-11-07 07:1x
- 执行者：zcode
- 结论：「4.bin→5.bin 切换限速模式需要降速重置 cwnd」不成立。T1 解耦定理（cwnd 只由丢包/ACK 流驱动，pacing 模式是调度层参数，构造性验证轨迹逐点相同）+ T2 单调性定理（cap 变化无 cwnd 通道）+ 缺口核算（唯一非零缺口 99.2 pkts，代价 ≤0.47s Reno 书挡 / ≤10ms CUBIC/BBR 族）+ 数据干净对照（KS p=0.345 不可区分）四线一致判定边界平稳。

## 具体动作

1. 核算两种 champion 架构的边界速率阶梯：Shot2 全 leak 冠军 4→5、5→6 边界 Δr=0（天然连续）；tb4+precise2(g1200) 4→5 为 +15.7% 上调（缺口 99.2 pkts=119KB），5→6 为 −4% 下调（cwnd 携带 ≥ BDP6 → 缺口恒 0）。
2. T1 构造性验证：同一 400 轮丢包序列下，批量调度与平滑调度驱动同一 cwnd 机器（reno/cubic），轨迹 max|Δ|=0；模式切换的影响只能经由丢包流介导，且 0085 已证平滑丢包流严格更稀 → 单向利好。
3. T2 数值验证 r(cap)=min(cap, cwnd/RTT) 单调性：速率受限区单调阶梯、cwnd 受限区 cap 变化零事件；cap 下调不触发任何 cwnd 事件。
4. B2 爬升代价三族上界：SS 延续 4.8ms / CUBIC 7.3ms / Reno 线性书挡 0.472s（字节代价 5.90MB），均低于官方单发噪声 σ_d≈7.0s（0084）两个数量级。
5. B3 瞬态：切换瞬间最坏 40 pkts 在途按 10416.7 pkt/s 排空 3.84ms ≪ RTT 70ms，无丢包尖峰、无减半事件，队列波形档位跃迁（0085：尾损 4.51%→0.157%）。
6. D1 数据检验（runs/results.jsonl 391 条 valid）：恒等式 Σdownloads==total 精确成立（偏差 0.000000s，移交 0088 作口径基础）；干净对照（固定 mode5=precise，precise→precise n=13 vs tb→precise n=63）KS p=0.345 不可区分；总体分层表显式标注混杂（bin5 自身模式差异）警示。
7. H1 并集结论：每 bin 新连接假设下模式切换微分代价恒 ≡0（慢启动基线 0.37s 模式无关，移交 0088）；持续连接假设下 ≤0.47s。两种假设下命题均被否定。
