# 0242 报告：官方评分历史波动与周末评测负载周期性自相关 ACF 分析

- 完成时间：2026-11-07 17:00
- 执行者：zcode
- 结论：**考核目标「周末 r1 < 0.25」在点估计上成立（r1 = −0.1845，真实数据 n=5），但 95% 带 ±0.877 不能排除 r1 ≥ 0.25，不得宣称统计显著；全序列 r1=+0.478 不显著——官方相邻出分接近不相关，自适应不应依赖出分动量；出分延迟呈深夜低负载窗口机制性下移（8–23 min）而非周期波动。**

## 具体动作

1. 装载真实数据（全部只读）：`runs/official_results.jsonl`（11/05–11/06 共 10 条官方出分）+ `runs/sequential_adaptive_log.jsonl` 中 11/07 真实夜跑 5 发（取最后一次 `dry_run=false` init 之后事件，且 `raw.submitted_at` 与 `submissions.jsonl` ±120s 交叉验证通过——rehearsal 的 mock 118.0 系列全部剔除）。
2. 编写并执行 `zcode/scripts/acf0242_official_score_acf.py`（纯本地 numpy，有偏 ACF 估计 + 白噪声 Bartlett 95% 带 + 按日去均值稳健性对照 + 出分延迟删失分析）。
3. 关键输出：
   - 周末（11/07 周六，n=5）出分序列 r1 = **−0.1845**（r2 = +0.1049），点估计 < 0.25 ✓；CI [−1.061, +0.692] 包含 0.25 → 统计上不可确立。
   - 全序列（n=15）r1 = +0.4775（不显著，|r1| < ±0.506）；按日去均值后 +0.3720（仍不显著）——正 r1 来自周四前两发 245s 未调参档的档位漂移，非系统波动。
   - 出分延迟：11/05 下午上界 9.5–109.4 min；11/06 凌晨右删失 >45.7 min；11/07 凌晨轮询上界 8.2–23.1 min（自身 r1=−0.68，不显著）。深夜窗口最短，但 3 天样本无法区分「时段效应」与「负载效应」。
   - 周期性：数据仅 3 天×每日 5 发，谱/周期估计在本样本下无意义，未做（硬边界声明）。
