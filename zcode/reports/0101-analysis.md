# 0101 报告：5 发真机出分 vs 离线理论仿真结果的残差正态性检验与 Q-Q 图生成

- 完成时间：2026-11-07 09:05 (Asia/Shanghai)
- 执行者：zcode
- 结论：三层预测模型（本地测试床均值 / 流体包络 / 预注册目标）的残差在 5% 水平下均不能拒绝正态性（Shapiro-Wilk p=0.75~0.86，Q-Q r≥0.957），但 n=4~5 的功效模拟显示对中等偏离的检出率仅 6%~9%——结论边界是「未发现反常证据」而非「证实正态」；官方复测预测区间应按 t 分布/自助法加厚（单发 95% 区间约 ±29s）。
