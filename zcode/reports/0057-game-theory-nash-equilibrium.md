- 执行者：zcode
- 结论：**96M 的正确理论地位 = 外生巨流下的「阈值贴靠最优响应」$x^*=C-h$（实测 $h\approx4\%C$ → 12.0 MB/s = 96 Mbps），且是 Pareto 前沿上我方目标最优点**；但经典对称 Nash 框架给出的是比例公平点（≈C/2），**不支持**「96M 为 Nash 均衡」——任务命题在经典框架内不成立、在含丢失惩罚的最优响应框架内成立，两个推导都完整给出、按适用性如实分列（不编造公式凑结论）。结构性事实：背景字节平均速率 λE[S]=12.5MB/s=C 满线速 → 速率切分博弈不可行，我方 37–48Mbps 来自 ACK 时钟填隙（η≈0.44 实测常数），真正决策维度是「pacing 贴多近触发巨流瞬间队列溢出」。6 项实测交叉验证全部方向一致（含今夜 Shot 2 贴阈值=纪录、Shot 3/4/5 的 98M/100M 越阈值=140–155s）。

## 具体动作

1. **效用函数显式化**：按任务定义 $U_1=\log g(x_1)-\beta D_q$，$g=\eta x_1$（η 实测定标）；时延/丢失项用巨流期队列动力学 + drop-tail 40 包缓冲 + QUIC 乘性退避结构化。
2. **经典 Nash 求解**（任务要求形式）：M/M/1 型 $D_q=1/(C-x_1-x_2)$ + 对称对数效用 → $\beta x_i=(C-x_1-x_2)^2$ → 对称解 $x^*=(C-y^*)/2<C/2$（比例公平），明确否定「96M 为经典 Nash」。
3. **正确模型推导**：丢失率线性化 $\ell(x)\propto(x-(C-h))^+$，$T=V/(\eta x(1-\ell))$ → 一阶条件给出 $x^*=C-h$（阈值内侧贴靠）；三段结构性论证（低于阈值被支配/超阈值被强支配/Pareto 前沿刻画）；h 的实测定标（96M↔100M 本地悬崖 + 官方今夜三发越阈受罚）与缓冲时标一致性核算（0.77s 吸收余度 ≈ 11×RTT）。
4. **交叉验证表**：6 项观测（本地 96/100M 悬崖、Shot 2/3/4/5 官方分、η 常数性）vs 模型预测全一致。
5. **可证伪条件**：97–99M 对照、94–95M 对照、leak 42/42（标称超 C）判别发——三项都可由后续额度低成本裁决。
