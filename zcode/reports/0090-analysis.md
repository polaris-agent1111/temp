# 0090 报告：多变量高斯过程对未探索参数网格耗时的贝叶斯优化置信上界评估

- 完成时间：2026-11-07 07:25
- 执行者：zcode
- 结论：家族控制后的 GPR 显示 6.bin precise 速率 p6 ∈ 90~96.5M 的响应面统计平坦（μ≈68.9~71.2s，σ≈2.0~6.2s），LOO 技巧分为负（GP 7.90s vs 常数基线 7.26s）——90~95M 未探索网格是「信息真空」；LCB₂ 对 90M 的偏好（56.55）纯系方差寻求，EI 最大点 90M 的 P(≤现役组均值)=49.7%（掷硬币）。90~95M 不构成比现役 96M 更优的投放优先级；若仍要封闭网格，首投 90M 且本地 n≥3。

## 具体动作
- 数据提取（runs/results.jsonl 只读）：valid 且非 load-* 的 hybrid/champ 族，家族控制（tb4 同构 + g=1000µs），得 p6 ∈ {95,96,97,98} 共 14 个样本；确认 90~94M 无任何样本（真·未探索）。
- **标注勘误**：tag `pXXM-pYYM` 第一个 token 是 5.bin 速率、第二个才是 6.bin（如 `p92M-p96M` = 5.bin@92M + 6.bin@96M）。STATUS「92M 单场 119.268s」的 58.03s 应记在 p6=96M 名下。本审计主数据集已按此重列。
- GPR 计算（zcode/scripts/gpr0090_ucb_grid.py，seed=42）：SE 与 Matérn-5/2 双核（NLL 多起点 L-BFGS）、LOO 交叉验证、LCB(κ=1,2)/EI 采集函数、20 万次蒙特卡洛后验、σ_n 假设敏感性（实证 6.6s vs 「悬崖情景」2.0s）。
- 关键数字：拟合 ℓ=30（上界）、σ_f=30（上界）、σ_n=7.60 → 等价常数+白噪声；重复点组内 sd=6.64s（参数效应与窗口噪声同量级）；ANOVA（95/96/97/98M 四组）p=0.144；Welch（96 vs 98M）p=0.252；「悬崖情景」（σ_n=2）NLL 恶化 +43、LOO-RMSE 翻倍 → 被数据否决。
- 诚实性检查：STATUS「96M 帕累托最优/4% 排空余量律」存在 min-of-N 偏差（96M min 簇 vs 95/97M n=1 比较）；建议降格为「无差异证据下的现役默认值」。物理解释：p6 90~100M 远高于 6.bin 有效瓶颈 ≈44.1 Mbps，是惰性维度；96M 相对 100M 的真实优势是不触发 0085 突发尾部丢包惩罚。
