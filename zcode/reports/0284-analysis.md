- 完成时间：2026-11-07 20:29
- 执行者：zcode
- 结论：**目标声明的 ≥96% 重合度未获支持**——预登记非循环校准下，Crown Fusion
  [41,41,40,37,36,36] 与 PMP 离散极值轨线 [36]×6 的阶段时间加权重合度 = **89.94%**
  （< 96%），且该值在 270 个校准点 + 3 组模型变体下完全不变。后期退避相位
  （阶段 4–6）与 BCB coast/back-off 弧 100% 吻合；前期饱和相位（阶段 1–3）不吻合，
  因为本地实测吞吐平台在 24–41 pkt/4ms 区间平坦，饱和不产生 PMP 所需的开关函数变号。
  如实签发否定结果，未硬凑门限。

## 具体动作

1. 预登记判定标准（±1 pkt/4ms 容差、阶段时间加权、非循环校准、校准盒鲁棒性）。
2. 从非 crown 数据校准流体模型：官方常数（630 MB 文件表、100 Mbps 瓶颈，
   `docs/extracted/六载穿柜.md`）+ leakc-24/27/36 均匀家族实测平台吞吐
   44.9±1.7 Mbps（n=21，valid、去 load-*）+ δ 模型速率组 + 0085 Kolmogorov 债务律。
3. 连续时间 PMP 推导（H = 1 + ψ(u−μ_p)/S_max，σ = ψ/S_max → Bang/Coast/Bang 结构
   及其存在条件）；离散执行器下用后向 DP（D 网格 0.005，硬约束 D≤1）求极值轨线。
4. 270 点校准盒扫描 + 3 组变体（δ 宽松读法、CC 钳制域 μ_p=18、模型有效性对照）。
5. 交叉验证：模型排序与实测方向一致（均匀 < crown）；crown 债务峰值 ≤1 于
   266/270 点成立（可行但非极值）。
