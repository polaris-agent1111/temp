# 0086 报告：极端高压重尾背景流下长连接吞吐衰减鲁棒性压力测试与最恶劣工况下确界

- 完成时间：2026-11-07 07:02
- 执行者：zcode
- 结论：最恶劣工况（全程线速饱和 + 30MB 巨流开局）下，开环平滑 pacer 架构的耗时确界为 5.bin ≤ 27.6s（模型地板）/ 33.2s（官方 Shot2 实测锚点）、6.bin ≤ 55.2s / 64.1s；单次 30MB 巨流对开环 pacer 的边际代价 < 1s；唯一点性风险（loss-based CC 在永久饱和下饥饿，Tier-0 上界 4,667s/9,333s）已被五发官方实测（124.4–155.2s）排除。

## 具体动作

1. 复核官方背景流长 11 节点 CDF 三项解析量（E[S]=1,711,250B、P(S≥10MB)=3.00%/条、P(S≥28MB)=0.300%/条），全部与 `monte-carlo-collision-simulation.md` 口径一致；计算 5/6.bin 窗口巨流命中概率（6.bin 实测份额窗 P(≥1 条≥28MB)=73.8%，E[最大流]=28.51MB）。
2. 建立逐 RTT（Δ=70ms）流体闭环仿真器：我方 pacer g=9000 pkt/s（leak36，Shot2 冠军口径）+ 三族 CC 风味（reno / cubic / bbr 开环）+ 四层背景情景（ρ∈{0.25,0.5,0.75,1.0} 定态网格、30MB 巨流响应式压顶、30MB 非响应火龙压顶、永久饱和巨流链），NSEED=4000、seed=42 确定性可复现。
3. 修复两处模型缺陷后复跑（过程有调试轨迹 `_debug0086.py`）：(a) CA 丢包误重入慢启动 → 改为 SS 丢包减半并永久退出；(b) 逐 RTT 布尔丢包把份额极小的溢出误判必丢 → 改泊松稀释事件概率。
4. 推导并数值互证开环份额闭式解 r_own(ρ)=μg/(g+ρμ)：grid0.50 bbr 仿真 40.4s == 闭式 40.4s；grid1.00/saturate bbr 27.6s/55.2s == 解析 Tier-1 地板 27.6s/55.2s（逐位一致）。
5. 产出三明治确界（详见 `docs/analysis/0086-theory-audit.md` §六）：满速下界 12.8/25.6s → 开环份额地板 27.6/55.2s → 实测锚点 33.2/64.1s → 工程包络 ≈40/71s（+σ_d≈7.0s，0084 口径）→ 病理上界 4,667/9,333s（被实测排除）。总时间最恶劣包络 124.2s（与 Shot2 官方 124.3683s 自洽）。

## 未完成/风险

- 官方客户端 CC 族不可知（也不应探测）：饥饿类结论按族条件化陈述，现实相关性由五发实测间接排除（若为 loss-based，任一 ρ≈1 窗口会推出数百秒的 6.bin，与 124–155s 实测矛盾）。
