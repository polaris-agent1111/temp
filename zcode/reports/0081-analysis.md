# 0081 报告：令牌桶补充周期与操作系统 250Hz/1000Hz 时钟中断相位同步机理

- 完成时间：2026-11-07 05:36
- 执行者：zcode
- 结论：**4000µs 是 250Hz（J=4ms）与 1000Hz（J=1ms）两时钟网格的公共整数倍 → 共振免检点**：粗定时器自重装 MC 验证周期锁死（mean=4000.0µs、std<0.2µs、零量化/零漂移），双网格因子均 100%；hrtimer 路径折损 = δ̄/(T+δ̄) 封顶 20%（T=4000 → 80%，独立复现 0068 的 77–87% 与 0076 的 76.8% 锚）。反例：T=1000µs@250Hz 被 ceil 拖到 4000µs（因子 25%）——「亚 G 间隔铁律」获得闭式机理链（0013 现象 → 0076 别名 → 0081 闭式）。相位锁定把背景碰撞从随机抽奖变成确定性窗口重叠：运行点碰撞概率上界 44.0%，满需求 93–104%。

## 具体动作

1. 建立粗定时器 ceil 语义模型：实际周期 = ceil(T/J)×J，零损失点集 = J 整数倍；4000µs ∈ 两点集交集 → 对 HZ 不可知性免疫（共振点）。
2. 编写并运行 `zcode/scripts/clk0081_refill_phase.py`（seed=42）：量化因子表（12 档 T × 2 HZ）、相位锁定 MC（T=4000 双网格 LOCKED；非整数倍 T 确定性降速 std<0.2µs）、hrtimer 迟滞 MC（1000/2000/4000/8000µs → 50/66.6/80/88.9%）、全 HZ 鲁棒性表（HZ∈{100,250,300,500,1000}，仅 HZ=100 跌破 41 Mbps 份额）、相位碰撞 MC（占空比=碰撞概率上界）。
3. 全 HZ 表：HZ∈{250,500,1000} 下 T=4000 因子 100%、r=36 最低 86.4 Mbps 仍 > 41 份额 2.1×；HZ=300 因子 60% 仍保份额；与 0013 G=4000 反推自洽。
4. 与前置审计闭环：0068/0076 的折损锚获得闭式解释 δ̄/(T+δ̄)；0080 占空比表与本报告碰撞表同构互证；r=38/36 双保险确认（修复占空比 + 迟滞档保有 1.8× 份额余量）。
