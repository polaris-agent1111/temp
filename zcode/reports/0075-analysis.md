# 0075 报告：5.bin 与 6.bin 长稳态传输下排空余量梯度的 Pareto 效率边界

- 完成时间：2026-11-07 04:42
- 执行者：zcode
- 结论：2%~10% 排空余量的 Pareto 膝点在 **m≈4%（R=96 Mbps）**，正是冠军 6.bin 设置。风险臂（有限缓冲 M/D/1 精确解）：P(自排队溢出) 从 90M 的 6.7e-5 单调升至 98M 的 1.1e-2（ρ_q≥0.98 为自拥塞区，m=0 在随机化抽象下发散）；时延臂：94M 以下每 −2 Mbps 多付 0.87–0.89 s 线速时间而风险已平坦。**96M 是 X/Y 双臂唯一同时平坦的平台点**（±1 Mbps ΔX≤0.41 s）。实测 6 组分速率族全部统计不可分辨或有批次 ρ 混杂，只作方向一致性证据；(92,96) 组 −10.7 s 信号建议同批次受控复投，不直接换装。

## 具体动作

1. 时延臂建模：X(R)=线速+(λ_g·ρ·T_win)·(T_starve+ρ_q·T_rec(m)+κ·RTT)，证明碰撞项对 m 平坦（2.10–2.29 s）、梯度全来自线速项；m=0（T_rec 发散）定性排除出数值前沿。
2. 风险臂精确求解：有限缓冲（40 pkt）M/D/1 嵌入马尔可夫链幂迭代（|Δπ|<1e-14），给出 ρ_q=0.90–1.00 的 P(溢出) 与 E[N]；另给碰撞满窗期望丢包/场（225→1725 pkt 随 R 上升）。
3. 组装 Pareto 边界与膝点分析：98M→96M 风险跨一个数量级、94M 以下风险平坦线速单调变差 → 膝点 m≈4%。
4. 实测抽取与 Welch 检验（(R5,R6) 精确分组，n≥3 六组）：t5 对 R5 无单调响应（背景份额淹没 1.4 s 线速差）；全部跨组比较标注 0065 批次 ρ 混杂，禁止因果解读。
5. 与 0066「96M 平坦区」、0072 复测口径、0068 长文件主导度三方闭环；给出 5/6.bin 非对称定价（5.bin 线速敏感度是 6.bin 一半）。
