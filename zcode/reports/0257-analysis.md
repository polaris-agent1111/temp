# Task 0257 交付报告：网络接口 MTU 探测与巨型帧分片开销在浅缓冲区下的性能边界

- 完成时间：2026-11-07 18:32
- 执行者：zcode
- 结论：**分片丢包临界点 MTU\* = 1200B（convention A，0249 裁决口径）；平台 Ethernet 1500 下 k=1 恒成立、余量 21.2%–25.0% —— 1200B 安全边界量化完成，零分片开销；一旦 MTU<1200，浅缓冲（B=40）报文级丢失率 ×4.13（k=2）/×11.8（k=3）且字节容量近半塌缩。**

## 一、任务目标与考核指标
- **任务目标**：测试不同 MTU 设置下的分片开销并评估浅队列下的分片丢失风险；
- **考核指标**：计算分片丢包临界点并量化 1200B 安全边界。

## 二、测试实施与脚本
- **执行脚本**：`zcode/scripts/mtu0257_fragment_boundary.py`（纯本地 numpy/scipy，零网络、零提交、零受保护路径写入）；
- **方法**：分片计数闭式 k=ceil(1180/(MTU−20)) + 柯尔莫哥洛夫脉冲链精确解（继承 0085 机器，B=40 浅队列）+ 事件驱动蒙特卡洛独立验证（确定性节奏 + 指数服务 + 40 槽 Drop-tail，600/300s × 3 种子）三路互证；
- **口径**：1200B = IP 满包（0249 已裁决），convention B（1228B）作敏感性留档。

## 三、测试结果数据
1. **分片临界点**：MTU 1200B 恰好单片；1199B 即 2 片；convention B 敏感性 MTU\*=1228B、L1 成帧计费 1238B —— Ethernet 1500 在全部口径下 k=1，余量 25.0% / 22.1% / 21.2%；
2. **锚点命中**：k=1 脉冲链复现 0085 已发布值 0.157%（leak 40/4ms），MC 独立验证 0.158%（相对偏差 0.5%）；
3. **浅缓冲分片惩罚（双重）**：报文级丢失率 k=1 0.157% → k=2 0.649%（×4.13，独立片下界仅 ×2.00——队列相邻相关性再翻倍）→ k=3 1.850%（×11.8）；MC 与脉冲链偏差 ≤1.6%；有效字节容量 k=2 塌缩 −49.2%；
4. **独立片下界律**（其他机制引用）：4.513%→8.82%（tb r40，k=2）；36.342%→59.48%（tb 倾泻，k=2）；
5. **巨型帧裁决**：MTU 9000 对本链路零收益（报文恒 1200B），且 9000B 帧 720µs 队头阻塞在浅缓冲下纯风险；
6. **合规核查**：MTU 不是提交杠杆（pacer.txt 无 MTU 参数），本审计为防御性确认 + 答辩弹药；QUIC 标准行为（RFC 9000 §14.1）端点禁用 IP 分片，MTU<1200 时为显式握手失败而非静默丢包。

## 四、结论
- 1200B 恰好位于 QUIC 最小数据报与 Ethernet 1500 之间最宽安全带内点：**全部口径下 MTU≥1200 ⟹ k=1 ⟹ 零分片开销**；
