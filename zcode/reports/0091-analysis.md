# 0091 报告：针对官方统一复测抽样的最佳样本量与统计检验效能分析

- 完成时间：2026-11-07 07:25
- 执行者：zcode
- 结论：官方单发噪声 σ_d≈7.02s 下，top-5 名次差（0.44~5.38s）要以 99% 功效（α=0.05 双侧）分辨需每方 34~9452 轮复测，现实轮数（n≤10）下不可实现；n=3 时 99% 功效 MDE=24.6s > top-10 全宽 15.6s。官方复测只能分辨 ≥13.5s（n=10）级真实优劣，榜头排序统计上不可证明；「统计可证明登顶」需对榜首保持 ≥13.35s 官方口径差距 → 真本地 X≤101.2s（与 0084 独立推出同一数字）。复测 n 必须预先定死（序贯停机是假阳性放大器）。

## 具体动作
- 噪声模型（0084 后验 + 仓库实证）：σ_d=7.02s（95% CI 3.8~12.4）、同构复测对点估计 10.70s、本地测试床 s=11.35s、μ_B=+2.49s、τ_b=4.51s。
- 计算（zcode/scripts/power0091_sample_size.py，seed=42）：① 双样本等 n 样本量公式（效应量菜单：榜头名次差 0.44~7.34s + μ_B/τ_b 系统效应）；② top-6 两两 n@99% 矩阵；③ MDE 逆问题（n=1~50）；④ t 检验蒙特卡洛验证（10⁵ 次/格，公式偏差 <0.15pp）；⑤ 敏感性（σ_d CI、官方内部 k 次取平均 σ/√k、配对 ρ∈{0,0.5,0.8}、Bonferroni×45、Mann-Whitney ARE、符号检验）。
- 关键数字：榜首 vs Catnet Δ=2.80s → n@80/90/99% = 98/132/230；Catnet vs hashkimi Δ=0.44s → n@99%=9452；MDE@99%：n=3→24.6s、n=10→13.5s；配对同日 ρ=0.8 最好也需 46 轮。
- 修复一处脚本调用参数错误（mc_power 缺 α 实参），重跑通过。
- 交叉验证：本审计「99% 稳固需官方口径差 ≥13.35s → 真本地 X≤101.2s」与 0084「P≥95% 破榜首需 X≤101.2s」由两个独立统计框架收敛到同一数字。
