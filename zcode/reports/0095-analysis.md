# 0095 报告：全局理论下确界 105.592s 的可达性物理条件与香农信道容量映射检验

- 完成时间：2026-11-07 09:50
- 执行者：zcode
- 结论：**香农/BDP 认证下界是 50.4–51.0s 而非 105.592s；105.592s 为 n 依赖的跨构型 min-of-mins 序统计量（同构造法 n=405 已漂移至 96.1/94.0s），其单构型可达性物理条件（剪刀差不触发+巨流不压顶+六段联合 3.3e-14）在现役参数空间内不成立——「绝对不可超越性」作为物理定理不成立，信封仅可作诊断书挡。**

## 具体动作

1. 数据链重算：从 `runs/results.jsonl`（421 行/有效 405 场，valid=true 且非 load-*）重算六段极小值与三种信封变体（E_file=94.019s、E_stage=96.113s、E_run=109.465s），与 11-06 冻结值 105.592/106.597s 对照，证实信封随 n 单调下移（一天 −9.5~−12.6s）且六段极值来自六个不同构型家族。
2. 香农/BDP 映射：D/C=50.4s 无条件认证；BDP=729.2pkt、慢启动爬坡 316–433ms 被 L_i/C 吸收；逐段 T_i ≥ L_i/C+35ms → Σ=50.61s（+握手 51.03s）。
3. 份额反演：105.592s 需持续份额 0.4773C > 冠军开环 ρ=1 饱和天花板 0.4635C（0086 闭式），最恶劣工况不可达；但实测逐段 0.46–0.71C 证明弹性背景下份额上限非常数。
4. 可达性检验：六段 ±1% 邻域联合概率 3.3e-14；405 场实测「六段同时进 ±5% 邻域」命中 0；剪刀差机理（0085：batch 40/60 → 5/6.bin 尾部丢包 4.51%/36.3%）给出参数区不相交的物理解释。
5. bootstrap E(n) 轨迹（2000 次）：E_file 中位 n=50→101.9s、n=405→94.4s，证明序统计量本质。
