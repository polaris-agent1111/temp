# 0088 报告：官方 6 个独立下载任务间系统缓存与连接重置残余开销测定

- 完成时间：2026-11-07 07:2x
- 执行者：zcode
- 结论：官方口径明文「总时间=六次下载耗时相加、配置写入不计入」+ 本地 392 样本恒等式核验（Σdownloads−total 偏差 0.000000s）确立：任务间空闲期（socket 释放、内核 buffer 回收）不进入官方计时；进入计时的连接层残余每 bin ≤1 RTT（70ms），全程 ≤420ms（占比 ≤0.32%，≤ σ_d 的 6%），官方分辨率下不可辨识；1.bin 包络超出 ≈2 RTT 与理论界 140ms 吻合是唯一经验锚点。残余开销不是优化对象。

## 具体动作

1. 口径层：从 `docs/extracted/六载穿柜.md` 引官方两条明文（总时间=六次相加、配置写入不计入），推导「任务间空闲期不进入成绩、残余收缩为 per-bin 内部连接建立/首字节」。
2. 恒等式核验：392 条 valid 本地样本 max|Σ downloads − total| = 0.000000s——计时连续相加无缝隙。
3. 经验包络：per-bin min−满速−慢启动折算（0087 H1 口径）；识别 6.bin 的 +29.3s 为背景份额税（本地 min 55.29s 与 0086 开环份额地板 55.2s 量级一致），1.bin 的 +0.132s ≈ 2×RTT 与冷连接握手+首字节 140ms 理论界吻合；明确「本地经验分解无法把连接层残余从背景税中分离（1.bin 除外）」。
4. bootstrap 回归 T_i = α_i + β_i·proxy（proxy=Σ_{j≠i}T_j，2000 次）：β≥0 且 1/4/5/6.bin 显著（背景跨 bin 正相关）；长 bin 截距由背景份额地板主导，残余不可辨识。
5. 本地 harness 编排开销（wall−total）干净子集 n=390：mean 83.1s / p50 33.3s，仅作本地与官方计时边界差异说明（2 条批量导入 wall<total 记录已剔除）。
6. 理论界表：QUIC 握手（冷 1 RTT/0-RTT≈0）、TIME_WAIT 不适用于 QUIC（CID 空闲超时机制）、内核 skb 回收 O(µs) 且与下一连接并行、teardown 在末字节后不计时 → 全程残余 ≤420ms（保守）/70ms（持续连接）。
7. 与官方成绩分解：133.086−50.4=82.7s 差值中背景税 ~79s 主导、慢启动 ≈2.2s、残余 ≤0.42s（<0.5%）、噪声 σ_d≈7.0s——残余为零期望收益方向。
