# 0079 报告：官方榜单历史提交记录的时间序列谱密度分析

- 完成时间：2026-11-07 05:14
- 执行者：zcode
- 结论：**数据覆盖声明优先**——任务标题「16 支队伍 100+ 次提交」超出本地离线数据（红线禁联网补抓），实际用 **9 队 / 64 事件 / 51 条出分 / 146h 跨度** 执行并显著标注。谱分析结果：提交流是**会话驱动强突发流**（突发度 B=0.880、Fano 1.5→6.2 单调升、卡方 95.0 拒绝均匀）；周期图上 **~12.3h 带显著**（22.4 > Bonferroni 门限 11.29，即每日双会话节律的谐波成像），**1/day 单峰线不显著**（2.19 < 2.996）→ 不存在可利用的固定周期；同队间隔 P(≥45min)=30.6% → 45–60min 等待纪律在历史数据中属少数派行为；出分序列**对手全为白噪声**，唯我方序列呈显著学习趋势（−5.06 s/h，p=0.013，去趋势后白噪声）——全场唯一非平稳序列是我方的自适应闭环。

## 具体动作

1. 数据源汇并去重（board_attempts 42 + board_log 30 + official_results 10 + board_watch 5 + own_ledger 15；同队 ≤2s 合并）→ 9 队 64 事件；覆盖差距与来源时钟偏差（~20s）如实标注。
2. 点过程强度：间隔分布（均值 139.0min / 中位 18.3min / CV²=15.73）、Goyal-Variya B=0.880、Fano 因子六窗曲线。
3. 谱密度：点过程周期图 P(f)=|Σe^{-2πift_k}|²/N，Exp(1) 零假设 + Bonferroni；频带 [73h, 10min]；1/day 谱线专项检验；带限（3–48h）最大值判定。
4. 昼节律：hour-of-day 卡方（北京时间修正——修复了初版 UTC 小时偏移 8h 的 bug）。
5. 同队节奏：六队同队间隔分布 + 单日峰值（5–6 发/日 = 配额硬约束成像）+ P(≥45/≥60min) 危险率（对照 WAIT_MIN 45→60 建议）。
6. 出分序列谱：各队 lag-1 自相关 + shuffle 白噪声检验 + 去趋势复核（区分「趋势主导」与「真 AR」）；赛博coder 判定为趋势主导。
