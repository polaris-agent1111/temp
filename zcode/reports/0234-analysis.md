# Task 0234 交付报告：决选树热加载自动校验与签名工具

## 一、任务目标与考核指标
- **任务目标**：研发并压测候选配置树热加载原子切换与飞行哈希校验工具，保障自适应流水线毫秒级切换；
- **考核指标**：P95 热加载切换时延 $< 5.0\text{ ms}$，文件系统冲突与损坏次数恒等于 0 次。

## 二、测试实施与脚本
- **执行脚本**：`zcode/scripts/hotload0234_tree_validator.py`
- **候选配置**：覆盖 5 套全量候选配置树（Crown Fusion / Plateau A / Ultra Low / BBR Probe / Defense）；
- **压测轮次**：100 次连续动态配置轮换；
- **校验内容**：3 行结构、LF 结尾、`[timestamp:N]` 匹配、SHA-256 签名一致性。

## 三、测试结果数据
1. **测试轮次**：100 轮候选树切换与飞行校验；
2. **平均切换延迟**：$1.242\text{ ms}$；
3. **P95 切换延迟**：$1.501\text{ ms}$（门禁标准 $< 5.0\text{ ms}$，通过）；
4. **最大切换延迟**：$1.967\text{ ms}$；
5. **文件系统竞争与格式冲突**：0 次（通过）。

## 四、结论
- 决选树热加载工具通过严苛压测，为 1-by-1 动态自适应决策提供坚实底层支撑；
