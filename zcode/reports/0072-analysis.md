# 0072 报告：多轮实测下令牌桶容量 Burst 与初始 tokens 差分耦合效应响应曲面拟合

- 完成时间：2026-11-07 04:02
- 执行者：zcode
- 结论：Burst×tokens 响应曲面为**铰链型**（光滑区 ∂²T/∂τ∂B=0，耦合只在 τ=B 与 (r/I)g=B），B/τ 均值效应物理上界 ~0.24 ms ≪ 噪声 ⇒ 均值维度不可辨识；匹配分层实测（n=27 双侧大格）发现 **B=60 场间方差显著更低（F=3.99, p≈0.023）**，官方复测平均口径下 B=60（150.9）优于 B=40（153.5）——冠军点 (τ=40,B=60) 的辩护词是方差稳健性而非均值速度。

## 具体动作

1. 只读解析 `runs/results.jsonl` 全部 88 条含 token_bucket 的 valid 记录，按 (τ,B,r,I) + 2/4/5/6.bin 精确签名分层；修正初版两层 bug（速率换算需用 0051 正典 r/4ms 口径、速率标签 12M/12.25M/12.5M 折叠）。
2. 解析推导铰链定理：理想令牌桶总时公式 + 三条偏导（τ/B 各自只经发射脉冲与积攒上限进入）+ 光滑区零交互；效应量上界表（发射节省 4.0 µs/包；全程 B 效应总界 ~0.24 ms；对照 ρ 效应 s 级 = 10⁴ 倍）。
3. 匹配对照检验（τ=40/r40/4ms/5.bin=100M/6.bin=96M，两侧 n=14 vs 13）：
   - 均值面 T(B)=128.14+0.256·B（n 加权 OLS），Δmean(B60−B40)=+4.83 s，Welch t=+1.23 不可分辨；斜率与物理界差 10⁴ 倍 ⇒ 归因于批次间 ρ 漂移（0066：ρ+2 档 ≈ +4.3 s，与实测同量级）。
   - 方差面：F=3.99（df 13,12），双侧 p≈0.023 ⇒ B=60 方差显著更低（sd 6.53 vs 13.05，CV 4.6% vs 9.4%）。
   - 选型：μ+1.96σ/√3 口径 B=60→150.9 < B=40→153.5，与 0058 复测方差惩罚框架一致。
4. τ 维度判定为不可辨识（无受控扫描，全部 τ 配置与 B/r 共移），保持冠军点 τ=40（铰链内侧）。
5. 邻域稳定性：B∈[40,60] 均值域 [138.7,143.5] 无悬崖；50/55/70 为 LOW_N 单点，只作方向参考。
