# 0243 报告：极小极大遗憾策略在极端网络对抗下的最坏情况分析

- 完成时间：2026-11-07 17:22
- 执行者：zcode
- 结论：**Savage 准则在全部已构造状态上选出 C1-steady-40x3-37-36x2，总最大遗憾 1.36s ≤ 2.5s——考核目标在点估计上成立；但 bootstrap（B=10000）显示 P(max regret ≤ 2.5s) 仅 22.3%，目标对抽样噪声不稳健；「任意候选任意态 ≤2.5s」强解读不成立（crown 族最大遗憾 4.47–5.79s）。**

## 具体动作

1. 从 `runs/seq_1108_shot_{1,2,3}.json` 装载决选 3 棵 distinct 配置树，并与其本地证据族（`runs/results.jsonl`，valid=true、剔除 load-*）做**逐目录 config 一致性校验**：全部完全一致（C1/C2/C3 ← n=15/15/10）。
2. 编写并执行 `zcode/scripts/regret0243_minimax_savage.py`（纯本地 numpy，seed=42 可复现）：
   - **Layer A 数据态**：经验分位数态 q∈{P25,P50,P75,P90,max} 遗憾矩阵。C1 最大遗憾 1.36s（仅在 q=0.25 态），C2 4.39s，C3 5.77s。
   - **Layer B 机制态**（引用 0085/0086 已审计实测数字）：共模抵消定理（官方-本地偏移不改变 regret 排序）；巨流/饱和态共模差分为零；阵风态差分按 0085 实测梯度（leak36/40 窗丢包 37/85 pkts）最坏外推——C2 vs C1 仅 0.080s、C3 vs C1 仅 0.027s（极端保守假设：每个 70ms 窗都在阵风）。机制差分对结论影响可忽略，遗憾排序由数据态主导。
   - **Bootstrap 校准**：族内重采样 10000 次，C1 max-regret P50=5.23s / P95=10.26s / P(≤2.5s)=22.3%；Savage 选择复制率 51.8%。
3. 排除污染：`sequential_1108_state.json` 的 118.1307 系列为 dry-run mock，未参与任何计算。

## 未完成/风险

- 官方态矩阵缺失：三棵决选树无任何真实官方出分，故「所有极端对抗状态」只能覆盖本地实证分位态 + 0085 阵风差分态 + 0086 共模态；官方侧未知调度突变不在能力内。
- 分位数态的「共同冲击强度」为构造性解释（各候选样本来自不同会话，无同期配对）。
- 目标「≤2.5s」是点估计结论而非统计结论（bootstrap P(≤2.5s)=22.3%），根因是本地样本重尾（std 8.4–9.6s）。

## 给 Lead 的建议
