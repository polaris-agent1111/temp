# 0248 报告：客户端用户态高精度计时器时钟漂移与补偿算法验证

- 完成时间：2026-11-07 17:30
- 执行者：zcode
- 结论：**考核目标 PASS**——4 ms 发送间隔累计漂移在「绝对时限死算 + 末端自旋」与「窗口重锚定」两方案下实测 0.0–0.1 µs（门限 10 µs 的两个数量级以下）；相对休眠同一实验累计漂移 127.4 ms（反面教材）；并复现了官方 G=4000 µs 量化时钟对 sub-G 间隔的 ×4 慢化（v1 245 s 惨案机理）。

## 具体动作

- 编写并执行 `zcode/scripts/0248_timer_drift.py`（标准库，仅本机计时，不触网、不碰云主机）：
  - E1：`perf_counter` 分辨率 100 ns、调用开销 p99=100 ns（n=20000）；
  - E2：相对 `sleep(4ms)` 400 拍累计漂移 **127 435.7 µs**（每拍 +317.9 µs，线性累积）；
  - E3：绝对时限 `deadline=start+n·Δ` 纯 sleep 累计漂移 184.0 µs（有界不累积，但 Windows 单拍唤醒抖动超门限）；
  - E4：绝对时限 + 0.8 ms 末端自旋累计漂移 **0.0 µs**（PASS）；
  - E6：窗口重锚定（W=500）2000 拍累计漂移 **0.1 µs**（PASS）；
  - E5：G=4000 µs 量化时钟仿真——1 ms 间隔相对调度被 ×4 慢化（9000→2250 pkt/s，与 v1 官方 245.995/243.958 s 换算一致），4000 µs 对齐间隔慢化严格 ×1.000。
- 关键输出（节选，全量见 `_0248_out.md`）：

