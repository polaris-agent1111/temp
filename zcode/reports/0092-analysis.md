# 0092 报告：官方宿主机 CPU 亲和性与上下文切换对微秒级 Pacing 稳定性的干扰测度

- 完成时间：2026-11-07 07:50
- 执行者：zcode
- 结论：CPU 调度链干扰在 leak 模式下唯一有效通道是速率折损，空闲基线仅 0.23–0.29%（ΔT≈0.3s = 0.04σ_d），绑核净收益仅 ≈0.14s；灾难量级需要「公平轮转风暴」，已被官方固定拓扑与 11-06 CPU 重载证伪排除。**CPU 亲和性/上下文切换不是官方-本地差距或复测方差的可归因来源，提交侧无 CPU 可行动作。**

## 具体动作

1. 建模唤醒路径四分量延迟：定时器回调分发（LogNormal 中位 3µs）+ 上下文切换直接/间接成本（Poisson 窗口叠加，1.2–3µs / Exp 20µs）+ CFS 抢占等待（Exp 100µs；风暴场景 U(0,24ms)）+ 跨核迁移（Exp 50µs，无亲和时）。
2. 蒙特卡洛（seed=42，31000 tick/下载）计算六个场景的干扰测度 I₁–I₄：
   - 空闲主机：E[δ]=9–12µs，速率折损 0.23–0.29%，ΔT=0.28–0.36s，**ΔT/σ_d=0.04–0.05**；
   - 中载 ρ=0.5：ΔT=1.7–1.8s（0.24–0.26σ_d）；重载 ρ=0.9：ΔT=3.2s（0.45σ_d）；
   - 公平轮转风暴（4 等权任务）：E[δ]=10.7ms、ΔT≈332s（47σ_d）——唯一灾难机制，已被证据排除；
   - 聚簇触发 P(δ>1000µs) 在正常谱系 ≤97ppm/tick，比 0076 固有聚簇下界低两个数量级；队列深 P99=0。
3. 闭式上界：P(δ>4ms)=10⁻³/tick 时折损恰 1000ppm（ΔT=0.124s）；吃掉 1σ_d 需要 P≈5.6%——等价于宿主机过半时间处于风暴态。
4. 亲和性净收益分解：MC 0.138s 与解析迁移项 0.155s 交叉验证一致。
5. 结构性结论：leak「严格单包等间隔」语义封死 CPU 抖动→突发超发的通道（突发惩罚只属于 token_bucket 模式），这是构型层面的结构免疫；µs 级 CPU 分量比 0068 已实测的 ms 级唤醒迟滞（0.8–1.2ms）小两个数量级；与 11-06「CPU 重载复现官方惩罚失败」一致。
