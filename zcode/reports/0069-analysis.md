# 0069 报告：BBRv1 拥塞控制在 Mininet 容器下的 BtlBw 与 RTprop 滤波动力学建模

- 完成时间：2026-11-07 04:10
- 执行者：zcode
- 结论：在「平台服务端 CC = BBRv1」条件假设下完成滤波器形式化 + 六条定理推导 + 轮级仿真验证；核心发现：**整形模块钳位等价于 BBR 泵阻尼器**（R ≤ μ_s 时泵幅归零），RTprop min 滤波在重尾间隙下自愈（ProbeRTT 不触发），G=4000µs 量化使 BtlBw 结构性上偏 +6.1%。

## 具体动作

1. 编写轮级流体仿真 `zcode/scripts/0069_bbr_dynamics.py`（纯标准库，仅 stdout，不写文件）。开发中修正三处建模缺陷：DRAIN 相位增益未设置导致状态卡死、交付量核算不一致（goodput 出现 >100% 线速）、min 滤波等值样本不刷新时间戳导致 ProbeRTT 死循环（43 次→0/3 次合理值）。
2. 形式化 BtlBw（10 轮最大值滤波）与 RTprop（10s min 滤波）方程、四相位控制律，映射 Mininet 容器四要素（模块钳位 R、RTT_prop=70ms、G=4000µs、浅缓冲 Q_lim=100）。
3. 推导六条定理：T1 公平份额锁定、T2 STARTUP 倍增收敛（0.32s）与浅缓冲过冲（1377 包一次性尾丢）、T3 泵幅恒等式（0.25·BDP=182 包 > Q_lim → 独占链路必然泵丢）与安全带（91% 线速）、T4 钳位稳态方程（欠驱/过驱两相）、T5 RTprop 续签/偏置/ProbeRTT 触发定理、T6 G 量化上偏 +6.1%。
4. 仿真三组验证：A 组四景（无钳位冷启动/重尾/钳位96M/巨流）；B 组 R∈{50..100Mbps} 扫描（丢包率 1.9%→19.3% 单调，goodput 46.5%→61.7%）；C 组 RTprop 续签对照（巨流常驻队列 3 次 ProbeRTT vs 间歇空闲 0 次）。
5. 与平台实测交叉验证：origin 默认档历史最差 ↔ T2 过冲自伤；6.bin 中位利用率 36.2% ↔ T1 份额锁定；leak/precise 族长文件更稳 ↔ T3 泵阻尼解释。
