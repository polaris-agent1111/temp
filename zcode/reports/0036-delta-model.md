# 0036 报告：官方 δ 建模 δ = f(rate, cap, interval)

- 完成时间：2026-11-06 08:06
- 执行者：zcode
- 结论：**三形式 δ 模型落地并出 Top-10**——主模型 B(`δ~rate+cap`) LOOCV MAE **2.9 pp（≈±3.8 s）**，优于 A(rate 样条 3.1 pp) 与 C(ln pps_eff 6.1 pp)；区域 `rate 34–40 × cap 30–60 × int 4000` Top-10 预测官方 **131.3–133.2 s**（全在现纪录 133.086 附近 ±4 s 内）；陷阱点 9/30/1000 三模型全部严重低估（+27~49% vs 实测 +96%）→ 确认模型只在 `interval≥4000` 域内有效。**8 个官方点分辨不出 <3 s 差异，输出只作投递排序、不作秒级结论。**

## 具体动作

1. **`tools/delta_model.py`**（标准库、一条命令重跑）：
   - 内置 8 个官方点（看板 06:40 表；官方分=leaderboard attempts 实测；本地分逐点标注口径，42/60 为插值 ~131）。
   - 三种形式 OLS 拟合（7 个正常档点，陷阱点留作 §3 边界检验）：
     - **A** `δ = β0+β1·rate+β2·max(0,rate−knot)`，结点 {27,30,33,36} 按 LOOCV 选（最优 33）；
     - **B** `δ = β0+β1·rate+β2·cap`；
     - **C** `δ = β0+β1·ln(pps_eff)`，`pps_eff=rate×1e6/ceil(int/4000)×4000`（G=4000 咬合后）。
   - 输出：系数、样本内 RMSE、**LOOCV MAE/RMSE**、逐点残差表、LOOCV 逐点误差表。
   - **陷阱边界检验**：7 点模型外推 9/30/1000 → A +49% / B +27% / C +27%，实测 +96.1% → 全部「严重低估→域外」。
   - **区域 Top-10**：rate 34–40 × cap≥rate–60 × int4000；本地分用 pre-1106 实测均值（剔 load-/hog-/11-06 污染样本），无实测格 IDW 插值（25 个实测格）；按主模型 B 排序。
   - CLI：`--predict rate,cap,int`（实测 `36,36,4000`→133.2 s、`36,40,4000`→136.0 s）、`--no-write`、`--out`。
2. **`docs/analysis/delta-model.md`**（AUTOGEN 覆盖写）：数据表 / 三形式拟合+LOOCV / 逐点残差 / 陷阱边界 / 区域 Top-10 / 敏感性与局限 / CLI。

## 关键发现

| 项 | 结果 |
|---|---|
| 主模型 | **B(rate+cap)**：LOOCV MAE 2.9 pp、RMSE 3.5 pp（A 3.1/4.1，C 6.1/8.2） |
| B 系数 | `δ ≈ +0.251 − 0.0099·rate + 0.0037·cap` → **rate 越高 δ 越小；cap 越大 δ 越大（最小桶方向被模型支持）** |
| C 形式最差 | 单变量 pps_eff 解释不了 30/50/5000（LOOCV +16.9 pp）——interval 单独进模型不够 |
| 陷阱检验 | 三模型外推 9/30/1000 全部 +27~49% ≪ 实测 +96% → **模型域 = interval≥4000**，1ms 是机制区不是曲面延伸（与 0013 一致） |
| Top-10 | 131.3（40/40）→ 133.2（38/39）；**10/10 预测 <133.086**，但模型对已知点 36/40/4000 样本内就偏 +2.9 s → 差异全在误差带内 |
| 敏感性 | 30/50/5000 本地 121.83→124.07 时 B 系数仅微变（+0.251→+0.238）；42/60 本地插值贡献 ±3% δ 不确定度 |
