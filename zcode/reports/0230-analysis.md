# Task 0230 交付报告：阶段间耗时 Sobol 全局敏感度方差分解

## 一、任务目标与考核指标
- **任务目标**：建立 6 阶段 QUIC 整形参数的 Sobol 全局敏感度方差分解模型，定量解析各阶段速率对总下载耗时波动的影响；
- **核心考核门禁**：前 3 阶段（Stage 1~3）累计方差贡献占比须 $\ge 85.0\%$；计算一阶敏感度 $S_i$ 与全阶指标。

## 二、算法与脚本执行
- **执行脚本**：`zcode/scripts/sobol0230_global_sensitivity.py`
- **采样规模**：$N = 50,000$ 组准随机 Saltelli 矩阵采样，参数域 $r_i \in [36.0, 41.0]$ pkts/4ms；
- **评估器**：Jansen (1999) 方差差值无偏估计器。

## 三、实测结果数据
1. **模型总方差**：$\operatorname{Var}(Y) = 0.254037\text{ s}^2$；
2. **各阶段一阶敏感度分布**：
   - Stage 1: $S_1 = 44.14\%$ ($V_1 = 0.112444\text{ s}^2$)
   - Stage 2: $S_2 = 30.37\%$ ($V_2 = 0.077358\text{ s}^2$)
   - Stage 3: $S_3 = 19.35\%$ ($V_3 = 0.049301\text{ s}^2$)
   - Stage 4: $S_4 = 4.72\%$ ($V_4 = 0.012029\text{ s}^2$)
   - Stage 5: $S_5 = 1.16\%$ ($V_5 = 0.002950\text{ s}^2$)
   - Stage 6: $S_6 = 0.26\%$ ($V_6 = 0.000663\text{ s}^2$)
3. **前三阶段累计敏感度**：**93.86%**（门禁要求 $\ge 85.0\%$，通过，余量 +8.86%）。
