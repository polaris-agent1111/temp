## 三、闭环仿真设计（模型阶梯与三族 CC）

**模型阶梯**：0085 已用柯尔莫哥洛夫方程解出**子 RTT** 队列波形（批量惩罚律）；本审计把窗口拉长到整个 bin 传输期，用**逐 RTT 流体步进**（Δ=70ms）+ 我方闭环 cwnd + 背景聚合速率控制器回答**长窗口吞吐**问题。两层互补：子 RTT 结构决定丢包档位（0085），长窗口份额决定完成时间（本审计）。

**我方闭环（三种 CC 风味，官方客户端 CC 族不可知 → 确界按族条件化）**：
- `reno`：SS 倍增 → CA +1 MSS/RTT，丢包 cwnd 减半（每 RTT 至多一次乘性减）——**最悲观族**；
- `cubic`：CA +max(1, 10%·cwnd)/RTT（CUBIC 大窗口增量近似）——中速恢复族；
- `bbr`：纯开环 pacing，丢包不闭环——**与我方「pacing 开环 + n_in_flight 旁路」架构同构，是对我方最有利的书挡**。丢包事件按泊松稀释概率化（期望丢包数 → 1−e^{−E}），避免把份额极小的溢出误判为必丢。

**背景情景（四层递进）**：
- `grid{ρ}`：非响应 Poisson 聚合，强度 ρ·μ（0085 §5 语义 + 我方闭环），ρ∈{0.25,0.5,0.75,1.0}；
- `mega_resp`：开局 2.4s 一条 30MB 巨流按线速 μ 泵入（响应式：丢包减半、每 RTT 向需求恢复一半），其后 N~Poisson(1) 响应式；
- `mega_fire`：开局 2.4s **非响应火龙**（ρ=1.0 恒定，30MB/C=2.4s 排空），其后 ρ=0.44 定态；
- `saturate`：永久非响应 ρ=1.0——**连续 30MB 巨流链的极限 = 最恶劣工况的模型化身**。

仿真器守恒自检：accepted = offered − overflow、q ∈ [0,B] 恒成立；**互证锚点：bbr 的 grid1.00/saturate 完成时间（27.6s/55.2s）与解析 Tier-1 地板（§四闭式）逐位一致；grid0.50 bbr（40.4s）与闭式 ρ=0.5（40.4s）一致**。

## 四、核心结果 1：开环份额闭式解与吞吐衰减律（bbr 书挡）

开环平滑 pacer 在饱和侧的份额有闭式解（drop-tail 溢出按供给比例分摊，我方供给 g、背景供给 ρμ、排空 μ）：

$$
r_{\text{own}}(\rho) = \min\left(g,\ \mu\cdot\frac{g}{g+\rho\mu}\right)
$$

| ρ_bg | 我方 goodput (pkt/s) | 占 C 比 | 6.bin 耗时 | 5.bin 耗时 |
|---|---|---|---|---|
| 0.25 | 8085 | 0.776 | 33.0s | 16.5s |
| 0.50 | 6597 | 0.633 | 40.4s | 20.2s |
| 0.75 | 5511 | 0.529 | 47.8s | 23.9s |
| **1.00（最恶劣）** | **4828** | **0.464** | **55.2s** | **27.6s** |
| 2.00（双巨流并发） | 3142 | 0.302 | 84.9s | 42.4s |
| 3.00 | 2361 | 0.227 | 100.2s*(闭式) | 50.1s*(闭式) |

（*ρ≥2 为闭式外推，仿真网格未覆盖；P(N≥2)=26.4%、P(N≥3)=8.0%（Poisson(1)），双巨流并发是真实存在的工况。）

**吞吐衰减律**：r_own(ρ) 是 ρ 的凹减函数，ρ∈[0,1] 内从 g 平滑降到 0.464g/0.864C=0.464×10416.7… 即 **0.464C 地板**；该地板由 g/(g+μ) 结构决定，与抖动无关。**衰减是温和且有下界的**——即使背景把「目标速率」全数兑现（ρ=1），我方仍保有 46.4% 线速能力。

三条结构性读数：

1. **开环（bbr 书挡）对一切情景鲁棒**：最恶劣 saturate 也只给 27.6/55.2s，相对满速加价 +14.8s/+29.6s。**30MB 巨流的边际代价 < 1s**：mega_fire（2.4s 火龙开局 + 0.44 定态）与同均值定态 grid0.50 几乎同值（20.1 vs 20.2s）——巨流挤占的是背景流的份额（它自己也在丢），我方 pacer 的每一包照常进入排空流；巨流不是叠加在我方时间上的额外灾难，它**就是**饱和本身。
2. **loss-based CC（reno/cubic）在持久饱和下饥饿**：ρ=1 / mega_resp / saturate 全部 >600s 未完成——机理是逐 RTT 必丢 → cwnd 钉死 CMIN=2（2 pkts/RTT ≈ 34KB/s），+1 MSS/RTT 的线性恢复追不上背景的减半-恢复循环。cubic 的 10%/RTT 增量也仅把 mega_fire 从 42.1s 拉到 31.8s，无法脱困。**若官方客户端是 loss-based CC，理论上最坏确界就是 Tier-0 的 4,667s/9,333s（cmin 钉死）——但五发官方实测 124.4–155.2s 直接排除该族为实际行为**（若为 loss-based，任一次 ρ≈1 窗口都会把 6.bin 推到数百秒，与实测矛盾）。
3. **实测锚点落在开环书挡与饱和侧之间**：Shot2 分解 5.bin≈33.2s、6.bin≈64.1s（份额 0.386C），介于 bbr grid1.00（0.464C）与实测最差之间；差距 = 子 RTT 丢包税（0085：leak 0.157% 起步）+ ACK 时钟/队列时延膨胀 + 实现残差。mega_fire reno 的 6.bin=71.9s 与本地 leak36 样本 6.bin 中位 72.6s（runs/results.jsonl）意外接近，仅作方向性旁证（本地与官方环境不同口径，不得混用——AGENTS.md 测量纪律）。

## 七、工程含义

1. **架构结论（本审计最重要单条）**：开环平滑 pacer 是对抗重尾巨流的正确架构——份额地板 0.464C 与 ρ 无关的结构保证（g/(g+ρμ)）意味着**不需要为巨流做任何速率 retreat**；一切「检测到巨流就降速」的反应式设计都会把损失-based 闭环引入而进入饥饿区。
2. **巨流边际代价定理（开环）**：单次 30MB 巨流压顶（2.4s 线速火龙）对完成时间的净加价 < 1s（mega_fire ≈ 同均值定态）——因为它挤占的份额本来也是背景的。真正的代价函数是**窗口平均饱和度** ρ，不是最大单流尺寸。
3. **双巨流并发是次恶劣设计点**：P(N≥2)=26.4%，此时 6.bin 退到 ~85s（闭式）；champion 的 111µs 间隔（13.6% 排空余量，0085 剪刀差）正是在该工况下把子 RTT 丢包税压半的机制。
4. **复测风险定位**：官方统一复测若抽到 ρ≈1 高压种子，champion 总时间的期望落点 ≈ 124–131s（锚点+σ_d），仍优于 Catnet 119.83 之外的全体历史提交；该结论与 0084 的贝叶斯校准（官方 ≈ 真值本地 +2.5±7.4s）一致。

## 八、结论

1. 复核官方流长 CDF 三项解析量（E[S]、P≥10MB、P≥28MB）全部与既有口径一致；6.bin 窗口遇 ≥28MB 巨流概率 73.8%，E[最大流] 28.51MB——高压是常态邻域。
2. 建立逐 RTT 流体闭环仿真器（42 情景组合，NSEED=4000，守恒自检 + 与解析闭式逐位互证），给出三族 CC 条件化的完成时间矩阵。
3. **最恶劣工况确界（三明治）**：5.bin ≤ 27.6s（模型）/ 33.2s（实测锚点）；6.bin ≤ 55.2s / 64.1s；工程包络 ≈40/71s；总时间包络 124.2s（=Shot2 自洽）/ 131s（含 σ_d）；病理上界 4,667/9,333s 被实测排除。
4. **开环份额闭式解 r_own(ρ)=μg/(g+ρμ)** 给出吞吐衰减律与 0.464C 地板；30MB 巨流的边际代价 < 1s——巨流压顶不构成对我方架构的额外威胁。
5. 合规：闭门数值实验（纯本地 numpy，seed=42 确定性），零探测、零提交、零受保护路径写入。

## 九、风险与未决

- 背景聚合的 RTT 级压缩（Poisson(1) 活跃流数、每流线速需求、响应式恢复 ×0.5/RTT）是粗粒度保守化：真实背景流有慢启动与流内 on-off 结构；火龙类情景（mega_fire/saturate）是上界方向，mega_resp 的响应式恢复介于真实 TCP 与火龙之间。
- CC 三族是风味级近似：reno/cubic 的 SS/CA 参数、bbr 的无损开环都未实现各自协议的完整状态机（BBR 的 STARTUP/PROBE_RTT、CUBIC 的 K 常数等）；结论按「族级」而非「协议级」成立。
- 官方客户端 CC 族不可知（也不应探测）：饥饿类结论（reno/cubic 未完成）是理论书挡，其现实相关性仅由五发实测间接排除；若官方栈为 CUBIC 且背景从未持续饱和，真实位置在 reno 行与 bbr 行之间。
- Tier-2 锚点的 bins1-4 部分来自本地 leak36/40 分文件中位（官方不公布逐 bin 成绩），仅作量级参照；本地与官方分开陈述（AGENTS.md 纪律）。
- ρ≥2 的闭式外推未做仿真复核；Poisson(1) 活跃流数忽略了流寿命（~2 RTT）的自相关，双巨流并发的持续时长被低估。
