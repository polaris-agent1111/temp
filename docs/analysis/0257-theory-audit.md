# 0257 任务理论审计：网络接口 MTU 探测与巨型帧分片开销在浅缓冲区下的性能边界

> 任务单：`zcode/requests/0257`（2026-11-07）。脚本：`zcode/scripts/mtu0257_fragment_boundary.py`；原始输出：`zcode/scripts/_0257_out.md`。
> 承接口径：0249（1200 B = IP 满包裁决、r=40 全口径安全上界）、0085（B=40 浅队列、μ=10416.67 pkt/s、脉冲链机器与丢包梯子 0.157%/0.605%/1.240%/4.513%/36.342%）。
> 合规声明：纯本地 numpy/scipy 闭门数值实验，零网络、零提交、零受保护路径写入；MTU 不是提交杠杆（pacer.txt 无 MTU 参数），本审计为防御性确认与答辩弹药。

## 1. 分片计数临界点（双口径）

convention A（0249 已裁决，官方锚点零自由度命中）：**1200 B = IP 层满包**，载荷 1180 B；每片净载荷 = MTU−20（RFC 791），分片数

$$k(\text{MTU}) = \left\lceil \frac{1180}{\text{MTU}-20} \right\rceil,\qquad \text{线材字节} = 1200 + 20\,(k-1)\ \text{（每片重加 IP 头）}$$

| MTU (B) | k | 线材总量 (B) | 判定 |
|---|---|---|---|
| 9000（巨型帧） | 1 | 1200 | 无分片 |
| 1500（Ethernet 标准） | 1 | 1200 | 无分片 |
| 1228 | 1 | 1200 | 无分片 |
| **1200** | **1** | **1200** | **恰好单片（临界点）** |
| 1199 | 2 | 1220 | 分片 ×2 |
| 900 / 1000 / 610 | 2 | 1220 | 分片 ×2 |
| 576（经典最小 MTU） | 3 | 1240 | 分片 ×3 |
| 420 | 3 | 1240 | 分片 ×3 |
| 315 | 4 | 1260 | 分片 ×4 |

**临界点：MTU\* = 1200 B**（convention A）；convention B 敏感性（1200 B = QUIC 净荷，0249 已否决但留档）线材 1228 B → MTU\* = 1228 B；L1 成帧计费（+38 B/帧）→ 1238 B。Ethernet 1500 在**全部三口径下均 k=1**——结论对口徘认知不敏感。

## 2. 浅缓冲区（B=40 Drop-tail）下的分片精确解：脉冲链 + 蒙特卡洛三路互证

节奏保持冠军构型 leak 40/4ms 的「每 100 µs 一报文」；分片使每报文在队列中变为 k 片批量（片内到达间隔 ≤72 µs，远小于 ms 级排队时标，批量近似成立）。服务率按片均字节取指数近似（异构服务需 phase-type，中性近似，已声明）。脉冲链：$P^*=\exp(\mathbf G_{\text{death}}T_e)\,J_k\,P^*$，$J_k$ 为批量跳变算子、溢出 $\ell_k=\sum_m (m+k-B)^+P_m^*$。

| k | 场景 | ρ | 片丢包占比 | 报文级丢失率 | MC 验证（片/报文） | 相对偏差 |
|---|---|---|---|---|---|---|
| 1 | MTU≥1200（现状） | 0.960 | **0.157%** | 0.157% | 0.158% / 0.158% | 0.5% |
| 2 | MTU 900（900+340 两片） | 0.976 | 0.413% | **0.649%** | 0.408% / 0.641% | 1.2% |
| 3 | MTU 420（420+420+400 三片） | 0.992 | 0.920% | **1.850%** | 0.906% / 1.821% | 1.6% |

- **锚点命中**：k=1 复现 0085 已发布值 0.157%（同构 D/M/1/40 脉冲链）；事件驱动蒙特卡洛（确定性到达 + 指数服务 + 40 槽，600/300 s × 3 种子）与脉冲链偏差 ≤1.6%。
- **放大律升级**：报文级丢失放大 k=1→2 为 **×4.13**、→3 为 **×11.8**，显著高于独立片假设 $P_d=1-(1-p)^k$ 的下界（×2.00 / ×2.96）——**同一报文的分片在 40 槽浅队列中位置相邻、丢失正相关，相关性使放大再翻一倍以上**。这是浅缓冲区别于深缓冲的本质特征。
- 独立片下界律在 0085 校准梯子上的读数（供其他发射机制引用）：4.513%→8.82%（k=2，×1.95）；36.342%→59.48%（tb 倾泻 k=2，×1.64）——倾泻档叠加分片将接近 6 成报文报废。

## 3. 浅缓冲槽位经济学：字节容量塌缩

队列按「包槽」计量（B=40 槽），分片后同一字节量占用更多槽：

| k | 片均字节 | 有效字节容量 | 相对塌缩 |
|---|---|---|---|
| 1 | 1200 B | 48 000 B | — |
| 2 | 610 B | 24 400 B | **−49.2%** |
| 3 | 413 B | 16 533 B | −65.6% |

即分片对浅缓冲的惩罚是**双重**的：批量跳变 b=k（§2 的脉冲链放大）+ 突发容忍的字节容量近半收缩。深缓冲（BDP 量级）下第二条可忽略，40 槽浅队列下两条同时全额生效。

## 4. 1200 B 安全边界的量化与巨型帧裁决

| 口径 | 临界 MTU* | Ethernet 1500 余量 | 判定 |
|---|---|---|---|
| A: 1200 B = IP 满包（0249 裁决） | 1200 B | 300 B = **25.0%** | k=1 安全 |
| B: 1200 B = QUIC 净荷（敏感性） | 1228 B | 272 B = 22.1% | k=1 安全 |
| L1 成帧计费（+38 B/帧） | 1238 B | 262 B = 21.2% | k=1 安全 |

- **QUIC 标准行为（RFC 9000 §14.1）**：端点禁止依赖 IP 分片，最小数据报 1200 B；路径 MTU < 1200 时 DPLPMTUD 收缩或握手直接失败——**显式故障，而非静默丢包**。§2/§3 的分片放大律属于「天真 UDP 栈」假想支路，用于量化最坏情形与答辩推演。
- **巨型帧（MTU 9000）裁决：纯风险、零收益**。我方报文恒 1200 B，k 本来就是 1，巨型帧不提供任何分片收益；反而引入 9000 B × 8 / 100 Mbps = **720 µs 的队头阻塞**（单帧占队列时长是 1200 B 帧的 7.5 倍），在浅缓冲下恶化我方 paced 报文排队时延。共享 100 Mbps 汇聚链路上启用巨型帧只有坏处。
- **边界控制面核查**：pacer.txt 仅接受 pacer 模块参数（`configs/params_schema.json`），MTU/分片均不在提交杠杆内；平台拓扑（接入与汇聚均 100 Mbps、标准 Ethernet）由官方固定。因此本结论是**环境安全性的防御性确认**：不存在我们可触发或需规避的 MTU 配置风险。

## 5. 结论

1. **分片丢包临界点 MTU\* = 1200 B**（convention A；convention B 敏感性 1228 B；L1 计费 1238 B）——1200 B 恰好是 QUIC 最小数据报与 Ethernet 1500 之间最宽安全带的内点。
2. 一旦 MTU < 1200，浅缓冲双重惩罚：报文级丢失率 k=1 0.157% → k=2 0.649%（×4.13，独立片下界 ×2.00，队列相邻相关性再翻倍）→ k=3 1.850%（×11.8）；有效字节容量 −49.2%（k=2）。
3. **1200 B 安全边界量化完成：全部口径下 MTU ≥ 1200 ⟹ k=1 ⟹ 零分片开销、零字节膨胀**；平台 Ethernet 1500 以 21.2%–25.0% 余量覆盖全部口径不确定性。
4. 三路互证（本审计脉冲链 / 事件驱动 MC / 0085 已发布锚点）偏差 ≤1.6%，数字可在答辩中直接引用。

## 6. 局限

- 分片服务率取片均字节指数近似（异构尺寸需 phase-type HCMB），对 k=2/k=3 的绝对值有 ~10% 量级模型误差；放大倍数的**排序与量级**在三路方法下稳定。
- MC 仅覆盖隔离稳态（无背景阵风）；背景阵风下的分片耦合需把 0085 的 G_bg 生成器与异构服务合并，属后续方向——但阵风情景只会放大（不会缩小）分片惩罚，不影响「k=1 即安全」的判定。
- MTU 值本身不可观测（拓扑由平台固定，也无遥测）：Ethernet 1500 是 mininet/Containernet veth 与物理网卡的标准默认，属合理工程假设而非实测。
