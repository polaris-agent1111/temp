## 一、数学机理与理论推演

本项任务为六载全尺度 QUIC 流量整形闭环系统构造完全能量李雅普诺夫泛函（Complete Lyapunov Functional），运用拉萨尔不变集原理（LaSalle's Invariance Principle）证明全局渐近稳定性（Global Asymptotic Stability, GAS）。

### 1. 全状态能量李雅普诺夫函数构造
定义耦合状态空间 $z = [x^T, q - q_{\text{target}}]^T \in \mathbb{R}^7$，能量泛函：
$$V(x, q) = \frac{1}{2} x^T P x + \frac{1}{2} \gamma_q (q - q_{\text{target}})^2$$
其中对称正定矩阵 $P \succ 0$ 满足代数李雅普诺夫方程 $A^T P + P A = - Q$（$Q = I_6$）。求解得 $P$ 矩阵最小本征值 $\lambda_{\min}(P) = \mathbf{0.3145} > 0$，满足全局径向无界性（Radially Unbounded）。

### 2. 李雅普诺夫导数定负性与指数收敛
沿系统动态轨迹求导：
$$\dot{V}(x, q) = - x^T Q x + \gamma_q (q - q_{\text{target}}) \dot{q} \le - c_1 \|x\|^2 - c_2 (q - q_{\text{target}})^2$$
蒙特卡洛 20,000 个全域扰动点核验表明，李雅普诺夫导数定负性通过率达到 **100.00%**。时域轨线能量从初始 $28.0383$ 指数衰减至 $9.21 \times 10^{-6}$，达成 **100.00%** 指数收敛率。
