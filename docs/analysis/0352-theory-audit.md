## 3. 门禁判定（诚实读数）

| 门禁（任务单原文） | BASE 实测 | 判定 |
| --- | --- | --- |
| 百万次抽样冠军保持率 ≥ 99.5% | 99.99% | ✅ 通过，**但非稳健**（见下） |
| 下侧 CVaR-99 ≥ 116.5s（按「最快 1% 期望」读数） | 113.45s | ❌ 不通过 |
| 下侧 CVaR-99（若按「最差 1% 期望」读数） | 118.63s | ✅ 通过（该读数下门禁近乎平凡） |

**两个门禁互相矛盾**：保持率 ≥99.5% 需要我方复测中枢显著快于 117（BASE 取 116.0）；而下侧 CVaR-99 ≥116.5s（最快 1% 期望不低于 116.5）要求中枢 **慢于** ~119.7（G9：μ=120 时 117.38 才达标）。在 μ_us∈[116,120] 区间两门禁不可同时满足——提示该门禁组未经一致性校对，不应作为投点依据。

**敏感性（决定性结论）**：保持率由两个未验证假设主导——
1. δ_opp：对手回归优势 4s → 99.99%；无回归优势（δ=0）→ **76.90%**；
2. μ_us：今晚真实出分。取当前最佳 124.37 → **0.66%**；取 120 → 76.99%。
3. σ 与尾部：σ=5 → 98.21%（<99.5%）；重尾 ν=4 → 94.68%；σ=13.4 → 61.93%。

即：**99.5% 只在「我方打进出 116s 级别 + 对手回归 ≥4s + σ≤3s」的有利角点成立**。今晚 5 发的真实出分（当前全部未回）才是决定变量；在本测算完成时点上，保持率 ≥99.5% 的说法没有实测资格。
