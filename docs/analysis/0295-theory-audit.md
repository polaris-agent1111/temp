# 0295 理论审计：官方复测鲁棒性裕度在线交叉验证

## 1. 核心理论：大数定律、样本均值方差抑制与反过拟合纪律

官方测评须知明确规定：
> **「排行榜 top 提交将统一复测，防止针对特定随机种子的过拟合；重复多次取平均，更新排行榜。」**

本审计从统计推断与极值理论（Extreme Value Theory）严格推导我方皇冠平台点在官方统一复测下的绝对优势。

### 1.1 独立同分布复测下的方差衰减
设单次评测随机变量 $X \sim (\mu, \sigma^2)$。当官方进行 $M$ 次独立复测时，排行榜最终认定的成绩为样本均值 $\bar{X}_M = \frac{1}{M}\sum_{i=1}^M X_i$。
根据中心极限定理：
$$\mathbb{E}[\bar{X}_M] = \mu, \quad \operatorname{Var}(\bar{X}_M) = \frac{\sigma^2}{M}, \quad \operatorname{SE}(\bar{X}_M) = \frac{\sigma}{\sqrt{M}}$$
- **我方皇冠构型**：由于过阻尼平滑 pacing 避免了浅队列溢出，单次评测标准差严控在 $\sigma = 1.15\text{s}$。在 $M=3$ 轮复测下，标准误仅为：
  $$\operatorname{SE} = \frac{1.15}{\sqrt{3}} \approx 0.664\text{s}$$
  均值绝对漂移期望仅为 $\mathbb{E}[|\bar{X}_M - \mu|] = 0.546\text{s}$。
- **竞争对手 (Catnet 等)**：其历史成绩单次取得 119.8293s，但 Task 0272 高阶矩反演证实其分布具有显著正偏度 ($+0.7205$) 与重尾风险。在随机种子变化时，浅队列在 5~6 阶段有 $18\%$ 概率发生连环丢包与拥塞窗口剧烈折半，单次惩罚达 $8.5\text{s}$。在 $M=3$ 轮复测中，其均值劣化至 **121.4373s**，有 **16.1%** 的样本直接被甩至 124s 以外。
