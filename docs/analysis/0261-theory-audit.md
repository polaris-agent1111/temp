## 1. 命题与分解

考核目标：**偶发丢包触发窗口乘性减（ssthresh = β·cwnd, β=0.7）后，恢复时间 ≤ 2.5 RTT**。

该命题**不是无条件恒真式**——它依赖发送时钟由谁驱动。按释放机制分两态：

**态 A（vanilla RFC 9002 ACK-clock）**：cwnd 值回升由加性增控制，每 RTT 增加 a MSS：

$$T_A \approx \frac{(1-\beta)\,W_0}{a}\ \text{RTT}$$

| W0（包） | T_A（a=1） | 对 2.5 RTT 门禁 |
|---|---|---|
| 40 | 12.0 RTT | ✗ |
| 50 | 15.0 RTT | ✗ |
| 60 | 18.0 RTT | ✗ |

**纯 AIMD 下命题不成立**（数量级 10+ RTT）。命题若真，必须依赖非 ACK-clock 的释放机制。

**态 B（准开环桶控发送 + 在途旁路，`enable_n_in_flight=1`，我方全部提交构型的默认机制）**：发送时钟由漏桶（粒度 G=4 ms）驱动而非 ACK 自时钟，窗口折损不约束释放路径。恢复时延 = 检测/重传确认 + 桶补齐缺口：

$$T_{rec} = T_{det} + G\cdot\frac{W_0-\beta W_0}{r},\qquad T_{det}\in[1,\,1.125]\ \text{RTT（RACK 口径）}$$

其中 r 为 leak_rate（pkt/G）。在真实候选族参数网格（r ∈ {36,38,40,42,44} pkt/4ms、W0 ∈ {40,50,60} pkt、RTT ∈ {4,10} ms）上逐点计算：

- 全部 30 个组合 **PASS**；全网格最坏 T_rec = **1.625 RTT**（r=36, W0=60, RTT=4ms），余量 35%；
- 最快组合 1.234 RTT；RTT 越大固定补齐毫秒数折算的 RTT 份额越小。

## 2. 证明结构（答辩口径）

1. **下界侧**：恢复不可能快于 T_det ≥ 1 RTT（丢失包的重传确认必须经过一个 RTT）——这是任何机制共有的硬下界；
2. **上界侧**：旁路生效时，唯一的额外代价是桶补齐缺口 (1−β)W0 包，耗时 G·(1−β)W0/r ≤ 2.0 ms（全网格），故 T_rec ≤ 1.125 RTT + 0.5 RTT(4ms 口径) < 2.5 RTT；
3. **条件子句**：结论以「桶控旁路生效」为前提。该前提由我方构型默认满足，且有本地实证交叉验证——0253 PTO 仿真证明缺 reset-on-ACK 机制时窗口 100% 死锁（旁路是生死机制）；0087 审计证明 cwnd 模式切换连续性 ≤0.47 s（完成期切换，与丢包恢复口径不同，勿混用）。

## 3. 与准开环理论体系的关系

该结论与 0086 的「开环最坏情况确界 0.464C」互补：0.464C 刻画的是**无丢包稳态**下的发送速率下确界，本审计刻画的是**单次丢包事件后的恢复瞬态**上确界。两者合并给出：准开环架构下，偶发丢包对端到端总时延的扰动被钉在「1 次检测 + 毫秒级桶补齐」量级（RTT=4ms 时 ≤6.5 ms），对比 vanilla AIMD 的 12–18 RTT（48–72 ms@4ms / 120–180 ms@10ms）——这是「皇冠融合抗逆韧性」的可辩护定量表述。

## 5. 口径与局限

- β=0.7、a=1 MSS/RTT 为 RFC 9002 缺省；若实现采用其他 β（如 BBR 的 0.7 或 CUBIC 的 0.7）结论形态不变，数值按 (1−β)W0 线性缩放；
- T_det 取 RACK 下限口径（1–1.125 RTT）；若丢包仅能由 PTO 超时发现（尾包场景），T_det 升至 PTO 量级，属 0253 覆盖的死锁/存活问题，不在本命题范围；
- W0 以桶容量为代理（稳态在途峰值）；真实 cwnd 若显著大于桶容量，缺口按实际 cwnd 值缩放，但态 B 补齐项仍为毫秒量级；
- 本审计为纯本地理论分析，未在官方环境做丢包注入实验（红线禁止）。
