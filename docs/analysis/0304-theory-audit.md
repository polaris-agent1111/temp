## 5. 复跑协议（战后如何形成完整复盘）

1. 每发出分后（或全部收官后）运行：`python -I zcode/scripts/archive0304_full_battle.py`；
2. 脚本自动：以 `submissions.jsonl` 当日佐证 + 控制器日志「★ 成功捕获官方真机出分」行
   纳入 11/08 真实出分（DRY-RUN 行一律排除）；对 11/08 各构型样本重跑四项门禁；
   重建 11/08 闭环决策链；输出 `archive0304_snapshot.json` 完整战役档案；
3. 复盘模型三问（复跑后自动可答）：
   - 闭环决策链与事前计划的偏差（哪几发未按 0292 封存的指纹执行）；
   - 各构型官方样本是否过门禁（n≥3、CV≤5%、min≥0.9·mean）；
   - 「本地均值 ↔ 官方」同日差的可校准性（对照 0084/0104-0106 的 offset 后验）。
