# 0172 理论审计：针对 Catnet 历史提交时间序列的泊松点过程到达间隔建模

## 1. 非齐次泊松过程 (NHPP) 到达强度模型
根据 Catnet 历史 22 次打榜提交的时间戳分布，构建昼夜双峰到达强度函数 $\lambda(t)$（单位：次/小时）：
$$\lambda(t) = \lambda_0 + A_1 \exp\left( -\frac{(t - \mu_1)^2}{2\sigma_1^2} \right) + A_2 \exp\left( -\frac{(t - \mu_2)^2}{2\sigma_2^2} \right)$$
其中夜间峰值位于 $\mu_1 = 00:30$（$\lambda_{\max} \approx 2.50\text{ 次/h}$），日间峰值位于 $\mu_2 = 12:12$。

## 2. 评测碰撞概率与出击窗口决策
运行 `zcode/scripts/poisson0172_catnet_arrival_model.py`：
- 在 00:05~00:20 的 15 分钟发射窗口内，Catnet 活跃概率为 $45.2\%$；
- 与我方首发单场评测（约 150 秒）发生精确时间重叠竞争的概率仅为 **9.54%**；
- 若推迟至 00:30~01:00（Catnet 峰值集中爆发期），重叠竞争概率将骤升至 $>28.5\%$。

## 3. 结论与战术决策
**00:05** 是抢占评测节点空闲通道的绝对最佳窗口，避开了 Catnet 的 00:30 提交洪峰，为 Shot 1 创造极高保真度的数据基准。
