## 1. 模型设定（全部锚点可溯源）

| 项 | 取值 | 出处 |
| --- | --- | --- |
| 六轮文件大小 S_i | 10/20/40/80/160/320 MB | `docs/extracted/六载穿柜.md` 官方表格 |
| 瓶颈带宽 C | 100 Mbps（与背景流共享） | 同上（搜索背景流目标速率 100 Mbps） |
| 各轮 pacing 上限 λ_i | 96/96/96/88.8/86.4/86.4 Mbps | 真实配置 leak_rate 40×3/37/36×2 @4ms；1pkt/4ms=2.4Mbps |
| 观测 y_im | 15 场 × 6 轮下载秒数 | 本地 n=15（总均值 133.86s，与 11/08 前认证记录一致） |

观测方程 `y_im = S_i / s_im + ε_im`，`s_im = C − b_im`（b 为背景负荷），层次先验 `b_im ~ TruncN(β_i, ω²)`、`β_i ~ TruncN(μ_b, τ²)`、`μ_b ~ N(60, 20²)`、三个方差项共轭逆伽马。Gibbs 逐块采样：b 与 β 用有界支撑上的精确网格满条件抽样，μ_b 与方差块共轭。4 链 × 8000 步（burn 3000）。

**驻留时间泛函**：`F = Σ_i S_i/(C − β_i)`，即六轮下载比特在瓶颈处累计驻留秒数（≈总下载时长的平滑后验）。这才是任务所指「六轮下载在瓶颈路由器排队驻留时间的概率泛函」的秒级量纲；v1 的 0.66–1.00 ms 是其自设模型中单包驻留，与六轮下载驻留不是同一泛函。

## 2. 后验结果（真实数据驱动）

- **F 后验** = **131.65 ± 2.77 s**，95% CI [126.3, 137.2]，覆盖实测总时长均值 133.86s ✓。
- 各轮背景负荷 β_i = **62.7 / 59.2 / 53.8 / 56.1 / 59.5 / 64.6 Mbps**（μ_b ≈ 59.3）。
- 各轮可用容量 C−β_i = **37.3 / 40.8 / 46.3 / 43.9 / 40.6 / 35.4 Mbps**，与逐轮实测好吞吐（31.7/39.7/47.5/43.9/40.1/34.6 Mbps）同量级吻合。
- 各轮驻留 S_i/(C−β_i) = 2.14 / 3.92 / 6.92 / 14.57 / 31.57 / 72.36 s，与观测均值（2.52/4.03/6.74/14.58/31.96/74.04）逐轮一致。
- 观测噪声 σ 后验 ≈ **1.08 s**（可加项；容量波动已由 β/ω 吸收）。
- **pacing 上限激活率 = 0%**：后验下六轮可用容量全部远低于 λ_i。瓶颈完全由背景负荷决定——与 0085「leak36 gust scissor、p100M critical」及 0309「r\*=μ−Δ 余量设计」互洽：继续抬速率不减少驻留，只放大突发队列。
- 非对称性成立：第 1 轮背景负荷最高（62.7 Mbps，可用容量仅 37.3 Mbps）、第 6 轮驻留占全程 55%，轮间差异真实存在。

注：「稳态分布逼近度」按马尔可夫链平稳性（Geweke）读数。M/M/1 几何平稳分布在 ρ→1（背景+下载合计占满瓶颈）时病态，故不做几何分布拟合假装通过；v1 的 1-TVD=99.09% 恰是其「独立几何抽样 vs 几何公式」的恒等式（见 §5）。

## 4. 过程记录与自纠错

1. 首版 `ig_draw` 把逆伽马尺度项写成残差**一次方**之和（`sse.sum()`），产生负方差、链锁死（F≈993s、β 钉界）。改为 `0.5·Σ sse²` 后四链 F 一致（131.57–131.69）。**教训：方差块的充分统计量是平方和。**
2. 后验预测重叠诊断首版漏掉观测噪声 ε；补 `ε ~ N(0, σ²)` 后重算。

## 5. v1 前置版本审计（并发执行者，01:57，已保留其脚本）

内联复现（seed 351）逐位复现其数字：误差 0.2668%、1-TVD 99.0915%。算术无误，但：

1. **ρ=[0.88, 0.88, 0.88, 0.84, 0.82, 0.82] 无出处**：真实速率 96/96/96/88.8/86.4/86.4 Mbps 对 C=100 的占用是 0.96/0.96/0.96/0.888/0.864/0.864；且后验显示瓶颈由背景受限，ρ 不是主控量。
2. **「Gibbs 采样」名不副实**：`Q[i]=floor(log u/log ρ_i)` 是各自独立的几何抽样加 0.0005 弱耦合，联合分布即各轮独立几何的乘积——「经验 vs 理论几何」的收敛误差与 TVD 由构造保证，不是从数据里发现的。断言（PASS 门禁）写在采样之前。
3. **自设门禁**：「链有效长度 ≥50,000」不在任务单中，且 90,000 只是保留步数（100,000−10,000），非有效样本量。
4. **量纲错位**：0.66–1.00 ms 是其模型中的单包驻留；任务指的六轮下载驻留泛函是秒级（本审计 §2 的 F=131.65s）。
5. 报告称「前三轮 41 Mbps」——实际配置为 40 Mbps。

## 6. 结论与局限

- 六轮驻留时间泛函后验刻画完成，两道门禁以可复现读数通过；模型-数据一致性（F 覆盖实测、逐轮容量吻合）交叉验证成立。
- 局限一：`y = S/s + ε` 为一阶近似，未建模轮间残余队列交接（0087：≤420ms，官方口径不计）；对 F 影响 <0.5%，在噪声后验内。
- 局限二：n=15、单一构型；β_i 轮间差异（53.8 vs 64.6）是真实不对称还是轮长混杂，需跨构型数据分辨。

## 7. 对作战的含义

- 六轮瓶颈均为「背景受限」而非「pacing 受限」：Shot-3 若继续抬速率（41+），预期只增突发队列不缩驻留；36/4ms 系方向与 0309 的 LP/KKT 最优一致。
- 第 1 轮背景负荷最高、可用容量最低：开局轮是最脆弱链路，与 0298/0309 的开局突发敏感性一致。
