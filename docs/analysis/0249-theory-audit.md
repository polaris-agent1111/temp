## 1. 分层字节微积分（1200 B = IP 层满包口径）

| 层 | 典型 (B) | 最小 (B) | 依据 |
|---|---|---|---|
| IPv4 固定头 | 20 | 20 | RFC 791 |
| UDP 固定头 | 8 | 8 | RFC 768 |
| QUIC 1-RTT 短头（Flags+DCID 8+PN 2） | 11 | 2（DCID 0B + PN 1B） | RFC 9000 §32.1 |
| QUIC AEAD 标签 | 16 | 16（强制） | RFC 9001 §5.4 |

| HTTP/3 DATA 帧（Type+Length） | ≈0（摊销） | ≈0 | RFC 9114 §4：DATA 帧是流级抽象，**可跨 QUIC 包**，不逐包重复 |

**三层结论：**
1. **典型开销 63 B** → 载荷 1137 B，γ_typ = **94.75%**（0198 的 60 B/95.00% 是本带的内点；差异在 STREAM Offset 字段的 varint 记账：文件均 >16.4 KB → Offset 4 B，0198 记 2 B 少计）。
2. **开销理论下界 49 B/包**（0 长 CID + 1 B PN + 无 LEN 位 STREAM 帧 + DATA 摊销）→ **γ_max = 95.92%**。这就是「传输协议开销理论下界」的严格形式。
3. **模型不确定度带 = 95.92 − 94.75 = 1.17% ≤ 1.2% 核算门限**——报头核算本身的误差预算受控。

### 可识别性局限（诚实声明）

份额受限实测中 γ 与背景流份额 ρ 简并（measured_app = ρ·100·γ），纯应用层计时**无法**分离 γ；γ 的实测隔离依赖通道一（pacer 为唯一瓶颈的速率受限场）。**不得**把「≤1.2%」外推成「份额受限段误差 ≤1.2%」。

## 4. 局限

- MB 口径假设 1e6 B（630 = 10+20+40+80+160+320 精确吻合）；若平台用 MiB，好吞吐上限整体 +4.9%，违例检验仍成立但绝对值需重标。
