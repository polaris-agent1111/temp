## 6. 复核记录：首版「Rank 0」为何不被采信

首版脚本 `zcode/scripts/ga0278_pareto_nsga2.py`（已复现，输出与 `runs/ga0278_pareto_nsga2.json` 一致：0 支配者、f2=0.000、136.099s）存在三处构造性缺陷，其「Rank 0」是模型定义的直接产物而非证据：

1. **容量向量即 crown 向量**：`capacities=[41.5,41.5,41.5,37,36.5,36.5]` 就是 crown 配置（[41,41,41,37,36,36]）逐位 +0.5；`eff_rate=min(r,c)` 使任何 r≥c 的个体与 crown 等时，而 r>c 触发 `delta=r−c` 的无界队列累积罚。crown「零丢包」与「0 支配者」由定义保证——循环论证。
2. **种群坍缩**：复现输出 `individuals_dominated_by_crown_fusion_count=0` 与 `dominators=0` 同时成立，说明 500 代后种群全部收敛到与 crown 等适应度的点类，支配比较退化为恒等类。
3. **物理量纲失锚**：每阶段 `total_pkts_per_stage=218453（#250MB）` 均一化，与真实每阶段 10/20/40/80/160/320 MB（合计 630MB）不符；136.099s 无物理对应。
