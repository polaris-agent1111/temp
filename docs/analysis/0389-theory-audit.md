# 任务 0389 理论审计：超低时延微秒级定时器硬件中断补偿与内核时间戳校准滤波

## 1. 任务背景与核心目标
在基于 Linux 高精度定时器（hrtimer）和 eBPF 的微秒级流量整形系统中，由于网卡硬件中断聚合（Interrupt Coalescing, rx-usecs / tx-usecs）以及 CPU 本地 APIC 定时器中断处理的非确定性延迟，内核获取的时间戳存在纳秒至微秒级剧烈颤抖（Jitter Spikes）。
此种偶发时钟抖动会导致以下物理恶果：
1. 错误计算 RTT 与包间间隔，造成拥塞控制算法产生虚假丢包误判；
2. 极端情况下产生非单调时间戳倒退，破坏滑动窗口与 PACING 令牌漏出时序。

本任务构建卡尔曼-布西（Kalman-Bucy）连续-离散状态估计器与单调钳位算子，消除中断聚合引起的毛刺。

- **核心门禁要求**：
  1. 硬件中断定时抖动滤波消除率 $\ge 99.0\%$；
  2. 内核校准时间戳严格单调递增性 $= 100.0\%$。

## 2. 卡尔曼-布西状态滤波模型构建

### 2.1 状态转移与观测方程
设真实晶振基准时钟按照标称时间常数 $T_{\text{nom}} = 4000\mu s$（4ms）匀速推进。建立线性动态离散状态模型：
$$
x_{k|k-1} = x_{k-1} + T_{\text{nom}}
$$
测量时间戳 $y_k$ 叠加了网卡中断聚合的脉冲噪声 $v_k$（$85\%$ 正常微抖动 $\sigma = 1.5\mu s$，$15\%$ 聚合突发延时 $20\sim 100\mu s$）：
$$
y_k = x_k + v_k
$$

### 2.2 鲁棒更新与单调钳位算子
为抑制大振幅中断毛刺，将更新增益设计为强鲁棒小增益状态（$K = 0.005$）：
$$
\hat{x}_k = x_{k|k-1} + K (y_k - x_{k|k-1})
$$
同时施加严格因果单调性钳位（Monotonicity Clamp）：
$$
t_{\text{calibrated}, k} = \max\left(t_{\text{calibrated}, k-1} + \epsilon_{\text{guard}}, \hat{x}_k\right)
$$
其中保护时隙取 $\epsilon_{\text{guard}} = 0.1\mu s$。

## 3. 实验验证与计算指标
运行 `python zcode/scripts/timer0389_interrupt_jitter_filter.py`，实测数据如下：
- **原始硬件中断抖动标准差**：$33.311\mu s$；
- **校准滤波后时间戳抖动标准差**：$\mathbf{0.118\mu s}$；
- **硬件中断抖动消除率**：$\mathbf{99.65\%}$（门禁要求 $\ge 99.0\%$，达成率 **100.65%**）；
- **10,000 个连续周期单调递增率**：$\mathbf{100.00\%}$。

## 4. 结论与工程指导
任务 0389 证明了卡尔曼校准滤波器能有效将微秒级网卡中断毛刺降低两个数量级（从 $33\mu s$ 降至 $0.1\mu s$），保障了流量整形系统的微秒级时间硬确定性。
结果已封存于 `zcode/reports/0389_result.json`。
