# 任务 0468 理论审计报告：自适应无迹卡尔曼滤波 (AUKF) 浅缓冲区瓶颈突发容量无偏跟踪

## 1. 理论背景与数学推导
在 6 阶段 QUIC 穿柜传输中，网络拓扑的瓶颈物理带宽由于多流竞争和排队时延的非线性积压呈现动态时变特征。
传统卡尔曼滤波基于一阶泰勒展开（EKF），在浅缓冲区排队引发的非线性时延截断处截断误差较大；
而标准 UKF 假定先验噪声协方差 $Q, R$ 恒定，当背景大象流突然涌入导致信道容量阶跃跌落时容易发散或产生显著滞后。

### 无迹变换 (Unscented Transform, UT) 与 Sigma 点采样
设增广状态向量为 $x_k = [C_k, q_k]^T \in \mathbb{R}^2$（分别表示瓶颈可用带宽 Mbps 与交换机瞬时队列长度 pkts）。
构造具有相同一阶矩与二阶矩的 $2n+1 = 5$ 个确定性 Sigma 点集：
$$\chi_0 = \hat{x}_{k|k}$$
$$\chi_i = \hat{x}_{k|k} + \sqrt{n + \lambda} (\sqrt{P_{k|k}})_i, \quad i = 1, \dots, n$$
$$\chi_{i+n} = \hat{x}_{k|k} - \sqrt{n + \lambda} (\sqrt{P_{k|k}})_i, \quad i = 1, \dots, n$$
其中标度参数 $\lambda = \alpha^2(n + \kappa) - n$。

### 遥测观测方程与 Sage-Husa 自适应估计
接收端双遥测观测流包含吞吐量与排队抖动：
$$y_k = h(x_k) + v_k = \begin{bmatrix} \frac{C_k}{1 + \eta q_k} \\ q_k \end{bmatrix} + v_k$$
通过传递 Sigma 点计算预测观测 $\hat{y}_{k|k-1}$ 及新息向量：
$$e_k = y_k - \hat{y}_{k|k-1}$$
引入 Sage-Husa 指数遗忘加权自适应更新量测噪声协方差矩阵：
$$\hat{R}_k = (1 - d_k) \hat{R}_{k-1} + d_k (e_k e_k^T - P_{yy, k})$$
保证了新息序列在信道突发变异时的正交白噪声特性。

## 3. 对 6 阶段穿柜整形的工程指导意义
