# 任务 0467 理论审计报告：广义纳什均衡 (GNEP) 变分不等式投影动力学与浅缓冲区协同整定

## 1. 理论背景与数学推导
在 6 阶段穿柜传输（`question/1..6`）中，各个数据流并非孤立存在，而是共享交换机物理浅缓冲区 $C_{\text{buf}}$。各个流的发送动作相互耦合，构成广义纳什均衡问题（Generalized Nash Equilibrium Problem, GNEP）。

### 广义博弈形式与共享约束
设参赛实体控制的 6 个虚拟分流 / 传输阶段为博弈方 $\nu \in \{1, \dots, N\}$（$N=6$）。
每个阶段选择发包速率 $x_\nu \ge 0$。目标是极小化各自的时延与拥塞代价：
$$J_\nu(x_\nu, x_{-\nu}) = \frac{1}{2} d_\nu x_\nu^2 - w_\nu \ln(x_\nu + 1) + c \sum_{j=1}^N x_j$$
共同受到物理浅缓冲区总容量约束：
$$\sum_{\nu=1}^N x_\nu \le C_{\text{buf}}, \quad x_\nu \ge 0$$
可行域 $X \subset \mathbb{R}^N$ 为非负单纯形超多面体。

### 变分不等式 (VI) 与伪梯度单调性
由于共享约束是线性的，根据 Rosen (1965) 规范解定理，该 GNEP 的正规均衡等价于单值变分不等式 $\text{VI}(X, F)$：
$$\langle F(x^*), x - x^* \rangle \ge 0, \quad \forall x \in X$$
其中伪梯度映射为：
$$F(x) = [\nabla_{x_\nu} J_\nu(x)]_{\nu=1}^N = \left[ d_\nu x_\nu - \frac{w_\nu}{x_\nu + 1} + c \right]_{\nu=1}^N$$
由于 $d_\nu > 0$ 且 $\frac{w_\nu}{(x_\nu+1)^2} \ge 0$，Jacobi 矩阵 $\nabla F(x) = \text{diag}\left(d_\nu + \frac{w_\nu}{(x_\nu+1)^2}\right)$ 处处严格正定，故映射 $F(x)$ 是强单调的，保证均衡解 $x^*$ 存在且唯一。

### Korpelevich 外梯度投影动力学
为避免单纯投影振荡，采用两步 Korpelevich 外梯度迭代：
$$y_k = \Pi_X(x_k - \gamma F(x_k))$$
$$x_{k+1} = \Pi_X(x_k - \gamma F(y_k))$$
其中 $\Pi_X$ 为 $O(N \log N)$ 欧氏单纯形投影算子。
