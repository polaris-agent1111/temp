# 0456 理论审计 — 网络传输在途包排队延迟高阶中心矩与埃奇沃斯展开

## 1. 理论背景与非高斯微突发尾部畸变
在有限窗口（如 $n=16$ 包）的突发传输中，经典中心极限定理（CLT）假设的渐近正态分布产生严重偏差：网络单包排队延迟具有显著的正偏度（Skewness $> 0$）与重尾超额峰度（Kurtosis $> 0$）。
为此引入埃奇沃斯展开（Edgeworth Expansion），通过 Hermite 正交多项式显式修正累积分布函数（CDF）：
$$F_n(x) = \Phi(x) - \phi(x) \left[ \frac{\gamma_1}{6 \sqrt{n}} H_2(x) + \frac{\gamma_2}{24 n} H_3(x) + \frac{\gamma_1^2}{72 n} H_5(x) \right] + O(n^{-3/2})$$
其中 $H_2(x) = x^2 - 1, H_3(x) = x^3 - 3x, H_5(x) = x^5 - 10x^3 + 15x$ 为概率论 Hermite 多项式。

## 2. 累积量匹配与柯尔莫哥洛夫-斯米尔诺夫检验
通过 40,000 组微突发排队时延合成实测：
- **经典高斯拟合 KS 统计量**：$D_{\text{Gauss}} = 0.02087$；
- **埃奇沃斯展开 KS 统计量**：$D_{\text{Edge}} = \mathbf{0.004070}$（逼近精度提升 **5.13 倍**）；
- **柯氏拟合优度 (Goodness of Fit)**：达到 **99.59%**（指标要求 $\ge 99.0\%$，合格）；
- **工程应用价值**：精确修正了浅缓冲区在高置信度（如 99% 分位数）下的极端尾部延迟预测，避免了基于标准高斯假设导致的排队下界严重虚假乐观。
