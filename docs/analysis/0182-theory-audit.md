## 3. 官方终审复测蒙特卡洛（假设显式，N=10 复测均值）

规则背景（AGENTS.md）：官方对 top 提交「重复多次取平均」统一复测。我方复测标的是当日排名最高构型的配置；对手复测真均值不可观测，以其榜单分作为位置、加入复测平均噪声（敏感性基线 3.0/3.5s）。榜首参照：光明未来 117.0257s（hourly 11/07 09:00 快照）；Catnet 119.8293s（看板背景，11/06 口径）。

| 情景 | 假设 | P(top1) |
|---|---|---|
| A 全不确定度 | 偏移 ~ N(+0.6, 13.4) + 复测平均噪声 | **7.86%** |
| B 乐观 | 11/08 偏移复制同构型锚点 −10.16 且复测日不回摆 | **1.19%** |
| C 乐观+对手回摆 | B + 对手复测均值上浮 5s（min-of-N 红利回吐） | **15.90%** |

B 低于 A 的解释：固定偏移使分布收窄、左尾变瘦，「需要多少」（情景均值）与「有多确定」（偏移方差）两层不确定度混排的必然结果，非计算错误。

**需求线反解**：80% 概率在复测均值上同时压过双对手，官方真均值需 ≤ **112.81s**（换算本地口径 ≈112.2s，与 0084 结论「本地 ≤111.0s」一致）。当前皇冠主力本地均值 135.48s，**缺口 23.3s**——在现有构型池下，官方终审复测夺冠是小概率事件（个位数至 ~16%），上榜前三才是现实目标。

## 4. 反过拟合纪律核查

- 排名与预测一律均值口径；min-of-N 极值红利不进任何推断（与官方 top 统一复测直接冲突）。
- 本地统计仅取 valid=true；本篇五大构型无污染样本。
- 尖点拒投：40x3-36x3 本地 min 114.69 与 mean 134.53 差 19.8s、CV=10.0%，超过门禁线，不作为冲冠依据。
- 本地口径与官方口径全程分开；同日偏移锚点（n=1）只作情景，不作承诺。
