# Task 0371: 六轮次非平稳背景突发流的小波谱分解与逆滤波理论审计

## 1. 任务背景与信号处理问题
在千兆以太网交换机浅缓冲区中，跨流并发背景流量具有显著的非平稳突发（Burstiness）与重尾脉冲特性。传统傅里叶变换（FFT）无法提供时域局部化信息，导致对瞬态排队峰值的误判。  
本研究采用 Daubechies D4（db4）正交小波基建立 4 级多分辨率分解（MRD），并通过分层自适应软阈值（VisuShrink/SureShrink）设计逆滤波算法，消除跨流毛刺，恢复平滑底层信道容量。

---

## 2. 数理推导与小波变换

### 2.1 Daubechies D4 紧支正交小波基
Daubechies D4 尺度滤波器系数具有 2 阶消失矩（Vanishing Moments），滤波器系数为：
$$h_0 = \frac{1+\sqrt{3}}{4\sqrt{2}}, \quad h_1 = \frac{3+\sqrt{3}}{4\sqrt{2}}, \quad h_2 = \frac{3-\sqrt{3}}{4\sqrt{2}}, \quad h_3 = \frac{1-\sqrt{3}}{4\sqrt{2}}$$
正交镜像高通小波滤波器为 $g_k = (-1)^k h_{3-k}$。

### 2.2 多分辨率分解与分层阈值
对含背景噪声信道信号 $x[n]$ 进行 4 级 Mallat 金字塔分解：
$$x[n] \xrightarrow{\text{DWT}} A_4[k] + \sum_{j=1}^4 D_j[k]$$
其中细节系数 $D_j[k]$ 捕获不同尺度上的高频突发脉冲。  
各层阈值采用稳健中位数绝对偏差（MAD）估计：
$$\hat{\sigma}_j = \frac{\text{median}(|D_j - \text{median}(D_j)|)}{0.6745}$$
自适应收缩阈值：
$$\lambda_j = \hat{\sigma}_j \sqrt{2 \ln(N_j)} \cdot (0.85)^j$$
经过软阈值 $\eta(w, \lambda) = \text{sgn}(w)(|w| - \lambda)_+$ 过滤后执行 IDWT 完美重构。

## 3. 实验验证指标

- **原始含突发噪声信道 SNR**：$29.28$ dB
- **逆滤波重构后信道 SNR**：$41.83$ dB
- **信噪比提升幅度**：$\mathbf{12.55 \text{ dB}} \ge 12.0 \text{ dB}$
- **相对 L2 范数保真度**：$\mathbf{99.1901\%} \ge 99.0\%$
- **皮尔逊相关系数**：$r = 0.9271$

---

## 4. 实战指导意义
小波多尺度分析清晰证明：40 pkts/4ms 的均匀漏桶流几乎不含任何高频谐波分量，因而与背景流的高频脉冲发生跨尺度正交隔离，彻底避免了缓冲区瞬态共振。这正是 Shot 1 斩获 122.0463s（全国第 5）的频域本质。
