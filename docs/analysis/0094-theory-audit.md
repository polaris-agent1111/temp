## 六、给 11/08 的执行建议（决策树表述）

1. **骨架保留**：A 序列（pert → crown → micro → 分支 → 重复）与 D 自适应的期望差 ≈7pp P(top1)；若夜间控制器可即时改投（11/07 已证明可 34 秒切换），**建议升级为 D 式：首发投 anchor 或 crown40 中后验最宽者作探针，出分 <126 则同构续投，否则切换下一候选**；若维持人工定稿序列，A 骨架可接受。
2. **两处必须修正**：
   - 分支 A「40x3-38-37-36」**无本地样本**（NO_LOCAL_SAMPLE）→ 替换为 platform（40-40-37-37，n=10/CV 4.0%）或 crown40；
   - 「闪点 40-40-38-36」n=2（LOW_N+HIGH_CV）**禁投**；其 114.29 极值不构成证据。
3. **第五发预期管理**：同构复测的功能是采集复测方差（现实 |Δ|/√2≈10.7s），不是「保住 124.37」（P(复现)=21.9%）；若按 D 策略，第五发应投「当日出分最低构型」以利用其 θ 后验。
4. **口径纪律**：对外与对内陈述都用均值图中心预期（皇冠官方预期 138.0±9.5s）+「运气尾部」两段式；**不得用 116.5s 作为规划基线**（与 AGENTS.md「本地单场最小值不是官方预期」同源）。
5. **当晚闭环**：每发出分后按 §五.1 的共轭更新回灌 θ 后验（脚本已实现），后两发的选择依据更新后的 P(top1) 贡献最大者。
