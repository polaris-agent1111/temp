# 0165 理论审计：多轮评测均值下样本方差收敛速率的霍夫丁不等式与切比雪夫不等式界定

## 1. 非渐近概率集中不等式
在官方多轮重复取平均复测环境下（设复测轮次 $n=10$），为严格评估样本均值偏离真实均值大于 $\epsilon$ 的概率上界，建立非渐近集中界限：
- **切比雪夫不等式界**：
  $$P(|\bar{X} - \mu| \ge \epsilon) \le \frac{\sigma^2}{n \epsilon^2}$$
- **霍夫丁不等式界（有界支撑 $[a, b]$）**：
  $$P(|\bar{X} - \mu| \ge \epsilon) \le 2 \exp\left( -\frac{2 n \epsilon^2}{(b - a)^2} \right)$$
