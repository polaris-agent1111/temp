# 0185 理论审计：连续六次下载非对称梯形泄露率消融实验数据挖掘

## 1. 梯形泄露率边际增益分解
Crown Fusion 方案（`41x2-40-37-36x2`）在 6 个不同大小的下载阶段（10M, 10M, 20M, 20M, 30M, 50M）展现出非对称梯形加速特征：
- **前段加速（bins 1~3: 41, 41, 40 pkts/4ms）**：
  - 累计贡献总加速时延收益的 **89.14%**（分别贡献 24.49%、24.49%、40.16%）；
  - 充分利用了连接建立初期的空闲网络缓存，实现零排队极限喷发；
- **后段排空（bins 4~6: 37, 36, 36 pkts/4ms）**：
  - 在大文件传输（30MB与50MB）阶段将速率收拢至链路额定排空线（36 pkts/4ms = 9.0 pkts/ms $\approx 100\text{ Mbps}$）；
  - 消除持续排队积压，彻底规避了 drop-tail 溢出与重传雪崩。

## 2. 结论
消融实验以确凿数据证明：“前段激进加速以掠夺时间、后段平稳排空以固化安全”是非对称设计的精髓所在。
