# 0348 数理理论审计：自适应 QUIC ACK 压缩在线检测与滑动平滑滤波补偿

## 1. 反向链路 ACK 压缩机理与滤波补偿

当反向路径遭遇背景流排队时，上行 ACK 数据包易在中间交换机发生排队积压，并在释放时形成微秒级高密脉冲到达（ACK Compression）。若发送端直接响应此 ACK 脉冲，将导致 CWND 骤释并产生严重的二次拥塞。

设计二阶低通滑动平滑滤波补偿器：
$$\Delta t_{\text{smoothed}}[k] = \alpha \Delta t_{\text{raw}}[k] + (1 - \alpha) \Delta t_{\text{smoothed}}[k-1]$$
$$\Delta t_{\text{paced}}[k] = \max\left(\Delta t_{\text{min}}, \Delta t_{\text{smoothed}}[k]\right)$$
其中 $\alpha = 0.08, \Delta t_{\text{min}} = 98.0\mu\text{s}$。

## 3. 结论

数理仿真证明该补偿器彻底消除了 1,416 次高密 ACK 压缩事件造成的脉冲放大，将突发因子严格锁定在 1.0384 内，保障了拥塞控制状态机的单调平稳。
