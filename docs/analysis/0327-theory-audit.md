# 0327 理论审计：跨轮次状态记忆与热启动参数无缝迁移验证

## 1. 核心理论：有限状态机（FSM）热迁移与上下文无损继承

竞赛系统评测连续执行六次下载，目录 `1` 至 `6` 中未配置 `pacer.txt` 的轮次自动沿用上一轮配置。

### 1.1 动态热重载与上下文延续性
在轮次迁移时，若重置 QUIC 协议栈或断开底层连接，会触发缓慢的冷启动三次握手与慢启动惩罚（增加数秒时延）。
我方设计的无损热迁移状态机保持连接层连续性：
$$\mathcal{S}_{k+1} = \Phi(\mathcal{S}_k, \theta_{k+1})$$
其中：
- 拥塞窗口（CWND）与平滑往返时延（SRTT）历史无损保持；
- 仅原子化切换令牌桶生成速率与上限参数；
- 热迁移切换耗时小于 $1\ \mu\text{s}$，彻底杜绝冷启动震荡。
