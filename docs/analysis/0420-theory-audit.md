## 2. 数理推导：二阶共轭梯度与正定二次型收敛

### 2.1 多尺度势函数加权优化目标
设多尺度漂移权重向量为 $w = [w_1, w_2, w_3]^T$（分别对应 $1\mu$s 微突发、10ms 调度时钟、20s 宏观下载尺度）。
重加权目标函数表示为对称正定二次型：
$$\min_{w} \mathcal{J}(w) = \frac{1}{2} w^T H w - b^T w$$
其中 Hessian 矩阵 $H \in \mathbb{R}^{3 \times 3}$ 表征不同尺度之间的交叉相关漂移方差。

### 2.2 共轭方向构造与 Krylov 子空间收敛
共轭梯度法在第 $k$ 步构造关于 $H$ 相互正交的搜索方向 $d_k$：
$$d_k^T H d_j = 0, \quad \forall j < k$$
更新步长与共轭参数：
$$\alpha_k = \frac{g_k^T g_k}{d_k^T H d_k}, \quad \beta_k = \frac{g_{k+1}^T (g_{k+1} - g_k)}{g_k^T g_k}$$
由共轭梯度收敛定理，对于 $n$ 维正定二次问题，共轭梯度法在精确算术下**至多 $n$ 步严格收敛**至全局唯一极小值：
$$k^* \le \text{dim}(w) = 3$$

### 2.3 性能对比与加速比

- **势函数单调性**：迭代过程无回弹、无超调，单调下降率 **100.00%**。
