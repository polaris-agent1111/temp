## 一句话结论

**香农/BDP 管道物理认证的下界是 50.4–51.0s，不是 105.592s——「105.592s 绝对不可超越」作为物理定理不成立**：同一构造法（分文件极小值复合）在 11-06 n≈280 快照给出 105.592/106.597s，在 11-07 n=405 快照已漂移到 **96.113/94.019s**（一天 −9.5/−12.6s）。105.592s 的正确身份是 **n 依赖的跨构型 min-of-mins 序统计量**（六段极值来自六个不同构型家族，±1% 邻域联合概率 3.3×10⁻¹⁴，405 场实测「六段同时进 ±5% 邻域」命中 0 次），只能作诊断书挡；其单构型可达性物理条件（同参同时支撑冲锋 60.3 Mbps 与稳态 44.1 Mbps、0085 剪刀差不触发、全程巨流不压顶）在现役参数空间内不成立。真正可写进答辩的物理不变量是：逐段管道下界 Σ(L_i/C+35ms)=50.61s、份额机制 s_own∈(0,1) 由平台固定背景需求（≈C）与我方节奏共同决定、以及官方「重复多次取平均」口径下的均值语义。

## 一、数据链重算：105.592s 的身份鉴定

105.592s 出自 0041 报告（11-06 20:06 快照）：`min-run(1~4.bin 小计 19.907s) + min 5.bin 27.651s + min 6.bin 58.034s`；发布版 106.597s（同日 19:46）用的是 `Σ 六个分文件各自极小值`（1-4 段 20.912s）。两者都是**跨场次取极小的复合量**，仅取法粒度不同。

## 二、香农信道容量映射：认证的是 50.4s，不是 105.592s

1. **香农层（无条件认证）**。评测瓶颈是确定性比特管道 C=100 Mbps（汇聚链路 s1–s2，官方拓扑）。任何策略的净荷 goodput ≤ C，故
   T ≥ D/C = 5.040 Gbit ÷ 100 Mbps = **50.4 s**（份额 s=1、零损、零背景的幻想极限）。
   Shannon 定理在此的角色是存在性背书：底层物理信道必须具备 ≥100 Mbps 容量，该管道才存在（平台已固定）。背景查询流是**干扰用户而非噪声**，其挤压量是排队/博弈结果量——物理只认证 s_own ≤ 1，**不认证任何更高的下界**。
2. **BDP 管道层**。BDP = C·RTT = 875 KB = 729.2 pkt（1200B 净荷）。慢启动窗口爬坡 log2(729/IW)·RTT ≈ 316–433 ms（IW=32/10），对最小文件（10MB = 11.4×BDP）被 L_i/C 完全吸收，不构成额外下界项。
3. **逐段认证下界**。T_i ≥ L_i/C + τ_1w（末字节单向传播 35 ms；官方口径剔除任务间隙，0088）：

   | bin | L_i/C | +35ms | 官方实测极小值 | 结构余量 |
   |---|---:|---:|---:|---:|
   | 1.bin | 0.800 | 0.835 | 1.372 | 0.537 |
   | 2.bin | 1.600 | 1.635 | 2.385 | 0.750 |
   | 3.bin | 3.200 | 3.235 | 4.602 | 1.367 |
   | 4.bin | 6.400 | 6.435 | 9.043 | 2.608 |
   | 5.bin | 12.800 | 12.835 | 21.327 | 8.492 |
   | 6.bin | 25.600 | 25.635 | 55.290 | 29.655 |
   | **Σ** | 50.400 | **50.610** | — | — |

   加上握手计入与否的分叉（6×1-RTT = +0.42s），**认证下界带 T* ∈ [50.4, 51.0]s**。veth 路径固定税仅 ~3µs 与瓶颈串行（0082），可忽略；G=4000µs 定时器量子化的相位滞后 ≤G/2 每 refill 批，被速率项吸收。

## 三、份额反演与最恶劣工况对照

把各信封倒算成对我方**持续份额**的需求（s* = 50.4/T）：

| 目标 T (s) | 所需 s* | 性质 |
|---:|---:|---|
| 124.368 | 0.4052C | 我方官方最好（11/07 Shot2） |
| 117.026 | 0.4307C | 榜单第一（光明未来） |
| 109.465 | 0.4604C | 历史最佳单场 total（本地实测） |
| 106.597 | 0.4728C | 冻结信封（n≈280） |
| **105.592** | **0.4773C** | **任务对象（n≈280）** |
| 96.113 | 0.5244C | 同构造 n=405 |
| 94.019 | 0.5361C | Σ 分文件极小值 n=405 |
| 50.610 | 0.9959C | 认证下界 |

冠军开环构型（g=9000 pkt/s）在**永久非响应饱和（ρ=1）**下的份额天花板 r_own = μ·g/(g+ρμ) = 0.4635C（0086 闭式）：105.592 所需 0.4773C > 0.4635C，**在最恶劣饱和工况下不可达**。但实测逐段极值达 0.46–0.71C（上表），说明真实背景是弹性的、N~Poisson(1) 存在空窗——份额上限不是常数，因此「饱和不可达」只是**一个工况的反证**，不是全域判决。

## 四、单构型可达性物理条件清单（任务核心交付）

单构型单场打穿 105.592s 必须同时满足：

1. **冲锋与稳态同参**：1–4.bin 段 ≥60.3 Mbps 均值（burst≈60 弹性、依赖背景空窗）、5.bin ≥46.3 Mbps、6.bin ≥44.1 Mbps，且由**同一份 pacer 参数**全程支撑；
2. **剪刀差不触发**（0085 柯氏突发惩罚律）：冲锋节奏 batch 40/60 在 5/6.bin 的尾部丢包为 4.51%/36.3%——冲锋最优与稳态最优的参数区不相交，这正是六个分段极值分属六个构型家族的机理；
3. **巨流不压顶**：六段连续 ~96–106s 内不遭遇 ≥28MB 背景巨流（0086：6.bin 窗口命中率 ~74%，指望全程躲开不现实）；
4. **联合概率**：六段各自进入当前极小值 ±1% 邻域的经验频率 0.25–1.0%，独立近似联合 3.3×10⁻¹⁴；405 场实测「六段同时进 ±5% 邻域」命中 **0** 次。

**判决**：在现役参数空间内，105.592s 的单构型可达性物理条件**不成立**；它不是官方出分抽样分布的支撑点（与 0052 §五对 106.597 的论证一致，且 105.592 更激进）。

## 五、分层认证链与最终判决

| 层级 | 量 | 性质 | 认证强度 |
|---|---:|---|---|
| L-2 香农/管道 | 50.4s | 物理恒等式 D/C | **无条件**（幻想份额 s=1） |
| L-1 结构层 | 50.61s（+握手 51.03s） | 管道+传播+BDP+量子化 | **无条件**（平台口径内） |
| L0 冻结信封 | 105.592 / 106.597s | 跨构型 min-of-mins 序统计量 | n=280 时刻经验值，**非物理** |
| L0′ 当前信封 | 96.113 / 94.019s | 同构造 n=405 | 随 n 漂移，无不变性 |
| L1 单场极值 | 109.465s | 历史最佳单场 | 经验支撑点（min-of-N 红利口径） |
| L2 官方锚 | 124.3683s（我方）/ 117.0257s（榜首） | 官方均值化出分 | 决策的真实工作点 |

1. 「以香农信道容量与 BDP 管道物理极限验证 105.592s 的绝对不可超越性」——**该命题按字面不成立**：香农/BDP 认证的是 50.4–51.0s；105.592s 是序统计量，且同构造法已随 n 漂移至 94.0/96.1s，比 105.592 更低。
2. 105.592/106.597 的合规用法：**诊断书挡**（对标上限的参照系），不得作为提交目标、预期管理或宣传口径——AGENTS.md 明令禁止 min-of-N/极值红利，官方 top 统一复测取**平均**，与该口径直接冲突。
3. 若需要「绝对不可超越」的严谨表述，正确对象是 L-1 结构层：**在官方剔除任务间隙的口径下，任何构型的六文件总耗时 T ≥ Σ(L_i/C + 35ms) = 50.61s**；若计握手则 51.03s。这不是 105.592，也不会被任何参数创新绕过。
4. 答辩口径建议：把「物理抗抖动」叙事锚定在**认证下界带 + 份额机制**（s_own ∈ (0,1) 由平台固定背景需求 ≈C 与我方节奏共同决定），而非锚定在会随 n 漂移的经验信封上。

## 六、局限

- 本地与官方环境同构性依赖 0013 结论（官方 133s ≈ 本地）；本地极小值不含官方复测噪声，外推到官方口径需经 0084 校准图（官方 ≈ 本地均值 +2.5±7.4s）。
- 慢启动爬坡采用 IW∈{10,32} 区间与 RTT 级粒度；官方客户端 IW 不可知，不影响 L_i/C 主导结论。
- 背景弹性（响应式 vs 非响应）在 0086 已按族条件化；本审计的份额反演只依赖实测锚点，不依赖该分类。
- bootstrap 独立近似忽略了段间相关（同场六段正相关，真实联合概率高于独立近似）——即便如此也只有 1e-14 量级，结论方向不受影响。
