# 任务 0396 理论审计：大规模跨流竞争环境下的排队网络 Jackson 定理极限承载力分析

## 1. 任务背景与核心目标
在大型网络拓扑中，流量从客户端发送端出发，经过多级交换节点、核心瓶颈交换机并交织背景流，构成典型的多级串联/并联排队网络。
若网络内任意单个节点的到达率超过其服务率（$\rho_i \ge 1.0$），该节点积压将以 $\mathcal{O}(t)$ 线性发散，诱发全链路雪崩式丢包。
本任务应用排队论经典杰克逊网络定理（Jackson's Queueing Network Theorem），求解流量平衡方程与稳态乘积解，精确标定网络极限承载容量。

- **核心门禁要求**：
  1. 全网各级交换节点极限承载通过率（全域 $\rho_i < 1.0$）$= 100.0\%$；
  2. 杰克逊定理乘积态（Product-Form）解析解形式一致性 $= 100.0\%$。

## 2. 杰克逊排队网络理论模型推导

### 2.1 拓扑矩阵与流量平衡方程
设网络由 $M = 4$ 个关键节点组成：
- 节点 0: Ingress Edge Switch
- 节点 1: Core Bottleneck Switch
- 节点 2: Cross-Traffic Merging Switch
- 节点 3: Egress Edge Router

转移概率矩阵 $P \in \mathbb{R}^{4 \times 4}$ 描述包在节点间的转发转移概率。设外部到达率向量为 $\gamma = (\gamma_0, \gamma_1, \gamma_2, \gamma_3)^T$。
各节点的总包到达率 $\lambda_i$ 满足杰克逊流量守恒代数方程：
$$
\lambda_i = \gamma_i + \sum_{j=0}^{M-1} \lambda_j P_{ji} \implies (I - P^T) \lambda = \gamma
$$
当 $I - P^T$ 可逆时，解唯一存在且解析可求：
$$
\lambda^* = (I - P^T)^{-1} \gamma
$$

### 2.2 乘积解定理（Product-Form Theorem）
若各节点服务率 $\mu_i$ 满足 $\lambda_i^* < \mu_i$（即节点服务利用率 $\rho_i = \frac{\lambda_i^*}{\mu_i} < 1$），则系统稳态联合排队长度概率分布呈现完美的边际独立乘积解形式：
$$
\pi(n_0, n_1, n_2, n_3) = \prod_{i=0}^3 (1 - \rho_i) \rho_i^{n_i}
$$
这表明各节点队列在稳态统计意义下彼此解耦，互不干扰，不存在高阶交叉排队雪崩效应。
