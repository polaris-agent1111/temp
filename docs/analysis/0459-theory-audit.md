# 0459 理论审计 — 多源异构流竞争下的有限长块编码正反向传输界

## 1. 理论背景与有限块长信息论 (FBLC)
经典香农信息论假设编码块长 $n \to \infty$，因而在实际高速网络（QUIC 拥塞窗口通常受限在 $n \in [50, 1600]$ 个数据包内）高估了真实可达信道容量。
引入 Polyanskiy-Poor-Verdú (PPV) 有限长块编码界（Normal Approximation）：
$$R^*(n, \epsilon) = C - \sqrt{\frac{V}{n}} Q^{-1}(\epsilon) + \frac{1}{2n} \log_2 n + O\left(\frac{1}{n}\right)$$
- **香农容量 $C$**：$C = \frac{1}{2} \log_2(1 + \text{SNR})$；
- **信道分散度 (Channel Dispersion) $V$**：
  $$V = \frac{\text{SNR}(\text{SNR} + 2)}{2 (1 + \text{SNR})^2} (\log_2 e)^2 > 0$$
  严格为正定标量，表征有限块长约束带来的速率统计波动方差。

## 2. 正向可达界与逆向元逆界紧致性
- **回退损耗量化**：在错误率 $\epsilon = 10^{-3}$ 下，当块长 $n=100$ 包时，实际最大传输速率为 1.7558 bits，相比香农无限长极限（2.0373 bits）存在 **13.82%** 的物理必要回退；
- **PPV 展开紧致性**：在 $n \ge 800$ 的平稳传输段，可达界与逆向界的半带宽残差仅 **0.006027**（指标要求 $< 0.01$，合格）；
- **信道分散度正定率**：**100.0%**；
- **工程应用价值**：严格解释了为何在短流（如 1.bin、2.bin）阶段不能盲目压满香农物理线速，必须为有限块长统计波动预留约 10%~14% 的信道分散度空间。
