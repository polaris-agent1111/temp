## 一、机制与记号

官方评测：每次提交在官方评测机**重复 3 次取平均**记为出分 $S$；排行榜取各队最好成绩；官方公平性条款明确「**排行榜 top 提交将统一复测，防止针对特定随机种子的过拟合**」。设某构型的出分（3 次平均）分布为 $\mathcal{D}(\mu,\sigma)$，则 $n$ 次独立复测平均的标准误 $SE=\sigma/\sqrt{n}$，单侧 95% 置信区间上界 $=\bar S+1.645\,SE$。

## 五、复测风险的双向性（对我方 124.3683 的具体含义）

统一复测若作用于我们的 top 成绩，新出分是 $\mathcal{D}(\mu,\sigma)$ 的抽取（或 3 次平均）：
- **下行风险**：σ=10.7 时 P(单次 >124.37)=50%、P(3avg >133.086)≈7.9%——纪录可能被复测回吐到 133+；
- **上行机会**（同一枚硬币）：σ=10.7 时 P(单次 <119.83)=66.4%、P(单次 <112.3)≈26%——**高方差同样是登顶的机制**（这也改写了 0052 的结论域，见 §六）；
- **策略含义**：σ 大时「5 发额度」的价值剧增（多抽极值），σ 小时价值收敛于 μ−0.8s——**σ_eval 的定价是额度分配策略的第一输入**，优先级高于新构型探索。

## 六、对 0052（EVT）结论域的修正记录（side-effect）

## 七、合规路线图（让命题「变为可证」的最短路径）

1. **σ 定价（最便宜、最高优先）**：对纪录构型 `leak 40/40×3+36/36×3` 再投 2 次同配置（合计 n=3）——同时完成 μ 定位与 σ_eval 收窄；若两发出分再次出现 >10s 级散布，则 σ=10.7 世界坐实。

## 附：复算脚本

```python
import math
Phi=lambda z:0.5*(1+math.erf(z/math.sqrt(2)))
obs=124.3683; target=119.8293
for sig in (0.7,1.44,3.0,6.0,10.70):
    se=sig/math.sqrt(3)
    print(sig, round(obs+1.645*se,1),                       # CI95 upper (n=3)
          round(1-Phi((133.086-obs)/se),4),                  # P(3avg>133.086)
          round(Phi((target-obs)/sig),3),                    # P(single<target)
          round(target-1.645*se,2))                          # required mu
```
