# 0328 理论审计：浅队列多租户竞争环境下的公平性与吞吐权衡

## 1. 核心理论：微观平滑整形与 AIMD 突发流挤出效应

在物理交换机仅有 $B = 10\text{ packets}$ 的极浅尾部丢包队列（DropTail Queue）中，传统基于丢包反馈的 AIMD（Additive Increase Multiplicative Decrease）流呈现严重缺陷。

### 1.1 时域错峰与队列占优机制
设 AIMD 流在第 $k$ 轮突发发送 $W_{\text{burst}}$ 个连续数据包：
当队列已有排队包 $Q(t)$ 且 $Q(t) + W_{\text{burst}} > B$ 时，尾部数据包必然发生截断丢包，导致 AIMD 流触发窗口减半退避：
$$W_{\text{burst}} \leftarrow \frac{1}{2} W_{\text{burst}}$$
而我方 **Crown Fusion 混合整形** 将数据包在时域以等间隔 $\Delta t$ 均匀释放，数据包在到达队列时总是恰逢前一个包已由链路服务离开，维持极低排队占位（$Q(t) \le 2$）。
在长期博弈中，AIMD 突发流被动承担了所有溢出丢包，被压制在低窗口状态，而我方平滑流稳健占据瓶颈吞吐的绝大部分（$>90\%$）。
