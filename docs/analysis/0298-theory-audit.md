## 一、模型与引擎

- **物理口径**（单位锚点）：瓶颈 C = 100 Mbps ÷ 1200 B = **10416.67 pkt/s**（p100M 临界档，0085 审计口径）；浅缓冲 **K = 30 包** drop-tail FIFO；仿真时长 60 s（625,000 个服务槽）。
- **引擎**：时步化 dt = 1/C，逐槽「各流轮转顺序产生到达 → 入队（溢出即丢）→ 服务 1 包」，无事件堆调度偏置。v1 事件堆版本曾出现同构流 71% vs 0% 的非对称伪影（heap 序数 tie-breaking 偏置），已弃用并以时步化引擎重跑，同构单元恢复对称。
- **流形态**：steady（我方匀速漏桶发射）、pulsed（k 包连续脉冲）、aimd（窗口自适应，丢包减半/无丢包加一）。

## 四、机理结论

1. **自然挤出效应的方向性得到证实但强度有限**：所有饱和场景中 amplification_S > 1 > amplification_B（R2: 1.0166 vs 0.9791；R4: 1.0028 vs 0.98/1.00）——被挤出的是脉冲/AIMD 租户而非定步长流；但 FIFO drop-tail 在慢性过载下**不能**把定步长流的丢失隔离到 0（R2 中 S 被动丢失 13.1%），「挤出」保护的是份额结构而非丢包豁免。
2. **共存域（总 offered ≤ C）是唯一安全域**：R1 中双方几乎零丢失且份额=发包份额；一旦对手无响应超发（R2, 117%），全员受损，份额优势仅剩 ~1.7pp。
3. **AIMD 型竞争者自我约束反而保护我方**：R3/R4 中 AIMD 窗口在浅缓冲内自限（对端拿到剩余或更少），S 占有率 65.3–69.6%、丢失 ≤0.64%；被挤到 amp<1 的是 AIMD 租户自身（R4 各 ~10%、丢失 1–3%）。
4. **纳什均衡结构**（双方 offered=4500 等额博弈）：
   - k=40 温和脉冲（邻域扰动）：**匀速为严格稳健最优响应，唯一纯策略 NE = (匀速, 匀速)**。
   - k=100 大脉冲：出现反协调双 NE（(匀速,匀速) 与 (脉冲,脉冲)）；(脉冲,脉冲) 的零丢失是**完美相位互补的脆弱临界产物**（线速率脉冲恰好填满服务槽、对方静默）——确定性无抖动模型的边界产物，任何相位抖动即破坏；k=40 邻域下即消失。这与 AGENTS「只投平台点不投尖点」纪律同构。
5. 与 0085「Kolmogorov 突发惩罚定律」（batch 1/40/60 → 尾部丢失 0.157%/4.51%/36.3%）方向一致：脉冲规模在浅缓冲区自毁，流级仿真复现了该定律的竞争版。

## 五、局限

- 确定性无抖动模型：真实网络的相位抖动会侵蚀 (脉冲,脉冲) 的 TDM 互补临界，但不影响 R1/R3/R4 的共存结论方向。
- 单瓶颈拓扑、无重传/超时反馈建模（AIMD 仅按窗口丢包反馈）；RTT 取固定基值 10/13 ms。
- 官方背景流按 1500 pkt/s 匀速近似（真实背景流形态由平台固定，未探测）。
- 占有率 ≥65% 的成立域依赖我方自身速率选择（r_S ≥ 0.65·C_used），属「自定步长防御」而非对对手的利用；不构成对他队流量的干预手段，合规无虞（纯离线模型）。
