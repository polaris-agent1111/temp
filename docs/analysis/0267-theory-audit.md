# Task 0267 理论审计报告：帕累托最优前沿离散邻域鲁棒扰动验证

## 1. 审计背景与反过拟合准则
根据竞赛反过拟合纪律《测量口径与反过拟合纪律》与《`docs/analysis/overfitting-and-selection.md`》：
- 官方评测采取“重复多次取平均，更新排行榜”及“Top 提交统一复测防止特定种子过拟合”；
- 候选配置必须满足“邻域稳定”准则：对关键参数进行 $\pm 1$ 包扰动，性能不应出现断崖式恶化；**严禁投递孤立的尖点配置，必须投递平坦的平台点**。

## 2. 离散扰动网格设计
基线配置：Crown Fusion 6 阶段速率向量 $\mathbf{r}^* = [41, 41, 41, 37, 36, 36]$（pkts/tick）。
1. **一维正交扰动（12 方向）**：各阶段分别施加 $\Delta r_i \in \{-1, +1\}$ 单变量扰动；
2. **全组合张量网格（$3^6 = 729$ 点）**：在各阶段同时施加 $\boldsymbol{\Delta r} \in \{-1, 0, 1\}^6$，穷举全空间超立方体。

门禁要求：
- 一维单变量扰动最大时延波动 $\max_i |\Delta T_i| \le 0.80\text{s}$；
- 一维单变量扰动平均时延波动 $\le 0.40\text{s}$。
