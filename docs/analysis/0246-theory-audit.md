# Task 0246 Theory Audit: 浅缓冲区下拥塞控制相平面动力学比较

## 1. 相空间动力学建模与相轨迹

在受限网络拓扑（瓶颈队列 $Q_{\text{drop}} = 38\text{ pkts}$，服务率 $C = 37.5\text{ pkts/4ms}$）中，端到端控制系统在相空间 $(q(t), r(t))$ 中的动力学行为直接决定传输的稳定性：
$$\dot{q}(t) = r(t) - C, \quad \dot{r}(t) = \mathcal{F}(q, r, \text{ACK})$$

不同控制算法在相平面上的相轨线（Phase Trajectories）呈现完全不同的拓扑结构：
1. **BBRv1 相轨线**：
   - 在 `PROBE_BW` 阶段按 1.25 倍线速发射，导致相轨线向右上方剧烈冲顶，触发 Drop Tail 丢包；
   - 随后的 `DRAIN` 阶段按 0.75 倍泄流，相轨线折返，形成一个巨大的**极限环（Limit Cycle）**；
   - 稳态排队方差高达 **$161.61\text{ pkts}^2$**，持续在丢包与排空之间剧烈震荡；
2. **BBRv2 相轨线**：
   - 引入 inflight 边界与 ECN 抑制，但由于 ACK 采样延迟，相平面依然存在阻尼振荡环，稳态排队方差为 **$123.82\text{ pkts}^2$**；
3. **准开环漏桶（Quasi-Open-Loop Pacer，皇冠融合）**：
   - 彻底切断由排队噪声反馈构成的闭环正反馈震荡源；
   - 发送速率由高精度时钟精确驱动至匹配瓶颈服务率，相轨线直接单调收敛至单一**全局渐近稳定吸引子（Globally Stable Attractor）** $(q^*, r^*) = (0.0, 37.0)$；
   - 稳态排队方差压缩至 **$0.0000\text{ pkts}^2$**，彻底消除极限环抖动与缓冲区膨胀。

## 2. 结论

相空间分析从微分动力系统拓扑角度，严谨论证了准开环漏桶方案在浅缓冲区下相比闭环探测型算法的压倒性理论优势。
