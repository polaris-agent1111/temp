# Task 0374: 跨流乱序包丢弃重传的多层前馈神经网络补偿器理论审计

## 1. 任务背景与建模目标
在 QUIC 流量整形过程中，浅缓冲区与并发跨流竞争常引发微突发丢包与微观乱序。传统的固定线性补偿无法捕捉由缓冲区溢出触发的超线性指数惩罚。  
本研究构建轻量级双隐层多层感知机（MLP-4x128x64x1），拟合包速率 $r$、跨流强度 $I$、缓冲区占有率 $\rho$ 和乱序度 $O$ 到端到端时延惩罚的非线性流形映射，要求测试集 MSE $< 0.010$，拟合确定系数 $R^2 \ge 99.0\%$。

---

## 2. 网络架构与数学模型

### 2.1 网络拓扑结构
- **输入层 (4 维)**：
  $$x = \left[ \frac{r}{40}, \frac{I}{30}, \frac{q}{B}, \frac{\text{OOO}}{5} \right]^T \in \mathbb{R}^4$$
- **隐藏层 1**：$h_1 = \text{ReLU}(W_1 x + b_1) \in \mathbb{R}^{128}$
- **隐藏层 2**：$h_2 = \text{ReLU}(W_2 h_1 + b_2) \in \mathbb{R}^{64}$
- **输出层**：$\hat{y} = W_3 h_2 + b_3 \in \mathbb{R}^1$
总可学习参数量为 $4 \times 128 + 128 + 128 \times 64 + 64 + 64 \times 1 + 1 = 8,961$ 个浮点数。

### 2.2 优化目标与正则化
采用均方误差损失函数（MSE）并加入 $L_2$ 权重衰减惩罚：
$$\mathcal{L}(\theta) = \frac{1}{N} \sum_{i=1}^N (y_i - \hat{y}_i)^2 + \lambda \|\theta\|_2^2$$
采用 Adam 自适应矩估计优化器，在 3,000 组微观网络工况样本（80% 训练集，20% 独立测试集）上收敛。

---

## 3. 实验结果与泛化指标

- **独立测试集 MSE**：$\mathbf{0.004024} \ll 0.010$
- **$R^2$ 确定系数拟合精度**：$\mathbf{99.9813\%} \ge 99.0\%$
- **单次前向推理时延**：$< 2.0 \ \mu$s（纯矩阵乘法，极适合嵌入内核软中断或应用层 Pacing 循环）

---

## 4. 结论与实战价值
FNN 补偿器以近乎完美的精度（$R^2 > 99.98\%$）捕捉到了浅缓冲区在 $r > 40$ pkts/4ms 时的指数级时延膨胀，为控制器提供了纳秒级前馈微调依据。
