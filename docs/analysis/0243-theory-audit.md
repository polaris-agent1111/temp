## 二、状态构造（两层，明示覆盖边界）

**Layer A（数据态）**：经验分位数态 q ∈ {P25, P50, P75, P90, max}。解释：同一冲击强度（共同分位水平）作用于所有候选，`regret(c,q) = Q_c(q) − min_c' Q_c'(q)`。这是唯一完全由真实样本支撑的状态层。

**Layer B（机制态）**——引用 0085/0086 已审计数字做差分界，不引入新物理假设：

1. **定理1（共模抵消）**：环境态若给所有候选加同一偏移 δ，则 regret 不变、Savage 排序不变。官方-本地同日偏移（0084：同日 +2.5±7.4s；11/06 两次 −7.8/−10.2s）即属共模。
2. **巨流/永久饱和态（0086）**：份额地板 0.464C 对全 leak 候选共模，且三候选 bin5/6 参数完全相同 → 该态差分为零。
3. **阵风态差分（0085 实测梯度外推）**：0085 柯尔莫哥洛夫解给出 70ms 阵风窗累计丢包 leak36=37 pkts、leak40=85 pkts，最坏线性梯度 12 pkts/窗/+1 rate。对差分 bin 施加「每个 70ms 窗都在阵风」的最坏假设：
   - C2 vs C1（bin1,2: 41 vs 40）→ 额外丢包 418 pkts → 时间代价上界 **0.080s**（1200B/pkt、C=12.5MB/s、CC 放大 ≤2）
   - C3 vs C1（bin1: 41 vs 40）→ 139 pkts → **0.027s**
   - C1 vs C1 → 0（基准）

### 考核目标判定（≤ 2.5s）

1. **点估计成立**：Savage 候选 C1 总最大遗憾 1.36s ≤ 2.5s。
2. **强解读不成立**：「任意候选在任意对抗态下 regret ≤ 2.5s」为假——C2/C3 在 P75–max 态遗憾 2.94–5.79s。
3. **抽样不稳健（重要）**：bootstrap（族内重采样 B=10000）下 C1 max-regret P50 = 5.23s、P95 = 10.26s、P(≤2.5s) = 22.3%、95% 区间 [0.00, 10.69]s。根因：本地样本重尾（std 8.4–9.6s，n=15/15/10）。即「≤2.5s」目前是**点估计结论，不是统计结论**——与本项目反过拟合纪律（按均值/中位数选型、不按单场极值）完全一致。
4. **覆盖边界**：官方态矩阵缺失（三棵决选树无任何真实官方出分；11/07 night 5 发为其它构型），「所有极端对抗状态」只能覆盖：本地实证分位态 ∪ 0085 阵风差分态 ∪ 0086 巨流/饱和共模态。官方侧未知调度突变类对抗不在能力范围内，如实声明。

## 四、操作含义（给 Lead）

1. **遗憾意义下的首发 = C1-steady**（1.36s），crown 族（C2）虽均值尾低 1.6s 但尾部遗憾 4.5s——若 11/08 采用遗憾框架，Shot 1 锚定 steady、后续按当发出分切换 crown 的既有计划与此自洽。
2. crown 的 4.47s 遗憾集中在 P75/P90/max 态：它不是「平台点」而是「右尾更重的冲分点」。投 crown 的每一发都应被理解为接受 ~4.5s 级尾部风险换取左尾（122–134s）机会。
3. 不要把「≤2.5s」写进对外承诺：bootstrap 表明它对抽样噪声不稳健；若需收紧，唯一途径是给 C1 增加 n（当前 15）。

## 五、风险与局限

- 分位数态的「共同冲击强度」解释是构造性假设：不同候选的分位数来自不同会话，未做同期配对（数据中不存在同期配对）。
- Layer B 的阵风梯度是 36↔40 两点线性外推到 41，单调但曲率未知；方向上对 C2/C3 不利（偏保守）。
- bootstrap 独立重采样高估了 regret 方差（未含跨候选共同会话效应），P(≤2.5s)=22.3% 应理解为保守下界而非精确概率。
