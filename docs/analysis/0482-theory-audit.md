# 任务 0482 理论审计报告：广义波尔兹曼机 (GBM) 自由能极小化流量平滑热力学平衡

## 1. 理论背景与数学推导
在微秒级网络流量整形中，微突发脉冲表现为离散微观状态 $s = [s_1, \dots, s_N]^T \in \{0, 1\}^N$（$s_i=1$ 表示流 $i$ 在当前微时间槽发包）。
为了平抑浅缓冲区并发竞争，系统哈密顿能量函数定义为：
$$E(s) = -\frac{1}{2} s^T W s - b^T s$$
其中非对角负耦合矩阵 $W_{ij} < 0$ 引入排斥能量势垒（惩罚多个流同时突发抢占浅缓冲区），偏置向量 $b_i$ 驱动各阶段的有效吞吐量需求。

### 吉布斯分布与变分亥姆霍兹自由能
统计物理吉布斯-波尔兹曼系综定义了微观态的概率分布：
$$P(s) = \frac{1}{Z} \exp\left(-\frac{E(s)}{T}\right)$$
引入平均场参数 $m_i = \mathbb{E}[s_i] \in [0, 1]$（宏观平均发包活跃率），系统的变分亥姆霍兹自由能泛函（Helmholtz Free Energy）为：
$$F(m) = U(m) - T S(m) = -\frac{1}{2} m^T W m - b^T m + T \sum_{i=1}^N \left( m_i \ln m_i + (1 - m_i) \ln(1 - m_i) \right)$$
自由能平衡态（$\nabla_m F(m^*) = 0$）等价于平均场自洽不动点方程：
$$m_i^* = \sigma\left( \frac{(W m^*)_i + b_i}{T} \right) = \frac{1}{1 + \exp\left(-\frac{(W m^*)_i + b_i}{T}\right)}$$

### 热力学梯度流与单调耗散定理
沿自由能负梯度演化的连续动力系统：
$$\frac{dm_i}{dt} = -\frac{\partial F}{\partial m_i}$$
由链式法则：
$$\frac{dF}{dt} = \sum_{i=1}^N \frac{\partial F}{\partial m_i} \frac{dm_i}{dt} = -\sum_{i=1}^N \left( \frac{\partial F}{\partial m_i} \right)^2 \le 0$$
严格证明自由能沿时间轨迹单调非增（$\frac{dF}{dt} \le 0$），保证系统无振荡地趋于唯一热力学平滑平衡态。
