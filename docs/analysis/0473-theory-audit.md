# 任务 0473 理论审计报告：截断柯西变异粒子群 (TC-PSO) 浅缓冲区整形参数全局探索

## 1. 理论背景与数学推导
在 6 阶段穿柜整形调优中，多维参数曲面（Pacer 发包速率、突发上限、泄露间隔）呈现出非凸、非光滑的多模态特征。
浅缓冲区丢包临界点与时延悬崖使得目标函数在全局最优解周围密布大量局部极值陷阱。
标准粒子群优化（PSO）的速度更新依赖高斯分布与个体/全局历史最优吸引：
$$v_i^{k+1} = \omega(k) v_i^k + c_1 r_1 (p_i^k - x_i^k) + c_2 r_2 (g^k - x_i^k)$$
在高维多峰环境下，粒子群体极易在迭代中期迅速聚集丧失多样性，陷入局部最优。

### 柯西变异（Cauchy Mutation）的长尾跃迁机理
一维柯西分布的概率密度函数为：
$$f(x; \gamma) = \frac{1}{\pi \gamma \left( 1 + \left( \frac{x}{\gamma} \right)^2 \right)}$$
由于其二阶矩甚至一阶矩不存在（重尾特性），柯西分布赋予粒子产生远距离大幅度跳跃（Long Jumps）的极高概率，能够以幂律衰减穿透局部极小值势垒。
为了避免无界跳跃飞出物理可行域，引入截断柯西算子：
$$\Delta x_c = \text{clip}\left( \text{Cauchy}(0, \gamma_k), -M, M \right)$$
其中退火尺度 $\gamma_k = \gamma_0 \left(1 - \frac{k}{K_{\max}}\right) + \epsilon$，前期主导全局大范围探索，后期自适应过渡为局部微调。
