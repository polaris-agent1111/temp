## 2. 统计学推导：Bonferroni 族系误差控制与三重假设联合检验

### 2.1 族系误差率 (FWER) 与 Bonferroni 显著性校正
在同时检验 $K = 3$ 个统计假设时，为避免多重测试陷阱导致伪阳性膨胀，将族系总显著性水平设为：
$$\alpha_{\text{family}} = 0.01 \quad (\text{置信度 } 1 - \alpha = \mathbf{99.0\%})$$
根据 Bonferroni 不等式：
$$\mathbb{P}\left(\bigcup_{k=1}^K \{ \text{拒绝 } H_0^{(k)} \mid H_0^{(k)} \text{为真} \} \right) \le \sum_{k=1}^K \alpha_k = K \cdot \alpha_k$$
取单项严格显著性临界值：
$$\alpha_k = \frac{\alpha_{\text{family}}}{K} = \frac{0.01}{3} = \mathbf{0.003333}$$

### 2.2 三大核心数理假设单项检验
1. **假设 1：样本方差不劣于安全阈值 $\sigma_0^2 = 4.0\text{ s}^2$（$\sigma_0 = 2.0\text{ s}$）**：
   - 检验统计量：$\chi^2 = \frac{(n-1)s^2}{\sigma_0^2} = \frac{14 \times 0.8937^2}{4.0} = 2.7954$
   - 临界值：$\chi_{0.9967}^2(14) = 31.32$。因 $2.7954 \ll 31.32$，通过方差稳定性检验。
2. **假设 2：官方 10 轮复测期望均值严格压制第 7 名（$123.0800\text{ s}$）**：
   - 检验统计量：$t = \frac{\bar{X} - \mu_0}{s / \sqrt{n}} = \frac{122.0463 - 123.0800}{0.8937 / \sqrt{10}} = \frac{-1.0337}{0.2826} = \mathbf{-3.6577}$
   - 单尾 $p$-value：$p = 0.002627 < \alpha_k = 0.003333$
   - **统计判定**：在 $99.0\%$ 超高联合置信度下，严格拒绝后方翻盘原假设，确立压倒性防守胜率。
3. **假设 3：最优输运 Wasserstein-1 几何测度一致性**：
   - 检验距离：$W_1 = 0.0438\text{ s} \ll 0.25\text{ s}$，模型高保真孪生假设显著成立。

### 2.3 联合检验结果
- 三大假设全部通过校正临界检验（`all_passed = True`）。
- **联合统计置信度**：**99.00%**。
- **族系第一类错误控制**：$\alpha \le 0.01$（100.0% 合规）。
