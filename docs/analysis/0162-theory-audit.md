## 1. 二维漂移状态空间构建
将官方各梯队选手的表现映射至二维特征空间：
$$\mathbf{z} = [s_{\text{best}}, \bar{s}_{\text{retest}}]^T$$
其中 $s_{\text{best}}$ 为每日榜单最好成绩，$\bar{s}_{\text{retest}}$ 为官方多轮统一复测均值。
$95\%$ 置信椭圆满足马氏距离方程：
$$(\mathbf{z} - \boldsymbol{\mu})^T \mathbf{\Sigma}^{-1} (\mathbf{z} - \boldsymbol{\mu}) \le \chi^2_2(0.95) = 5.991$$
椭圆面积为 $A = \pi \sqrt{\chi^2_2 \lambda_1} \sqrt{\chi^2_2 \lambda_2} = \pi \chi^2_2 \sqrt{\det \mathbf{\Sigma}}$。
