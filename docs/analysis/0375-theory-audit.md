> v2 修订说明：v1（2026-11-08 02:42 并行执行者草稿）的推导主体正确，但含两处不实叙述（「控制器 Shot 2 实测 124.66s 逃逸」关联、把有限样本 100% 说成定理）与一处术语误用（克拉默斯公式用于零势垒）。v2 原地更正，数值结论未变。

## 1. 模型定义与适用范围

考虑过阻尼朗之万 SDE（Euler–Maruyama，dt=0.01，β⁻¹=0.08）：

$$d\mathbf{x}_t = - \nabla U(\mathbf{x}_t)\,dt + \sqrt{2 \beta^{-1}}\, d\mathbf{W}_t$$

势能取 stylized 2D 双阱（对称耦合）：

$$U(x_1,x_2) = \tfrac{1}{4}(x_1^2-1)^2 + \tfrac12 x_2^2 - 0.2\,x_1 x_2$$

- 鞍点在原点，海森 $H=\begin{pmatrix}-1&-0.2\\-0.2&1\end{pmatrix}$，特征值 $\lambda=\pm\sqrt{1.04}\approx\pm1.0198$（零势垒鞍点，ΔU=0）。
- 两个等深极小值位于 $(\pm\sqrt{1.04},\ \pm0.204)$，「黄金盆地」指其一；**该势形是对真实六轮次目标函数的类比，不是其本身**。

## 2. 渐近逃逸定理（以概率 1，t→∞）

沿不稳定方向线性化 $y_t = v_{\min}^\top(\mathbf{x}_t-\mathbf{x}_s)$ 得反向 OU 过程 $dy_t = |\lambda_{\min}|\,y_t\,dt + \sqrt{2\beta^{-1}}\,dW_t$，其解与二阶矩为

$$y_t = y_0 e^{|\lambda|t} + \sqrt{2\beta^{-1}}\int_0^t e^{|\lambda|(t-s)}dW_s,\qquad
\mathbb{E}[y_t^2] = y_0^2 e^{2|\lambda|t} + \frac{\beta^{-1}}{|\lambda|}\left(e^{2|\lambda|t}-1\right) \xrightarrow{t\to\infty}\infty$$

（v2 复核：σ²=2β⁻¹ 代入 OU 方差公式 σ²(e^{2|λ|t}−1)/(2|λ|) 恰得上式，v1 该式无误。）因此任意正温度下鞍点邻域**渐近以概率 1 被逃离**。注意：这是 t→∞ 的结论，**有限时间逃逸概率严格小于 1**；下表给出有限时间严格界。

## 3. 逃逸时间尺度与收敛时间下界

**时间尺度（估计量，非精确 MFPT）。** 零势垒鞍点的逃逸由噪声地板 √(β⁻¹/|λ|) 沿不稳定流形的失控主导：

$$\tau \sim \frac{1}{|\lambda|}\ln\frac{R}{\sqrt{\beta^{-1}/|\lambda|}} = \mathcal{O}\!\left(\frac{\ln(1/\epsilon)}{|\lambda|}\right)$$

代入 R=0.6、|λ|=1.0198、β⁻¹=0.08 得 τ≈0.75，与实测均值 1.0917 同阶（比值 1.46，差异来自全非线性动力学与离散化）。**这不是经典克拉默斯 exp(ΔU/β⁻¹) 公式**——ΔU=0 时克拉默斯速率退化为 |λ|/2π，与上式是两个不同量。

**严格下界（有限时间，v2 新增）。** 记 τ_R 为首达半径 R 时间，M_t 为解中的中心化高斯鞅，Var M_t = v(t)=(β⁻¹/|λ|)(e^{2|λ|t}−1)。当 ε·e^{|λ|t} < R/2（ε 为初始 5σ 包络）时，漂移项不足以单独出圈，故

$$\mathbb{P}(\tau_R < t) \;\le\; \mathbb{P}\!\left(\sup_{s\le t}|M_s|\ge \tfrac{R}{2}\right) \;=\; 4\left(1-\Phi\!\left(\frac{R/2}{\sqrt{v(t)}}\right)\right)$$

（DDS 时间变换把 sup 归到方差时刻的布朗运动，反射原理给单侧 2(1−Φ)；双侧乘 2。）等价地，逃逸概率达到 1−δ 需要

$$t \;\ge\; \frac{1}{2|\lambda|}\ln\!\left(1+\frac{\delta R^2|\lambda|}{8\beta^{-1}}\right)$$

**数值对照**（`verify0375_escape_lower_bound.py`，同种子 1000 轨迹，违反断言即退出非零）：t=0.10/0.20/0.30/0.50 处理论上界 0.0487/0.2625/0.4872/0.8422，经验 CDF 0.0000/0.0020/0.0330/0.1850，全部满足经验 ≤ 上界（PASS）。δ=0.5/0.9/0.99 对应 t_min=0.124/0.204/0.221，经验占比 0.000/0.003/0.009，一致。

## 4. 仿真结果与口径

- **逃逸成功率 100.00%（1,000/1,000）是固定种子 20261108 下的有限样本观测**，v2 双次复现逐位一致（均值 1.0917、p99 3.8709 时间单位）。它不是「以概率 1 逃逸」的证明；后者是第 2 节的渐近定理。
- 判定口径：从鞍点 1e-4 微扰球出发，‖x‖>0.6 即记逃逸（两盆地在半径 1.02 处，0.6 位于其前）；两盆地等深，逃逸方向不论。
