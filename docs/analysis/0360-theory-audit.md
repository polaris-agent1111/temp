# 0360 数理理论审计：QUIC 协议栈多流乱序重组缓冲区溢出边界形式化验证

## 1. 乱序重组缓冲区上界形式化定理

设在途数据包上限为 $N_{\text{inflight}} = 50$，乱序延迟服从 Pareto 重尾分布。接收端重组缓冲区深度状态转移方程为：
$$Q_{\text{buf}}[t+1] = \max\left(0, Q_{\text{buf}}[t] + \mathbb{I}(\text{reordered}) - \mathbb{I}(\text{continuous\_drain})\right)$$

**定理（重组缓冲区紧致上界）**：
若发送端 Pacing 发包速率严格满足 $r \le C$，则对于任意有限方差或弱肥尾的排队延迟扰动，重组缓冲区峰值深度 $Q_{\max}$ 严格有界，且：
$$\mathbb{P}(Q_{\max} > B_{\text{cap}}) \equiv 0 \quad (\forall B_{\text{cap}} \ge 256)$$
