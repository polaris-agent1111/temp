## 一、博弈要素定义

| 要素 | 我方下载流（玩家 1） | WebSearch 背景流（玩家 2） |
|---|---|---|
| 策略 | pacing 速率 $x_1\in[0,C]$（pacer.txt 可控） | 到达过程外生（Poisson λ=7.3046/s，流长按官方 CDF） |
| 目标 | 最小化总下载时间（等价最大化有效吞吐） | 官方固定负载（**非理性体，不响应我方策略**） |
| 瓶颈 | $C=12.5$ MB/s（100 Mbps），RTT 70 ms，交换机 drop-tail 队列 $B=40$ 包（48 KB，排空时标 3.84 ms） | |

**关键结构事实**：背景流的字节平均速率 $\lambda E[S] = 12.5$ MB/s $= C$（官方设定即满线速）。因此**速率切分式博弈在结构上不适用**——不存在「双方各拿一块带宽」的稳态可行域使 $x_1$ 达到 96M（$x_1+x_2\le C$ 与 $x_2\to C$ 矛盾）。我方 37–48 Mbps 的有效吞吐来自 **ACK 时钟对包级空隙的填充**（效率系数 $\eta\approx0.44$–0.46，在 86–96M pacing 区间近似常数——本地/官方实测），而非稳态切分。博弈的真正决策维度是：**pacing 贴多近才会在巨流到达瞬间触发队列溢出**。

## 二、任务指定效用形式的显式化

$$U_1(x_1)=\log g(x_1)-\beta\,D_q(x_1,x_2),\qquad g(x_1)=\eta\,x_1\ \text{（有效吞吐，}\eta\text{ 实测定标）}$$

时延项取瞬时过载的队列代价：巨流存在期（时长 $\tau_g=S_g/C$，如 28MB 巨流 $\tau_g=2.24$ s）内，链路被背景占满，我方以 $x_1$ 注入的全部超出量进入队列：$D_q \propto x_1\tau_g/(2C)$（巨流期平均排队），且每秒丢包数 $\propto x_1/C$ 包——超出 48KB 缓冲的部分成为尾部丢弃，触发 QUIC 乘性退避（吞吐乘子 $(1-\ell)$，恢复代价 $\approx$ RTT 量级/次）。

## 三、经典对称 Nash 模型（任务要求的标准形式）及其局限

取标准 M/M/1 型时延 $D_q=1/(C-x_1-x_2)$（仅在 $x_1+x_2<C$ 有限）与对称对数效用：

$$\frac{\partial U_i}{\partial x_i}=\frac{1}{x_i}-\frac{\beta}{(C-x_1-x_2)^2}=0\ \Rightarrow\ \beta x_i=(C-x_1-x_2)^2 .$$

对称均衡 $x_1=x_2=x^*$：令残余 $y=C-2x^*$，则 $\beta(C-y)/2=y^2$，解得

$$y^*=\tfrac{-\beta+\sqrt{\beta^2+8\beta C}}{4},\qquad x^*=\tfrac{C-y^*}{2}<\tfrac{C}{2}.$$

即经典解收敛于**比例公平点附近（略小于 C/2）**，与 β 取值无关地远离 96M。**结论：在对称 Nash 框架内「96M 是均衡」不成立**——该框架隐含双方都是可策反应的理性体，而实际玩家 2 是外生过程且字节平均已占满 C。此节的作用是否定错误命题、防止「编造公式凑结论」。

## 四、正确模型：外生巨流下的阈值贴靠最优响应（96M 的真实位置）

把玩家 2 还原为外生过程，决策问题为我方单边最优响应。设丢失率在阈值 $C-h$ 以上近似线性增长（$h$ 为排空余量）：

$$\ell(x_1)=\ell_0\cdot\frac{(x_1-(C-h))^+}{C-h},\qquad T(x_1)=\frac{V}{\eta x_1\,(1-\ell(x_1))}.$$

一阶条件 $\partial\ln T/\partial x_1=0$：

$$\frac{1}{x_1}=\frac{\ell'(x_1)}{1-\ell(x_1)}\ \Rightarrow\ x_1^*=C-h\ \ (\text{阈值内侧贴靠}).$$

**结构性论证**：
1. $x_1<C-h$ 区间：$\ell\approx0$，$T$ 随 $x_1$ 严格递减 → 任何低于阈值的 pacing 都被支配（还能更快）；
2. $x_1>C-h$ 区间：$\ell'>0$ 且丢包触发乘性退避，$T$ 陡增 → 超阈值被支配；
3. 故最优响应唯一收敛于 **$x_1^*=C-h$（贴阈值）**。

**$h$ 的定标（实测，非第一性推导，如实声明）**：
- 本地 6.bin：96M（12.0 MB/s，$h=0.04C$）→ 58.03–61.53 s；100M（12.5，$h=0$）→ 73.8 s（丢包退避恶化 +27%）；
- 官方 11-07：5.bin precise 12.5e6（100M，Shot 4/5）与 12.25e6（98M，Shot 3）**双双越过阈值** $C-0.04C=12.0$ MB/s → 三发 champ 构型全部 ≥140.0 s；而 leak 40/40（12.0 MB/s，贴阈值）+ 36/36 后段拿下 124.3683 纪录；
- $h\approx4\%\,C=0.5$ MB/s 与缓冲时标一致性：0.5 MB/s 余量在 40 包缓冲上给出 $48\text{KB}/(0.5/8\text{ MB/s})\approx0.77$ s 的吸收余度，覆盖巨流起始的 ACK 反馈空窗（RTT 70 ms）的 ~11 倍，量级自洽。

**Pareto 命题的准确表述**：在前沿 $\{x_1\le C-h\}$ 上，提高 $x_1$ 恒改善我方、仅弱损害背景（外生过程无感知）→ 前沿内部点被 Pareto 支配；$x_1>C-h$ 后双方（我方退避加深、背景排队加深）同时受损 → 被 Pareto 强支配。**因此 $x_1^*=C-h\approx96$ Mbps 是 Pareto 前沿上「我方目标最优点」——即 96M 是 Pareto 最优（在我方效用定义与实测 $h$ 定标下），且是唯一同时满足「不丢包悬崖」与「吞吐边际」的点。** 它不是对称 Nash 均衡（§3 的 C/2），这一区别是本报告的核心诚实结论。

## 六、结论与适用边界

1. **96M 的理论地位**：外生满线速背景 + drop-tail 40 包缓冲 + QUIC 乘性退避下，我方最优响应为**阈值贴靠** $x^*=C-h$，实测 $h\approx4\%\,C$ → **96 Mbps（12.0 MB/s）**。它是 Pareto 前沿的我方端点，非经典对称 Nash 均衡（后者给 C/2，不适用于外生背景）。
2. **可证伪条件**：①若未来实测 97–99M 官方分不劣于 96M 同族对照 → $h$ 更小，阈值需下修重定标；②若 94–95M 显著更优 → η 非常数（ACK 时钟恶化），线性 $g$ 假设失效；③若 leak 42/42（12.6 MB/s，超 C）出分不崩 → 队列模型有误（⚠ 42/42 标称已超 C，按本模型预测受罚，可作判别发）。
3. **适用边界**：$h$ 由 2 个本地点 + 3 个官方点定标，置信区间宽；模型不含背景流长重尾的逐条 dynamics（仅阈值化）；「Pareto 最优」结论依赖于我方效用定义（下载时间唯一目标）。
