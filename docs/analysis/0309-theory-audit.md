## 一句话结论

**在泄漏桶到达约束下，浅缓冲区零溢出充分条件 Σrᵢ≤μ ∧ Σbᵢ≤B 使「我方吞吐极大化」成为 LP（凸），KKT 解析解 r₀* = μ − R_bg − Δ（λ*=1、γ*=0）、b₀* 按风险最小取 0（leak 严格单包间隔）；代入 0085 实测阵风裕度 Δ=0.136μ 得 r₀*=9000 pkt/s=36 包/4ms，与皇冠大文件档一致。三组独立仿真交叉验证：保证域边界精确落在 Σr=μ、缓存条件在 Σb=B 边界处紧（burst10 零丢 / burst15 即丢 0.61%）、同均值下 tb 突发惩罚 22×（0085 解析口径 29×，同量级互证）。**

## 一、模型与零溢出充分条件（定理）

K+1 条流共享 FIFO drop-tail 瓶颈（μ=10416.67 pkt/s，缓存 B）。每条流到达满足泄漏桶仿射界 A_i(t) ≤ r_i t + b_i。**定理（Cruz '91 式反压界）**：若 Σrᵢ≤μ 且 Σbᵢ≤B，则

$$Q(t)=\sup_{s\le t}\Big[\sum_i A_i(t)-\sum_i A_i(s)-\mu(t-s)\Big]\le \sum b_i\le B$$

即零溢出、时延 ≤ B/μ=2.88ms。随机可行参数 200 组数值核验：最坏超出 **0.25 包**（≤1 包整包服务相位容差）——定理成立。皇冠两维度由此定形：速率维度 r₀ 受容量约束；突发维度 b₀ 越小越好——leak（b₀=0）不占缓存预算，tb（b₀≈batch 40~60）一次吞掉整个缓存预算。

## 二、凸规划与 KKT 解析解

**程序 P（鲁棒形式）**：max r₀ s.t. r₀ ≤ μ−R_bg−Δ (λ)、b₀ ≤ B−B_bg (γ)、r₀,b₀≥0。目标与约束线性 ⇒ **凸**；Slater 成立 ⇒ 强对偶。**KKT**：

- 平稳性 ⇒ **λ\*=1**（容量影子价）；**γ\*=0**（缓存松弛，非吞吐瓶颈价）；
- 互补松弛 ⇒ **r₀\* = μ − R_bg − Δ**（容量打满）；b₀* 在 [0, B−B_bg] 内任意，**按风险最小取 0（leak）**；
- HiGHS 数值解与解析解逐位一致：r₀* = 9000.00 pkt/s = **36.000 包/4ms**，λ=1.0000，γ=0.0000，KKT 残差 ≤1e-9（PASS）。

**Δ 的物理来源（0085 实测）**：leak36 的 13.6% 排空余量（1416.67 pkt/s）把满缓存排空时间 T_drain=B/(μ−r₀*)=**21.18ms（B=30）/ 28.24ms（B=40）** ≪ RTT 70ms——亚 RTT 吸收，与 0085 开环有效窗口闭合。

## 四、「皇冠构型=全局凸极值点」的成立域与边界（如实陈述）

1. **成立域**：在 (r₀,b₀) 参数化、零溢出充分条件、LP 目标下，(9000, 0) 是**全局**最优（LP 无局部陷阱；KKT+解析+仿真三重验证）。皇冠**小文件档 40/4ms（0.96μ 名义临界）在鲁棒保证域之外**，属短窗口风险预算选择（0085：leak40 尾丢 0.157%），本定理严格覆盖的是大文件档 36。
2. **充分 ≠ 必要**：实际安全域大于保证域（背景占空比/闭环背压未建模）；反之 0298 R2 已证 117% 持续过载时 FIFO 无法隔离我方丢包——保证域=共存域（总 offered≤μ），与 0298 一致。
3. **份额归属**：本证明回答「给定零溢出约束我方速率上限」；官方锚点大文件实测份额 ~0.42C 由背景行为决定（0086），不在我方可控范围——两事实并存不矛盾。
4. **B 口径差**：任务书 30 vs 0082/0085 的 40；定理对 B 参数化，双口径数值均给出。

5. **零溢出论证缺突发结构**：仅以 Q*<30 断言，忽略 0085 的全部突发动力学。
