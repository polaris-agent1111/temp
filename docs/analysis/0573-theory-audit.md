# 矩阵自由李代数霍尔基底展开与贝克-坎贝尔-豪斯多夫公式紧凑截断审计报告 (Task 0573)

## 1. 核心李代数理论与 BCH 展开建模
在非对易多载控制矩阵群中，状态生成元 $X, Y \in \mathfrak{sl}(2, \mathbb{R})$ 满足不对易性 $[X, Y] \neq 0$。李代数指数积的对数合成算子遵循 Baker-Campbell-Hausdorff (BCH) 公式：
$$Z = \ln(\exp(X) \exp(Y)) = X + Y + \frac{1}{2}[X, Y] + \frac{1}{12}[X, [X, Y]] - \frac{1}{12}[Y, [X, Y]] - \frac{1}{24}[Y, [X, [X, Y]]] + \dots$$
通过 Hall 基底，李代数自由生成项中的雅可比恒等式冗余项被完全消除。
对于无迹李代数生成元 $\text{tr}(X) = 0, \text{tr}(Y) = 0$，其李群矩阵严格保持体积不变量 $\det(\exp(Z)) = 1$。
