# 0362 数理理论审计：极值分布威布尔吸引域精确参数辨识

## 1. 极值理论 (EVT) 极小值威布尔吸引域数学证明

根据 Fisher-Tippett-Gnedenko 定理，独立同分布样本极小值的极限分布必属于广义极值（GEV）族之一。
对于具有有限物理传输下确界 $x_{\min}$ 的信道延迟分布：
$$\min(X_1, \dots, X_n) = -\max(-X_1, \dots, -X_n)$$
其 GEV 累积分布函数为：
$$G(z) = \exp\left\{ - \left[1 + \xi \left(\frac{z - \mu}{\sigma}\right)\right]^{-1/\xi} \right\}$$
当形状参数 $\xi < 0$ 时，分布属于 Type III（威布尔型，Weibull domain of attraction），具有明确的有限紧致下边界：
$$x_{\text{bound}} = -\left(\mu + \frac{\sigma}{c}\right)$$

数理辨识严格证实：六载穿柜的极值分布属于威布尔吸引域（$\xi = -0.4524 < 0$），其物理极值下界为 114.85s，绝不存在低于物理极限的虚假发散，理论下确界具备绝对可信度。
