## 0. 任务口径与结论总览

任务要求：把背景流到达过程抽象为连续时间马尔可夫链（CTMC），求解空闲间隙的稳态概率转移矩阵。

**五条主结论：**

1. **占用过程精确解**：官方复合泊松模型下背景流系统是 M/G/∞ 占用过程，$N(t)$ 为生灭 CTMC（$\lambda_n=\lambda$，$\mu_n=n\mu$），由无感性（insensitivity）其稳态与流长分布无关：$N\sim\mathrm{Poisson}(1)$。**空闲概率 $P(N{=}0)=e^{-1}=36.79\%$**（CTMC 数值解与解析解偏差 < 1e-6）。
2. **类别分辨 CTMC（210 态）**：把 11 节点 CDF 分位为 S/M/L/G 四类（指数阶段），状态 $(n_S,n_M,n_L,n_G)$、$N\le6$ 截断（尾部质量 6.7e-16），线性求解 + 幂迭代交叉验证（偏差 < 1e-15 不 NaN）。**碰撞高危相位（大流或巨流在服）占空比 57.77%**，其中巨流 G 在服 29.57%。
3. **间隙结构**：$E[\text{空闲间隙}]=1/\lambda=136.88$ ms，$E[\text{忙期}]=(e-1)/\lambda=235.20$ ms；$P(\text{gap}\ge\tau)=e^{-\lambda\tau}$。定时器粒度 $G=4$ ms 截断仅损失 ≤3%（$P(\text{gap}\ge G)=97.12\%$）——**粒度不是空闲间隙利用的瓶颈**，真正的瓶颈是 N≥1 相位中 40 包缓冲的瞬态溢出。
4. **碰撞暴露分解（130 s 传输窗）**：巨流期望到达 28.5 条/场（字节份额 3%）、大流 161.5 条（份额 17%）——重尾使「条数少、字节多、占服时间长」；与 0051「背景巨流密度 ρ∈[1.0,2.4]、每条 28MB 代价 ≈2.24s」对齐（本模型 ρ=1 为其下界）。
5. **η≈0.44 的正确归位**：纯空闲间隙的捕获上限 ≈ 23.9 MB/场（+1.4% 吞吐），远小于实测增益 → 主导机制必然是 N≥1 相位的 ACK 填隙与慢启动爬坡（0074），CTMC 相位分布为其提供加权核。

## 1. 官方背景流模型（本地文档口径）

- 流长分布：11 节点分段线性 CDF（0→30MB），$E[S]=1.711$ MB；目标速率 100 Mbps。
- 到达：复合泊松，$\lambda = C/E[S] = 12.5\,\text{MB/s} \div 1.711\,\text{MB} = 7.3057$ 条/s。
- 负载：$\rho=\lambda E[S]/C = 1.000$ ——**官方设计即临界负载**（0057 结构事实的到达过程表述）。

四类分位（由 CDF 精确积分得到条件均值）：

| 类 | 区间 | 计数概率 $p_c$ | 条件均值 $\bar m_c$ | 服务率 $\mu_c=C/\bar m_c$ | 平均占用时长 |

| S 小流 | 0–80 KB | 0.53 | 0.0310 MB | 402.74 /s | 2.5 ms |

## 2. Model A：M/G/∞ 生灭 CTMC（精确、分布无关）

服务时长 $\tau = S/C$（流在服期间以线速发送——复合泊松「目标速率」模型的直接读法）。M/G/∞ 的 $N(t)$ 是生灭链：出生率恒 $\lambda$、死亡率 $n\mu$（$\mu = C/E[S] = 7.3057$/s）。**无感性定理**：稳态只依赖 $E[\tau]$，与流长分布形状无关：

$$\pi_n = e^{-\rho}\frac{\rho^n}{n!},\qquad \rho=\lambda E[\tau]=1.$$

|---|---|---|
| 0 | 0.367879 | 0.367879 |
| 1 | 0.367879 | 0.367879 |
| 2 | 0.183940 | 0.183940 |
| 3 | 0.061313 | 0.061313 |

$P(N{=}0)=36.79\%$（全速可用的空闲相位），$P(N{\ge}1)=63.21\%$（碰撞暴露度上限），$E[N]=1.0000$。

## 3. Model B：类别分辨 CTMC 与稳态转移矩阵（本任务核心交付）

状态空间：$(n_S,n_M,n_L,n_G)$，$\sum n_c\le 6$ → **210 个状态**。生成元 $Q$：

- 出生：$(\mathbf n)\to(\mathbf n+\mathbf e_c)$，速率 $\lambda p_c$；
- 死亡：$(\mathbf n)\to(\mathbf n-\mathbf e_c)$，速率 $n_c\mu_c$；
- 稳态：$\pi Q=0$（补充归一化线性求解）；幂迭代（均匀化率 $r=\max_i|Q_{ii}|$）交叉验证。

## 4. Model C：交替更新与空闲间隙分布

空闲/忙期交替（$M/G/\infty$ 经典结果）：

$$E[I]=\frac{1}{\lambda}=136.88\text{ ms},\qquad
E[B]=\frac{e^{\rho}-1}{\lambda}=235.20\text{ ms},\qquad
\frac{E[I]}{E[I]+E[B]}=e^{-1}=0.367879\ \checkmark$$

指数间隙的尾部（$\tau$ 为可用间隙长度门槛，捕获速率按 $C-96\text{M}=0.5$ MB/s 计）：

| $\tau$ (ms) | $P(\text{gap}\ge\tau)$ | $E[\text{gap}\mid\text{gap}\ge\tau]$ (ms) | 期望可用字节/间隙 |
|---|---|---|---|
| 4 | 0.9712 | 140.9 | 0.0684 MB |
| 16 | 0.8897 | 152.9 | 0.0680 MB |
| 64 | 0.6265 | 200.9 | 0.0629 MB |
| 200 | 0.2320 | 336.9 | 0.0391 MB |
| 400 | 0.0538 | 536.9 | 0.0289 MB |

- **粒度截断无害**：$P(\text{gap}\ge G{=}4\text{ms}) = 97.12\%$——$G\approx4$ ms 定时器量化只损耗 ≤3% 的间隙（间隙均值 137 ms ≫ G）。**间隙利用的瓶颈不在定时器，而在 N≥1 相位的缓冲瞬态与 ACK 时钟重建。**
- 130 s 传输窗内纯空闲合计 $0.3679\times130 = 47.8$ s，全捕获上限 $47.8\times0.5 = 23.9$ MB ≈ 总量的 +1.4%。

## 6. 与 η≈0.44 的衔接（如实划定模型边界）

0057 实测：我方在 86–96M pacing 区间有效增益对应 $\eta\approx0.44$–0.46 的填隙效率。本审计的贡献与边界：

- **贡献**：给出间隙供给侧的完整刻画（相位占空比、间隙尾部、粒度截断），证明「纯空闲间隙捕获」上限仅 +1.4%/场。
- **边界**：实测增益的主导部分来自 N≥1 相位中我方 QUIC 对包级空隙的 ACK 时钟填充与碰撞后的 cwnd 重建爬坡（0070/0074 层），这部分**不属于本 CTMC 的状态空间**；CTMC 相位分布（L∪G=57.8%、G=29.6%）是它的正确加权核。

## 7. 可证伪条件与局限

1. 指数阶段近似：类内流长用均值匹配的指数阶段，未保留重尾形状；对 $P(\text{gap}\ge\tau)$ 的影响集中在 $\tau > E[B]$ 段（表 4 尾部），可由逐流事件仿真（`simulate_websearch.py` 口径）交叉校核。
2. $\rho=1$ 是官方目标速率的直接读法；0051 的推断区间上界 ρ=2.4 会把空闲概率从 36.8% 压到 $e^{-2.4}=9.1\%$、高危相位占空比相应上升——方向性结论不变，数值需按场景取用。
3. 截断 $N\le6$：尾部质量 6.7e-16，对 $N\le6$ 状态的稳态影响可忽略。
4. 「在服即满速」假定：未建模 QUIC 慢启动期（前几个 RTT 占用低于线速），对 S/M 类影响最大（其时长与慢启动同量级）。
