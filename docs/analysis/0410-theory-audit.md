## 2. 数理推导与偏微分方程求解

### 2.1 反射伊藤 SDE 建立 (Skorokhod 问题)
排队过程在连续微秒尺度下表述为：
$$dX_t = (r - C) dt + \sigma dW_t + dL_t$$
其中 $C = 40.0$ pkts/4ms 为瓶颈容量，$r = 37.0$ pkts/4ms 为 Shot 1 稳定速率，$\sigma = 1.8$ 为高斯白噪声强度，$L_t$ 为原点处的局部时边界反射项（保证排队 $X_t \ge 0$）。

### 2.2 Fokker-Planck-Kolmogorov (FPK) 偏微分方程
稳态概率密度函数 $p(x)$ 满足定常零通量守恒：
$$J(x) = -(C - r) p(x) - \frac{1}{2} \sigma^2 \frac{d p(x)}{dx} = 0$$
转化为一阶常微分方程：
$$\frac{d p(x)}{dx} = -\lambda p(x), \quad \text{其中 } \lambda = \frac{2(C - r)}{\sigma^2}$$
代入参数解得严格解析指数稳态概率测度：
$$p^*(x) = \lambda e^{-\lambda x} = 1.851852 e^{-1.851852 x}$$
理论稳态矩统计量：
- 稳态期望排队：$\mathbb{E}[X] = \frac{1}{\lambda} = 0.540000$ 包
- 稳态方差：$\text{Var}(X) = \frac{1}{\lambda^2} = 0.291600$ 包$^2$

### 2.3 RK4 高精度数值 PDE 对偶校验
在空间域 $[0, 15]$ 上采用 30,000 点高精度 RK4 积分求解 FPK 边值问题：
- 数值解期望：$0.540018$ 包（绝对误差 $1.79 \times 10^{-5}$）
- 数值解方差：$0.291619$ 包$^2$（绝对误差 $1.95 \times 10^{-5} \ll 0.01$）
