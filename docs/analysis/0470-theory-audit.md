# 任务 0470 理论审计报告：庞特里亚金最大值原理 (PMP) 能量-时延帕累托最优轨迹合成

## 1. 理论背景与数学推导
在 6 阶段穿柜整形中，发送端面临着吞吐量能耗（发包剧烈度 $\frac{1}{2} r(t)^2$）与浅缓冲区排队时延累积（$\alpha q(t)$）的固有物理权衡。
考虑连续时间连续状态变分动力学：
$$\min_{r(t)} J = \int_0^T \left( \frac{1}{2} r(t)^2 + \alpha q(t) \right) dt$$
状态微分约束方程（浅缓冲区排队流形）：
$$\dot{q}(t) = r(t) - C, \quad q(0) = q_0, \quad q(T) = q_T$$
其中 $C$ 为交换机出端口恒定转发容量，$r(t)$ 为控制变量（Pacer 发送速率）。

### 庞特里亚金控制与哈密顿量解析
定义标量哈密顿量（Hamiltonian）：
$$H(q, r, p) = \frac{1}{2} r^2 + \alpha q + p (r - C)$$
由极小值必要条件（PMP）：
1. **协态动力学**：
   $$\dot{p}(t) = -\frac{\partial H}{\partial q} = -\alpha \implies p(t) = p_0 - \alpha t$$
2. **最优控制率**：
   $$\frac{\partial H}{\partial r} = r + p = 0 \implies r^*(t) = -p(t) = \alpha t - p_0$$
3. **状态轨迹精确积分**：
   $$\dot{q}(t) = \alpha t - p_0 - C \implies q(t) = q_0 + \frac{1}{2} \alpha t^2 - (p_0 + C)t$$
   代入终端边界约束 $q(T) = q_T$，解出协态初值：
   $$p_0 = \frac{q_0 - q_T}{T} + \frac{1}{2} \alpha T - C$$
4. **哈密顿量守恒律**：
   由于系统拉格朗日量与约束均不显含时间 $t$，沿最优极值轨迹哈密顿量严格守恒：
   $$\frac{dH}{dt} = \frac{\partial H}{\partial t} = 0 \iff H(t) \equiv \text{const}$$
