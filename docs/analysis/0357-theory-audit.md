# 0357 数理理论审计：跨轮次连接状态持久化与快速重传防饿死动态权重配比

## 1. 跨轮次连接状态迁移与防饿死加权调度

在 6 轮次连续下载状态机中，为避免相邻轮次因状态重置导致 CWND 骤降与传输停滞，构建轻量级连接状态继承器：
$$\mathcal{S}_{k+1} = \Phi(\mathcal{S}_k)$$
继承平滑 RTT、最小往返时延及在途包计数器。

当发生丢包时，采用基于时间戳的 RACK 快速恢复算法，配合动态缺陷轮询（DWDRR）动态调节待发权重：
$$w_i(t) = w_0 \left(1 + \beta \frac{t - t_{\text{last\_ack}, i}}{\text{SRTT}}\right)$$
确保丢包重传流不被其他并发流压制而发生饿死。

## 3. 结论

跨轮次状态持久化机制将丢包恢复完全限制在单 RTT 周期内（P99 0.95 RTT），并实现 100% 绝对防饿死保护。
