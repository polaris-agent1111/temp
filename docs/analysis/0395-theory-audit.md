# 任务 0395 理论审计：基于自适应卡尔曼滤波的高速微秒 RTT 动态估计器

## 1. 任务背景与核心目标
在基于 QUIC 协议的高速流控中，标准 RFC 9002 使用指数加权移动平均（EWMA, $\alpha = 0.125$）平滑往返时延（SRTT）。
然而，EWMA 存在固有的结构性缺陷：
1. **平滑迟滞（Lag Effect）**：在网络遭遇突发拥塞导致排队队列阶跃抬升时，EWMA 需要经过多个 RTT 才能跟进真实值，延误了流量整形降速的时机；
2. **毛刺敏感性**：面对单包因 ACK 压缩造成的偶发毛刺，固定权重的 EWMA 会产生无意义的时延抬升。

本任务设计双重自适应卡尔曼状态估计器（Adaptive Kalman Filter, AKF），实现微秒级 RTT 动态跟踪。

- **核心门禁要求**：
  1. 动态时延跟踪均方误差 $\text{MSE} < 0.15\text{ ms}^2$；
  2. 阶跃跳变跟踪加速比 $\ge 1.5\times$；
  3. 滤波器收敛性证明率 $= 100.0\%$。

## 2. 自适应卡尔曼滤波算法设计

### 2.1 状态空间与动态预测
设真实往返时延标称状态为 $x_k$。离散时间动态模型为：
$$
x_{k} = x_{k-1} + w_k, \quad w_k \sim \mathcal{N}(0, Q_k)
$$
观测方程为：
$$
z_k = x_k + v_k, \quad v_k \sim \mathcal{N}(0, R)
$$

### 2.2 持续阶跃判定与自适应协方差跃迁
计算新息 $v_k = z_k - x_{k|k-1}$。为区分单包离群毛刺与系统性阶跃拥塞：
- 若连续两次测量新息满足 $|v_k| > 1.2\text{ms}$ 且 $\text{sign}(v_k) == \text{sign}(v_{k-1})$，判定网络发生真实的浅队列阶跃积压，自适应跃迁放大过程噪声至 $Q_k = 0.35$；
- 若仅为孤立单包毛刺，对新息实施稳健 Huber 截断并压低过程噪声至 $Q_k = 0.005$；
- 稳态阶段维持基准滤波 $Q_k = 0.008$。

卡尔曼增益与后验状态更新公式：
$$
K_k = \frac{P_{k|k-1}}{P_{k|k-1} + R}, \quad x_k = x_{k|k-1} + K_k v_k, \quad P_k = (1 - K_k) P_{k|k-1}
$$
