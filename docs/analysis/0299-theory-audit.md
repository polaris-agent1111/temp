# 0299 理论审计：Shot 3 成绩吸收与全国前三排位巩固

## 1. 数学理论：次序统计量与极值极限定理 (Extreme Value Theory)

在 11/08 实战的逐发推进过程中，官方大榜最终认定的团队成绩为当天所有有效提交的最小值：
$$M_k = \min_{1 \le i \le k} X_i$$
其中 $X_i$ 为第 $i$ 发真实出分。

### 1.1 三发极值累积分布函数
由于三发配置在自适应决策下依次解耦网络背景流与微调参数，设 $X_1 \sim \mathcal{N}(\mu_1, \sigma_1^2), X_2 \sim \mathcal{N}(\mu_2, \sigma_2^2), X_3 \sim \mathcal{N}(\mu_3, \sigma_3^2)$：
$$F_{M_3}(t) = P(M_3 \le t) = 1 - \prod_{i=1}^3 (1 - F_{X_i}(t))$$
其中 $F_{X_i}(t) = \Phi\left(\frac{t - \mu_i}{\sigma_i}\right)$。
当 $t = T_{\text{Rank3}} = 120.2670\text{s}$ 时，登上全国领奖台（Top 3）的联合概率为：
$$P(\text{Podium}) = 1 - [1 - \Phi(z_1)][1 - \Phi(z_2)][1 - \Phi(z_3)]$$
