# 任务 0483 理论审计报告：随机摄动同步逼近 (SPSA) 零阶黑盒评测梯度重构

## 1. 理论背景与数学推导
在真实网络云端黑盒评测中，目标函数 $L(\theta)$（如 6 阶段总下载耗时）无法通过解析式进行符号自动微分（Automatic Differentiation），只能通过黑盒执行获得带噪声的标量反馈：
$$y(\theta) = L(\theta) + \epsilon$$
传统的有限差分法（FDSA）在 $p$ 维参数空间中，计算单次数值梯度需要 $2p$ 次黑盒调用（在 $p=6$ 时需要 12 次评测），在高耗时系统中开销极大。

### Spall 随机摄动同步逼近原理 (SPSA)
Spall (1992) 提出的 SPSA 算法每次仅需 **2 次目标函数调用**，即可估计整个 $p$ 维梯度向量。
构造伯努利/拉德马赫随机摄动向量 $\Delta_k \in \{-1, +1\}^p$：
$$\mathbb{E}[\Delta_{k, i}] = 0, \quad \mathbb{E}[\Delta_{k, i}^{-1}] = 0, \quad \Delta_{k, i} \text{ 相互独立}$$
同时在两个相反方向施加摄动：
$$\theta_k^+ = \theta_k + c_k \Delta_k, \quad \theta_k^- = \theta_k - c_k \Delta_k$$
对应的 SPSA 梯度分量估计为：
$$\hat{g}_k(\theta_k) = \frac{y(\theta_k^+) - y(\theta_k^-)}{2 c_k} \begin{bmatrix} \Delta_{k, 1}^{-1} \\ \vdots \\ \Delta_{k, p}^{-1} \end{bmatrix}$$
由泰勒二阶展开：
$$\mathbb{E}[\hat{g}_k(\theta_k) \mid \theta_k] = \nabla L(\theta_k) + \mathcal{O}(c_k^2)$$
其期望严格等于真实的理论解析梯度，且方差随多次独立摄动以 $\mathcal{O}(1/M)$ 速率衰减。

### 梯度方向保真度与余弦相似度
通过与真实解析梯度的余弦相似度检验方向一致性：
$$\cos(\hat{g}, \nabla L) = \frac{\hat{g}^T \nabla L}{\|\hat{g}\| \|\nabla L\|}$$
当余弦相似度 $\ge 0.95$ 时，零阶估计梯度的下降方向与一阶解析梯度高度同向。
