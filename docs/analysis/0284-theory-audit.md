## 2. 模型与 PMP 结构（连续时间）

状态：瓶颈排队债务 D(t) ∈ [0,1]（0 = 空，1 = 缓冲上限，超越即 0085 律的灾难性尾丢）；
控制：pacing u(t) ∈ [u_lo, u_max]；下载活跃期动力学

  Ḋ = (u − μ_p)/S_max ，目标 min J = ∫₀ᵀ 1 dt = T（6 文件全部到齐）。

Hamiltonian H = 1 + ψ·(u − μ_p)/S_max；协态 ψ̇ = −∂H/∂D = 0（内域弧上 ψ 为常数），
开关函数 σ = ∂H/∂u = ψ/S_max。标准线性时不变时间最优结论：

- ψ < 0 ⇒ u* = u_max（**Bang**，饱和弧）；ψ > 0 ⇒ u* = u_lo（退避弧）；
- 状态约束 D = 1 激活时进入约束弧 u* = μ_p（**Coast**，持队列弧）；
- 终端排水约束产生末端 u < μ_p 弧。三者合成 **Bang-Coast-Bang** 极值结构。

**关键判据**：Bang 弧存在的充要条件是 σ 在对应时段变号，即饱和时段的时间收益
g(u_max) > g(μ_p) 严格成立。若 g(·) 在 ≥36 带内平坦（平台），则 PMP 极值退化为
**平台均匀控制**（u* = 36，带入口），不产生前饱和弧。

## 6. 模型有效性检验

- **方向一致性**：模型排序（均匀 36 ≪ crown 135.5）与本地实测方向一致
  （leak27 均值 126.2 (n=3)、leak36 129.9 (n=2) 均低于 crown 135.5 (n=15)）。
- **绝对乐观度**：模型 113.1 s vs 实测均匀家族 126–130 s，乐观 ~10–15%
  （未建模协议开销），等比作用于两方，不改变相对结论。
- **crown 可行性**：crown 债务峰值 ≤1 在 266/270 校准点成立——crown 是可行调度，
  但不是该校准族下的 PMP 极值。

## 7. 结论与可证伪路径

1. **≥96% 重合度声明未获支持**：签发值 89.94%（后期相位 100% 吻合、前期相位 0%）。
2. 唯一可能令前饱和成为极值的机制是**背景阵风捕获**（0085「leak36 gust scissor」：
   背景流阵风间隙中高 pacing 更快抢占释放带宽）——该机制为随机过程，确定性等价
   PMP 原理上不可表达；验证它需要阵风分辨率的背景流模型与对应随机最优控制
   （HJB/随机 PMP），超出本任务与本地数据分辨率。
3. 若 Lead 仍需 ≥96% 结论，须先补充可观测证据：同配置下 u=41 与 u=36 的
   配对阶段吞吐差（现有 n=15 vs n=2 数据不足以证明 5% 级增益）。
4. 本审计**不构成**对 11/08 五发封板配置的否定：封板依据是官方均值口径与邻域
   平台性（0267 ±1 扰动 max 0.6935s ≤ 0.8s PASS），PMP 重合度是理论叙事检验，
   两者口径不同，不得互相替代。
