## 一句话结论

**官方口径明文「总时间=六次下载耗时相加、配置写入不计入」，本地 392 样本核验 Σdownloads==total 偏差为 0.000000s——任务间空闲期（socket 释放、内核 buffer 回收）根本不进入官方计时；能进入计时的连接层残余每 bin ≤ 1 RTT（70ms，冷连接握手+首字节），全程 ≤ 420ms（占比 ≤0.32%，≤ σ_d 的 6%），在官方分辨率下不可辨识；1.bin 包络超出 ≈2 RTT 与理论界 140ms 吻合是唯一可用的经验锚点。残余开销不是优化对象。**

## 一、口径层：官方计时结构决定了残余开销的位置

官方题目明文两条：

1. 「六份文件全部下载成功后，**把六次下载耗时相加**，得到该场景的总时间」；
2. 「**配置写入生效的时间不计入下载耗时**」。

推论（本审计第一条结论）：**任务之间的空闲期——socket 释放、内核 socket buffer 回收、配置写入与生效——全部位于两次 per-bin 计时之间，官方总时间里不存在这个分项。**任务单标题中的「socket 释放与内核 socket buffer 回收耗时」按官方口径**不进入成绩**；能进入成绩的残余只有「每次下载耗时内部」的非传输部分：

- QUIC 连接建立（若每 bin 新建连接：冷握手 1 RTT；若持续连接/0-RTT：≈0）；
- 服务端 pacer 重配生效后的首个数据包延迟（配置写入本身不计，但生效后的首包在 per-bin 计时内）；
- 请求-响应往返的首字节延迟。

teardown（CONNECTION_CLOSE drain）发生在最后一个数据字节之后，**不计时**。

## 二、恒等式核验：计时连续相加、无缝隙

392 条 valid 本地样本（六 bin 齐全）核验：

$$\max\left|\sum_{i=1}^{6} t_i - T_{\text{total}}\right| = 0.000000\ \text{s}$$

per-bin 计时**连续相加、无缝隙**——评测器的计时结构里没有可藏「任务间开销」的自由度。残余开销要么为 0（不计时），要么已含在 per-bin 内部（连接建立/首包）。这把「测定」问题从六边形收缩为单点：只需定 per-bin 内部的非传输部分。

## 三、经验包络与回归：残余被背景税淹没，1.bin 是唯一干净锚点

**per-bin 包络**（min − 满速 − 慢启动折算）：

| bin | n | min (s) | 满速 (s) | α_lo−SS (s) | 解读 |
|---|---|---|---|---|---|
| 1.bin | 392 | 1.372 | 0.80 | **+0.132** | ≈ 2×RTT，**与冷连接握手+首字节 140ms 吻合** |
| 2.bin | 392 | 2.385 | 1.60 | +0.345 | 短 bin，SS/背景敏感性混合 |
| 3.bin | 392 | 4.602 | 3.20 | +0.952 | 背景税开始主导 |
| 4.bin | 392 | 9.043 | 6.40 | +2.183 | 背景税主导 |
| 5.bin | 392 | 21.327 | 12.80 | +8.157 | 背景份额地板主导 |
| 6.bin | 392 | 55.290 | 25.60 | +29.340 | **背景税**（对照 0086 开环份额地板 55.2s 量级一致） |

口径诚实性：背景需求 a=λE[S]/C≈0.9999 是**常态**（0083），即使最幸运样本也背着份额税——长 bin 的 α_lo−SS 全部是背景税而非连接层残余。**本地经验分解无法把连接层残余从背景税中分离（1.bin 除外）**；6.bin 本地 min 55.29s 与 0086 模型开环份额地板 55.2s 的量级一致恰说明：最优本地样本已经贴住饱和份额地板，没有给残余开销留下可测空间。

**回归** T_i = α_i + β_i·proxy + ε（proxy=Σ_{j≠i}T_j，bootstrap 95% CI）：β 全部 ≥0（1/4/5/6.bin 显著），证实同场次跨 bin 背景正相关；长 bin 截距由背景份额地板主导（6.bin α=59.3s[51.9, 66.2] ≈ 0086 地板量级），连接层残余在 α 中不可辨识——回归只能给出「残余 ≪ α」的弱界。

**本地 harness 编排开销**（wall−total，干净子集 n=390）：mean 83.1s / p50 33.3s——这是配置写入、tar 分发、评测器编排等本地流程开销，官方口径一律不计；仅用于说明本地与官方计时边界不同（2 条批量导入记录 wall<total 已剔除并注明）。

## 四、理论界：socket/内核层每 bin 残余上界

| 开销项 | 冷连接 | 持续连接 | 进官方计时 | 依据 |
|---|---|---|---|---|
| QUIC 握手（Initial+Handshake） | 1 RTT = 70 ms | 0 / 0-RTT ≈ 0 | **是** | RFC 9002；官方 RTT=70ms |
| 证书验证 | 握手窗内并行 | 0 | 是 | 含于 1 RTT 口径 |
| 首字节（pacer 重配后首包） | ≤1 RTT | ≤1 RTT | 是 | 配置写入不计，生效后首包计入 |
| 连接关闭 drain | 1 RTT | 1 RTT | **否** | 末字节后 |
| TCP TIME_WAIT | 不适用 | 不适用 | 否 | QUIC/UDP 无 TIME_WAIT；CID 空闲超时（≈30s 量级）不阻塞新连接 |
| 内核 socket buffer 回收 | O(µs) | O(µs) | 否（与下一连接并行） | 批量 skb 释放，不占关键路径 |
| 端口/四元组耗尽 | 0 | 0 | 否 | QUIC CID 机制 |

**合计**：

- 冷连接假设（最不利）：现实口径 70 ms/bin（握手+请求同一 RTT 窗），保守双计 140 ms/bin → 全程 ≤ 420 ms；
- 持续连接假设：仅 1.bin 冷启动 70 ms → 全程 ≤ 70 ms；
- 相对官方锚点 133.086s：占比 **≤ 0.32%**；相对官方单发噪声 σ_d≈7.0s（0084）：**≤ 6%**——在官方分辨率下不可辨识。

## 五、与官方成绩的分解对照

满速总时间 50.4s（630MB/12.5MB/s）→ 官方锚点 133.086s 的差值 82.7s 分解：

| 分项 | 量级 | 依据 |
|---|---|---|
| 背景份额税 | **~79s（主导）** | 0083 临界负载 + 0086 开环份额地板 |
| 慢启动基线（6 bin） | ≈2.2s | 0087 H1（每 bin ≈0.35–0.46s） |
| 连接层残余 | **≤0.42s（<0.5%）** | 本审计 A4 |
| 实现残差/噪声 | σ_d≈7.0s（单发） | 0084 |

**结论：官方总时间的水平与方差由背景份额和 CC 行为完全主导；连接/socket 层残余即使按最不利假设全部消除，也不可能在官方成绩上产生任何可测变化。任何针对「任务间开销」的优化都是零期望收益方向。**

## 六、结论

1. 官方口径明文 + 本地 392 样本恒等式核验（偏差 0.000000s）共同确立：**任务间空闲期不进入官方计时**；残余开销问题收缩为 per-bin 内部的连接建立/首字节。
2. 理论界：每 bin ≤ 1 RTT（70ms），全程 ≤ 420ms（冷连接保守）/ 70ms（持续连接），占比 ≤0.32%、≤ σ_d 的 6%，官方分辨率下不可辨识；TIME_WAIT 不适用于 QUIC，内核 buffer 回收 O(µs) 且在关键路径之外。
3. 经验侧：1.bin 包络超出 ≈2 RTT 与理论界吻合（唯一干净锚点）；长 bin 的包络与回归截距被背景份额税淹没（本地 min 55.29s vs 0086 地板 55.2s），残余不可分离——测定问题的诚实答案是「**有界、不可测、非优化对象**」。
4. 合规：闭门计算（numpy + 本地既有数据），零探测、零提交、零受保护路径写入。

## 七、风险与未决

- 连接持续性（每 bin 新建 vs HTTP/3 复用）官方未公布；两假设并集已覆盖，且结论（≤0.32%）对假设不敏感。
- 「首字节 ≤1 RTT」假设 0-RTT/请求搭首飞；若官方栈对每 bin 走完整冷启动且服务端重配引入额外生效延迟，每 bin 上界再 +1 RTT → 全程 ≤ 840ms，占比仍 <0.7%，结论不变。
- 本地样本的 per-bin 计时起点语义（是否含连接建立）官方未公布；恒等式与包络分析对该语义不敏感（只要六 bin 相加=total 恒成立）。
- wall−total 的批量导入记录（2 条 wall<total）已剔除；该字段仅作本地流程说明，不进入任何结论。
