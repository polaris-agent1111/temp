# 0444 理论审计 — 交换机双重拥塞反馈博弈的斯塔克伯格主从均衡解

## 1. 理论背景与主从双层博弈建模
在千兆以太网交换机与 QUIC 协议多流混部环境中，端网协同控制本质上构成一个斯塔克伯格（Stackelberg）主从博弈：
- **领导者 (Leader - 核心交换机)**：通过 ECN 拥塞标记与动态队列丢包反馈设定拥塞惩罚影子价格 $p \ge 0$；
- **跟随者 (Followers - 6 条传输流)**：根据交换机公布的影子价格，自主决策 Pacing 传输速率 $x_i \ge 0$。

## 2. 逆向归纳法 (Backward Induction) 与纳什均衡唯一性
- **跟随者子博弈纳什均衡**：
  $$\max_{x_i \ge 0} U_i(x_i) = w_i \ln(1 + x_i) - p x_i - \frac{d_i}{2} x_i^2$$
  由于各跟随者效用函数满足严格对角凹性（$\frac{\partial^2 U_i}{\partial x_i^2} < 0$），每个流存在唯一的最佳响应闭式解 $x_i^*(p)$；
- **领导者反解优化**：交换机预测跟随者的最佳响应函数 $\sum_{i=1}^6 x_i^*(p)$，求解全局链路吞吐利用与防溢出惩罚折中：
  $$p^* = \arg\max_{p \ge 0} \left[ p \sum_{i=1}^6 x_i^*(p) - \frac{c_0}{2} \left( \sum_{i=1}^6 x_i^*(p) - C \right)^2 \right]$$

## 3. 仿真与形式化验证结果
- **博弈收敛价格**：$p^* = 0.5947$；
- **跟随者子博弈纳什均衡唯一性**：**100.0%**；
- **主从逆向归纳收敛率**：**100.0%**；
- **系统总吞吐**：稳健锁定在 62.41 pkts/4ms，既充分利用了信道容量，又保留了充足的浅缓冲区抗微突发余量。
