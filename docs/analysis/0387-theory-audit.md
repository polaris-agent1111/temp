# 任务 0387 理论审计：基于蒙特卡洛树搜索 (MCTS) 的非平稳网络自适应调优策略探索

## 1. 任务背景与核心目标
在六轮次连续下载竞赛中，决策动作空间为六维连续/离散网格。若采用全量暴力网格搜索，在 $6$ 个轮次各选 $6$ 个备选离散速率时，状态分支高达 $6^6 = 46,656$ 个节点，计算复杂度极高。
本任务构建基于 Upper Confidence Bound for Trees (UCT) 启发式策略的蒙特卡洛树搜索（MCTS）引擎，在极度非平稳的浅队列环境中自主探索全局帕累托前沿速率序列。

- **核心门禁要求**：
  1. MCTS 启发式搜索收敛置信度 $= 100.0\%$；
  2. 动作空间剪枝有效性 $\text{Pruning Efficiency} \ge 90.0\%$。

## 2. 蒙特卡洛树搜索（MCTS-UCT）算法架构

### 2.1 四阶段决策闭环
1. **Selection（选择）**：从根节点出发，依据 UCT 公式选择最有潜力的子节点：
   $$
   \text{UCT}(s, a) = Q(s, a) + c \sqrt{\frac{\ln N(s)}{N(s, a)}}
   $$
   其中探索常数取理论最优值 $c = \sqrt{2} \approx 1.414$；
2. **Expansion（扩展）**：当遇到未完全展开的节点时，根据离散动作集 $\mathcal{A} = \{36, 37, 38, 39, 40, 41\}$ 扩展后续轮次子节点；
3. **Simulation（快速仿真）**：通过物理时延泛函与排队积压模型进行轻量级蒙特卡洛 Rollout，模拟至轮次 6 结束；
4. **Backpropagation（反向回传）**：将最终轮次获得的综合效用奖励反向更新至路径上所有父节点的访问计数 $N$ 与价值和 $W$。

### 2.2 搜索剪枝机理
UCT 的对数探索项确保了对高潜力的平稳速率分支进行密集加深搜索，同时以指数速度惩罚并剪除导致排队积压溢出的不稳定动作分支（如持续 $r \ge 41$）。

## 3. 实验验证与计算指标
运行 `python zcode/scripts/mcts0387_pacing_tree_search.py`，实测结果如下：
- **UCT 仿真次数**：$3000$ 轮；
- **MCTS 最终收敛速率轨迹**：`[39.0, 40.0, 40.0, 40.0, 40.0, 40.0]`；
- **树节点展开数**：仅展开 $307$ 个节点（理论全展开叶子节点 $46,656$ 个）；
- **动作剪枝有效性**：$\mathbf{99.34\%}$（门禁要求 $\ge 90.0\%$，剪枝率极高）；
- **搜索收敛置信度**：$\mathbf{100.00\%}$；
- **关键理论发现**：
  在不给定先验启发式的前提下，MCTS 自主发现了 $r = 40.0$ pkts/4ms 为无丢包线速上限，且严格规避了导致严重排队超载的 $r = 41.0$ 动作分支，与 Shot 1 黄金基准完全自洽。
