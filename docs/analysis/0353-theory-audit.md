## 1. 领奖台位次锁定与位次弹性模型

定义位次弹性（Ranking Elasticity）：
$$E = \frac{\Delta \text{Rank} / \text{Rank}}{\Delta T / T}$$
衡量出分发生轻微环境微扰 $\Delta T$ 时位次变动的剧烈程度。若 $|E| = 0$，表示系统处于宽阔的位次安全平台，无位次滑落风险。
