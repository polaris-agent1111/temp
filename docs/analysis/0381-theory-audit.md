# 任务 0381 理论审计：网络拓扑非对称丢包与前向纠错 (FEC) 编码冗余开销纳什均衡

## 1. 任务背景与核心问题
在 QUIC 流量工程领域，面对跨流背景竞争与瞬时浅队列，常见的应对策略包括：
1. 编码层保护：引入 Reed-Solomon 或 RaptorQ 前向纠错（FEC），通过在发送端注入冗余包（Redundancy Ratio $\gamma$）对抗网络突发丢包；
2. 传输层整形：依靠 Pacing 精确速率控制消除突发，避免将交换机缓冲区推至溢出临界点。

在「六载穿柜」以最小化六轮连续下载总耗时为核心竞赛目标的设定下，是否存在某一非零冗余率 $\gamma > 0$ 能够提升总成绩？本任务通过博弈论纳什均衡框架对该问题进行了数学证明与仿真检验。

## 2. 纳什均衡博弈建模与数学推演

### 2.1 目标效用函数
选手发送端的目标为最小化总完成时间 $T(\gamma, r)$，对应博弈效用函数定义为：
$$
U(\gamma, r) = - T(\gamma, r)
$$
设单次下载基准数据量为 $S_0$（50MB），发送速率为 $r$（pkts / 4ms），有效传输带宽为 $B(r)$。引入 FEC 冗余率 $\gamma$ 后，发送端必须发送的总数据量为：
$$
S_{\text{total}} = S_0 (1 + \gamma)
$$

### 2.2 传输时延与重传代价比较
在微秒级 Pacing 流量整形作用下，由于发送速率严格受控于瓶颈容量以下（$r \le 40$ pkts/4ms），拥塞诱发的排队溢出丢包率降为零，信道仅存在偶发的物理随机微丢包 $p_{\text{rand}} \sim 0.1\%$。
- 若采用选择性确认重传（ARQ）：仅需对发生丢失的 $0.1\%$ 数据包进行重传，传输总数据量仅为 $S_0 (1 + 0.001)$；
- 若采用静态 FEC 编码：即便是最小的常规冗余率 $\gamma = 5\%$，也将总数据量直接膨胀至 $S_0 (1 + 0.05)$，开销激增 50 倍！

### 2.3 导数单调性与严格占优证明
对任意 $r \in [36, 40]$，效用函数对冗余率 $\gamma$ 的一阶偏导数为：
$$
\frac{\partial U}{\partial \gamma} = - \frac{S_0}{B(r)} < 0 \quad (\forall \gamma \ge 0)
$$
由于一阶偏导数严格负定，效用函数在闭区间 $[0, \gamma_{\max}]$ 上严格单调递减。因此，全局最大效用点在边界唯一取得：
$$
\gamma^* = \arg\max_{\gamma \ge 0} U(\gamma, r) = 0.0
$$
$\gamma^* = 0.0$（零冗余纯 Pacing 整形）是博弈空间内的**全域严格占优纳什均衡解**。
