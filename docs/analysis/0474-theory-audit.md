# 任务 0474 理论审计报告：随机逼近罗宾斯-蒙罗 (Robbins-Monro) 极小极大瓶颈速率自适应辨识

## 1. 理论背景与数学推导
在真实网络传输中，寻找浅缓冲区的饱和临界发包速率 $\theta^*$（即丢包概率与排队时延开始急剧攀升的拐点速率）实质等价于求解未知回归函数的零点问题：
$$M(\theta^*) = \mathbb{E}[Y(\theta^*)] = 0$$
其中 $Y(\theta) = \tau(\theta) - \tau_{\text{thresh}} + \xi$ 为实测端到端排队时延与安全时延阈值之差，$\xi$ 为具有未知分布特征的随机噪声。

### Robbins-Monro 随机逼近算子
根据经典 Dvoretzky 与 Robbins-Monro 定理，构造投影递推迭代格式：
$$\theta_{k+1} = \Pi_\Theta \left( \theta_k - a_k Y_k(\theta_k) \right)$$
其中步长序列 $a_k = \frac{a_0}{k^\gamma}$ 必须满足：
$$\sum_{k=1}^\infty a_k = \infty, \quad \sum_{k=1}^\infty a_k^2 < \infty \iff \gamma \in (0.5, 1.0]$$
$\Pi_\Theta$ 为参数紧集有界投影算子，保证迭代轨迹的有界性。

### Polyak-Ruppert 平均化与最佳渐近有效性
为了达到渐近方差的最优下界（即克拉美-罗下界 CRLB），对迭代轨迹尾部实施 Polyak-Ruppert 平均：
$$\bar{\theta}_K = \frac{1}{K - K_0} \sum_{k=K_0+1}^K \theta_k$$
当 $K \to \infty$ 时，$\sqrt{K}(\bar{\theta}_K - \theta^*) \xrightarrow{d} \mathcal{N}\left(0, \frac{\sigma^2}{(M'(\theta^*))^2}\right)$，实现参数估计的最优渐近正态效率。
