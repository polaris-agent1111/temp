## 一、机理：粗定时器的 ceil 语义与零损失点集

Linux 粗定时器（jiffies 后端）语义：`expires` 向上取整到 tick 网格；自重装（回调内 re-arm）从 tick+ε 起算，故：

- **实际周期 = ceil(T/J) × J**，速率因子 = T / (ceil(T/J)×J)；
- **零损失点集 = J 的全部整数倍**：HZ=250 → {4, 8, 12…}ms；HZ=1000 → {1, 2, 3, 4…}ms；
- **4000µs 同时落在两个点集的交集**（1×4ms = 4×1ms）→ 双网格 100% 因子 → **对内核 HZ 配置不可知性免疫**（共振点）。

量化因子表（T 扫描 × HZ∈{250,1000}）：T=1000µs 在 250Hz 因子 25%（→ 4000µs）、1500µs → 37.5%、2500µs → 62.5%、5000µs → 62.5%（ceil 2 → 8000µs）；全部非整数倍 T 被确定性地拖到下一格，**无平均偏置、无抖动**（MC std<0.2µs）——这解释了 0013 为什么观察到的是「确定性 2× 慢」而不是「概率性变慢」：v1 的 leak 9/1000µs 被重写为 9/4000µs，速率 ×1/4，时长 ×4。

## 二、相位锁定 MC 验证（seed=42，n=2500/格）

| T (µs) | HZ=250 | HZ=1000 |
|---|---|---|
| 1000 | QUANTIZED：mean 3999.7µs（4× 拖延） | LOCKED：mean 999.8µs |
| 2500 | QUANTIZED：3999.8µs | QUANTIZED：2999.7µs |
| **4000** | **LOCKED：3999.7µs** | **LOCKED：3999.8µs** |
| 6000 | QUANTIZED：7999.7µs | QUANTIZED：5999.7µs |
| 10000 | QUANTIZED：11999.8µs | LOCKED：9999.8µs |

判定标准 |mean−T|<1µs。T=4000 在两个 HZ 下均为 LOCKED——**这是唯一同时通过两网格的候选周期**（1ms 只过 1000Hz，8ms 只过 250Hz 且浪费 2× 速率）。工程含义：4000µs 不是「凑整」，是**双网格共振免检点**——官方容器无论 250/500/1000Hz，速率兑现不变。

## 三、hrtimer 路径：大周期对唤醒迟滞的一阶不敏感

若 refill 定时器走 hrtimer（ns 级），量化消失但唤醒迟滞 δ∈[0.8,1.2]ms（0068 锚）保留。MC（seed=42）：有效因子 = T/(T+δ̄)：

| T | 1000µs | 2000µs | **4000µs** | 8000µs |
|---|---|---|---|---|
| 因子 | 50.0% | 66.6% | **80.0%** | 88.9% |

- **T=4000 → 80%**，独立复现 0068 的 77–87% 实测折损与 0076 的 76.8% MC——两份前置审计的「折损锚」在此获得闭式解释：δ̄≈1ms 恒定，相对折损 = δ̄/(T+δ̄)，**T 越大越钝感**。
- 工程余量核算：r=40/4000µs 名义 96 Mbps → 迟滞档 76.8 Mbps；r=38 → 73.0；r=36 → 69.1——全部仍高于 41 Mbps 份额 1.7–1.9×，**即使 hrtimer 桶也不跌破运行份额**（这是 4ms 档对迟滞鲁棒的定量表述）。
- 两种后端（粗/hrtimer）的因子区间 [80%, 100%] 都不构成份额风险；危险区只在 T<J 的子倍数配置（因子 ≤25%）——「亚 G 间隔铁律」（0013）的机理表述。

## 四、全 HZ 鲁棒性与份额安全带

| HZ | J (µs) | T=4000 因子 | eff r=40 | eff r=38 | eff r=36 | 安全带判定 |
|---|---|---|---|---|---|---|
| 100 | 10000 | 40% | 38.4 | 36.5 | 34.6 | **跌破 41 份额** |
| 250 | 4000 | 100% | 96.0 | 91.2 | 86.4 | ✓ |
| 300 | 3333 | 60% | 57.6 | 54.7 | 51.8 | ✓（勉强） |
| 500 | 2000 | 100% | 96.0 | 91.2 | 86.4 | ✓ |
| 1000 | 1000 | 100% | 96.0 | 91.2 | 86.4 | ✓ |

- HZ∈{250,500,1000}（服务器/容器主流配置）全部 100% 因子；HZ=100/300 这类罕见配置下 4ms 仍保住份额（除 HZ=100 极端）。
- 与 0013 的 G=4000 反推自洽：官方四出分点只在 HZ=250 系（J=4ms）假设下同时命中；本文给出**即使猜错 HZ 也不会塌方**的鲁棒性证明——4000µs 对 {250,500,1000} 平台点免疫，对 {100,300} 有份额级容错。

## 五、相位同步的第二后果：碰撞从抽奖变窗口

refill 锁死在 tick 相位 → 我方 4ms 爆发窗口固定在 tick+ε 相位 → 背景事件（同样受 tick 调度的定时器流量）与我方的相位关系是**确定性的**：

| 场景 | 爆发线上时长 | 占空比=碰撞概率上界 |
|---|---|---|
| 满需求 r=40 | 4.144 ms | 103.6%（必然重叠） |
| 满需求 r=38 | 3.937 ms | 98.4% |
| 满需求 r=36 | 3.730 ms | 93.2% |
| **运行点 41 Mbps（r≈17/4ms）** | **1.761 ms** | **44.0%** |

1. 满需求下背景事件几乎必撞（与 0080 §三占空比表同构，互相印证）；
2. **运行点 44%**：0076 的「坏相位侵蚀」（丢包阈值 28.5→18.5 包）在此获得相位概率口径——不是所有背景突发都坏，坏的是落在爆发相位的 44%；
3. 确定性窗口意味着**自适应调参可利用相位信息**（如果背景流也是 tick 锁定的，相位差恒定，可测可避——但官方背景流生成器相位不可观测，仅作机理枚举）。

## 六、对参数与答辩的含义

1. **4000µs 是「双网格共振 + 迟滞钝感」的最优点**，答辩口径：「不是拍脑袋的整数值：它是 250Hz 与 1000Hz 两个时钟网格的公共整数倍——内核配置猜对猜错速率都 100% 兑现，且对 1ms 级唤醒迟滞折损封顶 20%」。
2. **「亚 G 间隔 ≥4000µs 铁律」的完整机理链**（0013 现象 → 0076 别名 → 0081 闭式）：ceil 语义把 T<J 的配置确定性拖到 J，因子 = T/J（25% 对 1ms@250Hz）；hrtimer 后端则把折损变成 δ̄/(T+δ̄)（50% 对 1ms）。两条路径都指向同一个禁区。
3. **r=38/36 降档的双保险确认**：0080 证明其修复「占空比 >1」，0081 证明其在迟滞档（73/69 Mbps）仍保有份额余量 1.8×——速率微调不影响鲁棒性结构。
4. **token_bucket 与 leak_bucket 的 refill 语义差异**：token 桶 refill r/4ms 的名义速率同样受 G 网格支配（若走粗定时器），但 tb 有 `enable_n_in_flight` 旁路（leak 没有）→ 空管道时绕过定时器 → 启动期与恢复期不受 4ms 网格束缚（0013 的 S3 1:1 实测即旁路效应）。4000µs 把「必须走定时器的部分」也送到共振点。

## 七、结论与合规口径

1. **共振命题**：T=4000µs ∈ Z×J(250Hz) ∩ Z×J(1000Hz)，粗定时器零量化损失（MC 验证 std<0.2µs），hrtimer 折损封顶 20%——双后端、双 HZ 全区间安全。
2. **机理链闭环**：0013（G=4000 反推）→ 0076（别名/聚簇）→ 0081（ceil 闭式 + 相位锁定 MC + 迟滞一阶不敏感）。
3. **相位碰撞**：占空比=碰撞概率上界；运行点 44%，满需求 93–104%。
4. **合规**：全部为公开内核定时器语义（add_timer/msecs_to_jiffies ceil 语义为公开行为）+ 确定性 MC（stdlib random，seed=42）；无远程探测、无环境修改；官方 HZ/定时器后端不可观测，已按双网格包络呈现。

## 八、风险与未决

- 官方 HZ 与定时器后端（粗 vs hrtimer）不可观测：本文以「双网格交集 + 双后端包络」免疫该未知，但 80% 因子是否真实发生无法从本侧验证（0068 的 77–87% 是间接锚）。
- 相位碰撞表假设背景事件相位均匀：若背景流生成器也 tick 锁定且相位与 refill 对齐，实际碰撞率会高于/低于 44% 的均匀估计；官方背景流相位不可观测。
- 自重装 ε∈[0,0.5]µs 为 IRQ 迟延的示意建模；真实 ε 不影响 LOCKED/QUANTIZED 判定（阈值 1µs 远大于 ε 上界）。
- 若官方 pacer 用 `hrtimer_nanosleep`/CLOCK_MONOTONIC_COARSE 混合路径，因子介于 [80%,100%]，方向不变、数值不闭环——需官方实现细节，超授权范围。
