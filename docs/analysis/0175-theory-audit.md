# 0175 理论审计：跨轮次排队时延增量的贝叶斯序贯更新模型与置信度更新

## 1. 正态-反伽马共轭先验动力学
设信道排队附加时延 $X \sim \mathcal{N}(\mu, \sigma^2)$。
先验参数由云端 $n=15$ 大样本校准获得：$\mu_0 = 12.4\text{ms}, \kappa_0 = 15, \alpha_0 = 7.5, \beta_0 = 45.0$。
当获得 Shot 1 真实出分映射的排队样本 $x_1$ 时，后验参数序贯更新方程为：
$$\kappa_1 = \kappa_0 + 1, \quad \mu_1 = \frac{\kappa_0 \mu_0 + x_1}{\kappa_1}$$
$$\alpha_1 = \alpha_0 + 0.5, \quad \beta_1 = \beta_0 + \frac{\kappa_0 (x_1 - \mu_0)^2}{2 \kappa_1}$$

## 2. 后验收敛测算
运行 `zcode/scripts/bayes0175_sequential_rtt_update.py`：
- **先验期望方差**：$6.92\text{ ms}^2$；
- **Shot 1 观测注入后后验期望方差**：收缩至 $6.53\text{ ms}^2$（**降幅 -5.75%**）；
- **95% 贝叶斯可信区间**：由 $[11.07\text{ms}, 13.73\text{ms}]$ 收敛至 $[11.07\text{ms}, 13.58\text{ms}]$（**区间宽度收缩 6.00%**）。

## 3. 结论
贝叶斯序贯更新机制在单发反馈后立即使后验不确定性有效下降，为后续轮次微调提供了动态数学支撑。
