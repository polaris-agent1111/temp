## 二、解析偏导矩阵（核心交付）

在基线点 $(RTT_0{=}70\text{ms},\ R{=}96\text{M},\ \rho{=}1)$ 处的偏导数矩阵，弹性形式 $S_{ij}=\partial\ln O_i/\partial\ln I_j$：

| 输出 $O_i$ | $\partial O_i/\partial RTT$ | RTT 弹性 | $\partial O_i/\partial\varphi$（相位） | $\partial O_i/\partial\rho$ | $\partial O_i/\partial R$ |
|---|---|---|---|---|---|
| $O_1$ BDP | $+10.417$ pkt/ms（+1.43%/ms） | **+1.000** | 0（流体内生无相位） | 0 | 0 |
| $O_2$ 在途窗 $W$ | $+10.000$ pkt/ms（+1.43%/ms） | **+1.000** | 0 | 0 | +1（随 $R$） |
| $O_3$ 恢复时间 $T_{\text{rec}}$ | **0（RTT 不变式）** | 0 | 0 | 0 | $+24.0$ ms/Mbps（弹性 −1，经 $C-R$） |
| $O_4$ 恢复轮次 $n_{\text{rtt}}=T_{\text{rec}}/RTT$ | $-0.0196$/ms | **−1.000** | 0 | 0 | 0 |
| $O_5$ 自排队底噪 $E[D_q]$（M/D/1） | **0（只依赖 $R/C$）** | 0 | 0 | 0 | $\rho_q{=}0.96\Rightarrow E[D_q]{\approx}1.25$ ms；$R{\to}C$ 时爆炸 |
| $O_6$ 6.bin 完成时 $T_6$（碰撞通道） | $+0.584\rho\kappa$ ms/ms $\approx+0.0006\rho$ s/ms | **≈+0.002** | 0（流体） | **+1.0（主导）** | 经 $T_{\text{rec}}$、$\rho_{\text{pipe}}$ |
| $O_7$ 突发模式峰队 $Q_{\text{peak}}$ | 0* | 0* | $-\mu_s=-10.42$ pkt/ms（线性区） | +1（背景体量） | ≈−0.04 |

*RTT 进入突发模式的唯一通道是「每秒突发机会数 $\propto 1/RTT$」（1–4.bin 慢启动墙钟弹性 −1；65→75ms 全程仅 ±0.2 轮）。

### 2.1 各条目推导要点

1. **$T_{\text{rec}}$ 的 RTT 不变式（§三 表最重要的 0）**：$T_{\text{rec}}=BL/(C-R)$ 只由缓冲区容量与排空余量决定。RTT 抖动不改变恢复时间，只改变「以 RTT 计的恢复轮次」$n_{\text{rtt}}=96/RTT$（65→75ms：1.48→1.28 轮）。**设计含义：排空余量才是恢复速度的唯一杠杆**，$R$ 每上探 1Mbps，$T_{\text{rec}}$ 从 96ms 涨 24ms（本地有限差分 4→3Mbps 时 +32ms，非线性放大）。
2. **自排队底噪（96M 稳态的固有排队）**：确定性 pacing ≈ D 服务，$\rho_q=R/C=0.96$，M/D/1 期望积压 $E[N_q]=\rho_q^2/2(1-\rho_q)=11.52$ pkt，$E[D_q]\approx1.25$ ms——**只依赖比值 $R/C$，与 RTT、相位无关**。这是 96M 设计的不可消除底噪，也是 4% 余量的代价。
3. **碰撞通道（巨流）**：采用 0051 定标的一阶代价模型（每条 28MB 巨流代价 $T_{\text{starve}}=V_g/C=2.24$ s + 满队列恢复 $T_{\text{rec}}$ + $\kappa$ 次 RTT 级反应停顿）：
   $$E[T_6]=T_{6,\text{base}}+\lambda_g\rho\,T_{\text{win}}\,(2.24+0.096+\kappa\cdot RTT),\qquad T_{6,\text{base}}=26.667\text{ s}$$
   对 RTT 的偏导只经 $\kappa\cdot RTT$ 项进入：$\partial E[T_6]/\partial RTT_{\text{ms}}=0.584\rho\kappa\times10^{-3}$ s/ms（$\kappa=1$）。
4. **相位偏移 $\varphi$（突发叠加区，1–4.bin token-burst 模式）**：两条线速串行化序列叠加，重叠期队列以 $\mu_s$ 增长；我方 60 包突发（实测弹性界 $B^*{=}60$）已自吸收（无稳态积压），故
   $$Q_{\text{peak}}(\delta)=\min\big(b_{\text{bg}},\ \max(0,\ 60-\mu_s\delta)\big)\quad(\delta\le 5.76\text{ ms})$$
   线性区 $\partial Q_{\text{peak}}/\partial\delta=-\mu_s$：**每 +1ms 相位偏移削减 10.42 包峰值队列**；丢包需要同时满足 $b_{\text{bg}}>40$ 且 $\delta<1.92$ ms——脆弱窗 $W_{\text{vuln}}=(60-B)/\mu_s=1.92$ ms，仅占 RTT 的 2.7%（每周期碰撞概率的 RTT 弹性为 −1）。

## 四、敏感度排序与工程结论

$$\underbrace{\rho\ (\text{背景密度})}_{\text{弹性}+1.0\ \text{— 主导}}\ \gg\ \underbrace{(C-R)\ (\text{排空余量})}_{T_{\text{rec}}\ \text{弹性}-1\ \text{— 设计杠杆}}\ \gg\ \underbrace{RTT\ \text{摄动}}_{\text{有效弹性}\approx0.002}\ >\ \underbrace{\varphi\ (\text{相位})}_{\text{仅突发丢包界，脆弱窗}2.7\%}$$

1. **RTT±5ms 对 6.bin 的总效应 ≈ ±6ms（ρ=2、κ=1）**，对比官方同配置 σ_eval ≥0.14s——**RTT 摄动在统计上不可分辨**，不构成复测方差的可归因来源。
2. **σ_eval 的物理主源是 ρ（巨流碰撞代价 2.24s/条 × 泊松计数涨落）**——这把 0051 的 ρ 模型与 0065 的 σ 情景带在机理上闭环：σ_eval ≈ $T_{\text{starve}}\times\sqrt{\lambda_g\rho T_{\text{win}}}$ 量级。
3. **若未来微调 $R$**：每 +1Mbps（余量 4→3），$T_{\text{rec}}$ +24ms、$\rho_q$→0.97（自排队 +3.4 包），边际收益是碰撞概率下降、代价是恢复变慢与底噪上升——96M 处于 $T_{\text{rec}}$/$\rho_q$ 的平坦区，±1Mbps 内无悬崖（与「要求邻域稳定」纪律一致）。
4. **突发模式（1–4.bin）的丢包风险不来自 RTT 摄动而来自相位对齐**：只有背景突发落进我方突发后 1.92ms 内且体量 >40 包才穿 40 包缓冲。RTT 变化反而以 −1 弹性降低每周碰撞概率。

## 五、边界与假设声明（诚实口径）

- 一阶碰撞代价模型沿用 0051 定标（$V_g/C=2.24$ s/条），它已被官方出分锚定（$T(\rho)=T_p/(1-g\rho)$，$g=0.04909$）；本报告**不重新标定背景流**，只在其上做 RTT/相位摄动。
- 包级叠加采用「线速串行化序列」理想化；真实 QUIC/背景 TCP 的 AIMD 动力学未建模（对峰值队列是保守化：AIMD 背景在碰撞后回退，实际 $Q_{\text{peak}}$ 低于本模型）。
- M/D/1 底噪假设确定性 pacing；实际定时器 4000µs 粒度引入的微突发（227 场基线族）会使底噪略高于 1.25ms，但不改变 RTT 不变性（粒度不是 RTT）。
- $\kappa$（每次碰撞的 RTT 级反应停顿数）取 1；κ=2 时 RTT 通道加倍，仍是 ρ 效应的 1/200 量级，排序不变。
