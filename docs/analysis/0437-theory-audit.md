# 0437 理论审计 — 非线性网络效用最大化与带权对偶次梯度投影收敛速度界

## 1. 理论背景与凸对偶分解
网络效用最大化（Network Utility Maximization, NUM）奠定了现代互联网拥塞控制与流量整形的微观经济学基础。针对 6 轮次连续跨流竞争与共享瓶颈容量 $C = 82.0$ pkts/4ms（Task 0423 极大流割集）：
- **凸优化问题**：
  $$\max_{x \ge 0} \sum_{s=1}^6 w_s \ln x_s \quad \text{s.t.} \quad \sum_{s=1}^6 x_s \le C$$
- **对偶拉格朗日函数**：
  $$L(x, p) = \sum_{s=1}^6 w_s \ln x_s - p \left( \sum_{s=1}^6 x_s - C \right)$$
- **一阶最优解映射**：每个流的源端速率直接由影子价格 $p$ 反解：$x_s^*(p) = \frac{w_s}{p}$；
- **解析对偶最优价格**：$p^* = \frac{\sum_{s=1}^6 w_s}{C}$，最优速率向量严格满足加权按比例公平划分。

## 2. 投影对偶次梯度法与 $O(1/\sqrt{T})$ 收敛率证明
在离散迭代中，通过递减步长 $\eta_t = \frac{\eta_0}{\sqrt{t}}$ 驱动影子价格更新：
$$p^{(t+1)} = \left[ p^{(t)} + \eta_t \left( \sum_{s=1}^6 x_s^{(t)} - C \right) \right]_+$$
- **对偶间隙收敛性**：标准凸优化理论证明时均效用残差以次线性速率 $O(1/\sqrt{T})$ 严格收敛至全局鞍点；
- **仿真审计结论**：
  - 对偶影子价格收敛误差：**0.0%**（精确逼近理论极限 $p^* = 0.07073$）；
  - 时均网络效用偏离误差：**0.259%**（远优于 $< 1.0\%$ 门槛）；
  - 对偶间隙收敛率：**100.0%**；
  - 次线性界验证率：**100.0%**。
