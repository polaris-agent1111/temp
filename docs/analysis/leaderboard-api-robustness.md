## 二、逐发打榜 30 秒轮询退避模型设计

- **轮询间隔设定为 30 秒**：
  - 官方评测出分延迟通常为 25~35 分钟；
  - 30 秒轮询一次，全周期产生约 50~70 次 HTTP GET 请求，平均每秒仅 0.033 次请求，完全处于防爬安全阈值之内；
- **指数退避重试机制（Exponential Backoff）**：
  - 发生超时（Timeout > 5s）或 HTTP 5xx 错误时，采用指数退避：第 1 次等待 10s，第 2 次等待 20s，第 3 次等待 40s；
  - 连续 3 次失败触发警告并维持 60s 慢速保活轮询；
- **超时熔断保护**：
  - 设定 50 分钟出分超时硬保护，若官方队列堵塞超 50 分钟未出分，自动暂停下一发提交，保护后续额度。
