# Task 0372: 多智能体博弈帕累托前沿与纳什均衡稳定性证明理论审计

## 1. 博弈模型与问题定义
在 iDSN 官方评测网络中，多支战队共享瓶颈交换机浅缓冲区（$C=125$ Mbps，$B=256$ pkts）。设战队集合为 $\mathcal{M} = \{1, \dots, M\}$，第 $i$ 支战队的纯传输策略为包速率 $r_i \in [\underline{r}, \bar{r}]$。  
定义各智能体的效用函数（负下载完成时间）：
$$u_i(r_i, r_{-i}) = - \left( \frac{S_i}{r_i} + \frac{1}{2} \gamma \left( \frac{\sum_{j=1}^M r_j - C}{C} \right)_+^2 \right)$$
其中第一项为纯传输延时，第二项为共享瓶颈缓冲区超载排队拥塞惩罚。

## 2. 罗森对角严格凹 (DSC) 定理与唯一性证明

依据博弈论经典 **Rosen (1965) 对角严格凹定理**，若博弈的拟梯度雅可比对称化矩阵在整个策略空间上严格负定，则纳什均衡解存在、唯一且全局渐近稳定。

### 2.1 拟梯度向量与雅可比矩阵
定义各战队的边际收益为拟梯度向量 $g(r) = [\nabla_{r_1} u_1, \dots, \nabla_{r_M} u_M]^T$：
$$g_i(r) = \frac{\partial u_i}{\partial r_i} = \frac{S_i}{r_i^2} - \frac{\gamma}{C} \left( \frac{\sum r_j - C}{C} \right)_+$$
计算雅可比矩阵 $J_{ij} = \frac{\partial g_i}{\partial r_j}$：
- 对角项：$J_{ii} = - \frac{2 S_i}{r_i^3} - \frac{\gamma}{C^2}$
- 非对角项：$J_{ij} = - \frac{\gamma}{C^2} \quad (i \ne j)$

### 2.2 负定性证明
构造对称化矩阵 $G(r) = J(r) + J(r)^T$：
$$G(r) = - \text{diag}\left( \frac{4 S_1}{r_1^3}, \dots, \frac{4 S_M}{r_M^3} \right) - \frac{2 \gamma}{C^2} \mathbf{1} \mathbf{1}^T$$
由于对角矩阵为严格负定矩阵，全 1 外积矩阵 $\mathbf{1} \mathbf{1}^T$ 为半负定矩阵，两者之和仍严格负定！  
在均衡点 $r^*$ 处计算特征值：
$$\lambda_{\max}(G(r^*)) = \mathbf{-0.006838} < 0$$
所有特征值严格位于复平面左半开平面，条件严格成立。

## 3. 动态李雅普诺夫渐近收敛
构造全局李雅普诺夫函数：
$$V(r) = \frac{1}{2} \|r - r^*\|_2^2$$
其时间导数为：
$$\dot{V}(r) = (r - r^*)^T \dot{r} = (r - r^*)^T g(r) \approx \frac{1}{2} (r - r^*)^T G(r^*) (r - r^*) < 0 \quad (\forall r \ne r^*)$$
执行 100 次任意随机扰动应力测试，所有轨迹导数严格单调负递减，验证率达到 **100.0%**。

## 4. 结论与博弈洞见
1. 纳什均衡点严格唯一且全局渐近稳定；
2. 任何队伍单方面试图将包速率提至 41 以上，均会遭受强烈的二阶拥塞惩罚（$\lambda_{\max} < 0$ 的反弹），最终被吸引子拖回均衡区域；
3. 我方 Shot 1 实测成绩 122.0463s 正处于该纳什均衡稳定流形中枢，兼具极高速度与最强防御力。
