# 任务 0464 理论审计报告：浅缓冲区互补约束 Fischer-Burmeister 平滑阻尼牛顿法

## 1. 理论背景与数学推导
在 6 阶段 QUIC 穿柜整形中，发送速率分配与浅缓冲区溢出约束天然构成非线性互补问题（NCP）：
求向量 $x \ge 0, F(x) \ge 0$，使得 $x^T F(x) = 0$。
其中 $x_i$ 为阶段 $i$ 的最优发包速率，$F_i(x) = C_i - q_i(x)$ 为交换机缓冲区剩余裕度。当队列未满（$F_i(x) > 0$）时，拥塞代价为 0（$x_i$ 可自由调整）；当缓冲区饱和溢出（$F_i(x) = 0$）时，强加背压约束。

### Fischer-Burmeister C-函数及其平滑化
经典的 Fischer-Burmeister 函数定义为：
$$\phi(a, b) = a + b - \sqrt{a^2 + b^2}$$
其核心代数性质为：$\phi(a, b) = 0 \iff a \ge 0, b \ge 0, ab = 0$。
由于根号在原点不可微，引入摄动参数 $\mu > 0$ 构造光滑同伦逼近：
$$\phi_\mu(a, b) = a + b - \sqrt{a^2 + b^2 + 2\mu^2}$$
其偏导数处处连续：
$$\frac{\partial \phi_\mu}{\partial a} = 1 - \frac{a}{\sqrt{a^2 + b^2 + 2\mu^2}}, \quad \frac{\partial \phi_\mu}{\partial b} = 1 - \frac{b}{\sqrt{a^2 + b^2 + 2\mu^2}}$$

### 阻尼牛顿迭代与 Armijo 线搜索
对于给定的同伦参数 $\mu$，构造方程 $\Phi_\mu(x) = 0$，牛顿方向满足：
$$J_\mu(x_k) \Delta x_k = -\Phi_\mu(x_k)$$
结合 Armijo 回溯步长准则：
$$\|\Phi_\mu(x_k + \alpha_k \Delta x_k)\|^2 \le (1 - \sigma \alpha_k) \|\Phi_\mu(x_k)\|^2$$
当 $\mu \to 0$ 时，同伦轨迹全局收敛到原 NCP 问题的精确解。
