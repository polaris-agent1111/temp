# 任务 0480 理论审计报告：动态贝叶斯网络 (DBN) 隐式丢包原因因果推断辨识

## 1. 理论背景与数学推导
在穿柜 QUIC 流量整形中，数据流发生丢包时存在两类物理根因：
1. **浅缓冲区瞬态拥塞丢包（Congestion Loss, $S=1$）**：由微突发流量灌满物理交换机缓冲区造成，伴随高排队时延（RTT 激增）和吞吐量折损；
2. **随机物理误码/链路丢包（Random Dropout, $S=2$）**：由传输介质位翻转或偶发校验失败引起，此时缓冲区为空，排队时延处于基线水平，物理吞吐量未饱和。

传统拥塞控制（如 CUBIC / Reno）遇丢包一律将 CWND 减半，导致在随机丢包场景下误触惩罚性降速；
而若在拥塞丢包时误判为随机丢包不作减速，又会引发缓冲区击穿持续恶性丢包。

### 动态贝叶斯网络 (DBN) 拓扑与隐马尔可夫模型
设 $t$ 时刻隐状态为 $S_t \in \{0: \text{正常}, 1: \text{浅缓冲区拥塞}, 2: \text{随机误码}\}$。
多维联合观测向量 $Y_t = (L_t, D_t, T_t)$，其中：
- $L_t \in \{0, 1\}$：丢包事件指示；
- $D_t \in \mathbb{R}^+$：端到端往返排队时延；
- $T_t \in \mathbb{R}^+$：瞬时交付吞吐量。

### 前向-后向置信度传播 (Forward-Backward Belief Propagation)
定义前向变量 $\alpha_t(i) = P(Y_{1:t}, S_t = i)$ 与后向变量 $\beta_t(i) = P(Y_{t+1:T} \mid S_t = i)$：
$$\alpha_t(j) = \left[ \sum_{i} \alpha_{t-1}(i) A_{ij} \right] B_j(Y_t)$$
$$\beta_t(i) = \sum_{j} A_{ij} B_j(Y_{t+1}) \beta_{t+1}(j)$$
后验因果平滑概率为：
$$\gamma_t(i) = P(S_t = i \mid Y_{1:T}) = \frac{\alpha_t(i) \beta_t(i)}{\sum_j \alpha_t(j) \beta_t(j)}$$
