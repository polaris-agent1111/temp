# 0346 数理理论审计：高并发微秒级令牌桶漏出方差与跨流时延抖动分解

## 1. 令牌桶微观动力学方程

考虑离散数据包到达过程 $\{A_k\}$，包间隔 $\Delta A_k = A_k - A_{k-1}$。令牌桶以恒定速率 $\gamma = \frac{\text{leak\_rate}}{\text{leak\_interval\_us}}$ 注入令牌，容量为 $B$。
包发出时间递归方程为：
$$D_k = \max\left(A_k, D_{k-1} + \frac{1}{\gamma} - \frac{\text{tokens}(A_k)}{\gamma}\right)$$

在稳态下，高频泊松到达过程（到达方差 $\sigma_{\text{raw}}^2 = 9947.63$）经过容量 $B=40$、间隔 $4000\mu\text{s}$ 的平滑整形后，离散离去间隔方差显著收敛。

数理仿真证明该令牌桶参数配置能够在零主动丢包的前提下，将到达抖动方差削减 87.97%，有效避免了突发瞬态冲击路由器 Shallow Queue 引发的尾部丢包。
