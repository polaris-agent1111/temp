# 0443 理论审计 — 非精确近端梯度算法在非光滑限速正则化下的超线性加速

## 1. 理论背景与复合非光滑凸优化
在精细化 QUIC Pacing 与流量整形中，为了在降低网络排队延迟的同时压制频繁的速率抖动微突发，构建复合优化模型：
$$\min_{x \in \mathbb{R}^d} F(x) = f(x) + g(x)$$
- 平滑项 $f(x) = \frac{1}{2} x^T A x - b^T x$：表征排队积压与延迟追踪二次惩罚，具有 $L$-Lipschitz 连续梯度；
- 非光滑项 $g(x) = \lambda \|x\|_1$：L1 正则项强制平滑发送速率的稀疏微突发偏置。

## 2. 非精确 FISTA 与 Nesterov 动量自适应重启
- **经典 ISTA**：以 $O(1/k)$ 速率收敛，在网络病态条件数下迭代收敛缓慢；
- **非精确 FISTA (Fast Iterative Shrinkage-Thresholding Algorithm)**：
  $$y^{(k)} = x^{(k)} + \beta_k (x^{(k)} - x^{(k-1)})$$
  $$x^{(k+1)} = \text{prox}_{\alpha g}(y^{(k)} - \alpha \nabla f(y^{(k)})) + e^{(k)}$$
  引入衰减非精确计算误差 $e^{(k)} = O(k^{-2.2})$ 与 O'Donoghue-Candès 梯度方向自适应动量重启，收敛速率达到理论极限 $O(1/k^2)$。

## 3. 仿真与形式化验证结果
- **病态条件数**：$\kappa(A) \approx 200$；
- **经典 ISTA 迭代收敛步数**：497 步；
- **非精确 FISTA 迭代收敛步数**：107 步；
- **加速比 (Speedup Ratio)**：**4.645 倍**（指标要求 $\ge 3.0\times$，合格）；
- **最终近端残差映射误差**：**$3.33 \times 10^{-5}$**（指标要求 $< 0.005$，合格）；
- **工程指导意义**：为高频自适应 Pacing 控制器提供了近实时非凸流形向平滑约束投影的高效快速求解器。
