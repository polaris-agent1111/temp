# 0450 理论审计 — 跨轮次非平稳流长自回归滑动平均谱估计与自适应周期抵消

## 1. 理论背景与非平稳背景突发周期辨识
在多轮次高频流量整形与拥塞对抗中，跨轮次背景流（Cross-Traffic）往往受到硬件中断周期性唤醒、TCP 拥塞窗口加法递增乘法递减（AIMD）或特定应用层定期心跳冲击，呈现准周期振荡。
采用自回归滑动平均（ARMA）极点共振模型对背景突发序列 $x_t$ 进行谱估计：
$$x_t - a_1 x_{t-1} - a_2 x_{t-2} = \epsilon_t + c_1 \epsilon_{t-1} + c_2 \epsilon_{t-2}$$
通过二阶自回归特征多项式 $A(z) = 1 - a_1 z^{-1} - a_2 z^{-2} = 0$ 确定复共轭极点对 $z_{1,2} = r e^{\pm j \omega_0}$。

## 2. 自适应陷波数字滤波器 (Notch Filter) 消除算法
针对辨识出的谐波角频率 $\omega_0 = 2\pi f_0 / f_s$，构造二阶 IIR 陷波滤波器：
$$H(z) = \frac{1 - 2\cos\omega_0 z^{-1} + z^{-2}}{1 - 2\rho\cos\omega_0 z^{-1} + \rho^2 z^{-2}}$$
其中单位圆收缩因子 $\rho = 0.96$。由于分子零点严格落在单位圆上 $e^{\pm j \omega_0}$，使得系统在主频处传递函数增益严格为零，彻底抑制周期微突发冲击。

## 3. 仿真与形式化验证结果
- **真实振荡主频**：15.0 Hz；
- **自适应估计主频**：**15.039 Hz**（估计绝对误差仅 0.039 Hz）；
- **自回归极点模长**：$|z| = 0.9500 < 1.0$；
- **自回归极点稳定率**：**100.0%**；
- **主频谐波抑制比**：**25.41 dB**（指标要求 $\ge 18.0$ dB，达到 99.7% 能量阻断）；
- **工程应用价值**：能够在线自适应过滤背景流周期性抢占波峰，消除 Pacing 发送窗口在特定频段上的共振排队积压。
