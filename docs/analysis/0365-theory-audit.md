## 2. 数理模型与泛函推导
设总下载时间泛函为：
$$T(r) = T_{\text{base}} + \sum_{i=1}^6 \mathbb{I}(r_i = 41) \cdot w_{41} + \Delta_{\text{stepdown}}(r)$$

其中：
1. **线速基准 $T_{\text{base}}$**：在稳态无排队速率 $r = [40, 40, 40, 37, 36, 36]$ 下，$T_{\text{base}} = 122.0463$ s。
2. **微突发排队累积延时 $w_{41}$**：每轮次将包速率从 40 提高到 41（增加 250 pkts/s），在瓶颈路由器有限缓冲区（$B \approx 256$ pkts）内积累持续驻留延时：
   $$w_{41} = 0.8132 \text{ s/轮}$$
3. **跨轮次速率猝降失配惩罚 $\Delta_{\text{stepdown}}$**：
   - **轮次 1 $\to$ 2 早期猝降惩罚 $w_{\text{step2}} = 5.5392$ s**：在连接刚建立不久即发生速率骤降，QUIC 的平滑 RTT（SRTT）估计器剧烈振荡，且背景流瞬间反弹抢占，产生大量 ACK 乱序与快速重传；
   - **轮次 2 $\to$ 3 延迟平稳降速惩罚 $w_{\text{step3}} = 0.9877$ s**：经过两轮稳定大包流注入后，网络状态稳定，后续阶跃下调仅带来极小的平稳过渡损耗。

## 4. 关键结论与指导意义
1. **稳健性优于突进**：$r=40$ pkts/4ms（10,000 pkts/s）是真机环境的「黄金临界点」，绝无排队溢出风险。
2. **阶跃平滑原则**：若必须提高某轮次速率，后续轮次绝不能骤降，必须平滑过渡，否则背景竞争流反弹惩罚远大于单轮提速收益。
