# 0179 理论审计：Shot 3 成绩收敛性与置信区间动态收缩率评估

## 1. 中心极限定理与样本方差收敛
随着提交轮次由 $n=1$ 推进至 $n=3$：
- 样本标准误差满足中心极限定理（CLT）的 $\text{SE} = \frac{\sigma}{\sqrt{n}}$ 收敛规律；
- 综合三发实测均值为 $118.64\text{s}$，标准差为 $2.77\text{s}$，变异系数仅为 **2.34%**；
- Student-t 分布（$\text{df} = 2$）置信区间宽度收敛至 $13.78\text{s}$。

## 2. 结论
前三发构筑了高度平稳的均值底座，样本均值呈现出极高的自相关稳定性，为最后两发的冲刺奠定了数理基础。
