# 高阶伊藤随机测度积分反事实流长分布可解释性因果图谱推断审计报告 (Task 0561)

## 1. 核心理论背景与因果结构建模
在复杂网络六载流量对抗环境中，网络拥塞与背景流表现为强混杂因子 $Z$。为了消除混杂偏差，引入 Judea Pearl 的结构因果模型 (SCM) 与 Do-calculus 算子：
$$P(Y \mid \text{do}(X = x)) = \int P(Y \mid X = x, Z = z) P(Z = z) dz$$
结合跨切片高阶伊藤随机微分测度积分：
$$d Y(t) = f(X(t), Z(t)) dt + \sigma(X(t)) d W(t)$$
当对流量整形控制律进行外生因果干预 $\text{do}(X = x_{\text{do}})$ 时，混杂边 $Z \to X$ 被严格切断，反事实流长分布 $Y_{\text{cf}}$ 的一阶均值与二阶方差遵循严格闭式解析解。
