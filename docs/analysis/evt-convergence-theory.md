## 一、问题设定与记号

官方竞赛取 5 次提交中的最优成绩计入排行榜。设某固定构型第 $i$ 次官方成绩为 $S_i$，则打榜成绩为

$$S_{\min}=\min(S_1,\dots,S_5).$$

任务目标：给出 $P\big(107 \le S_{\min} \le 118\big)$ 的区间估计（$107$ 对应全局理论下确界信封 106.597s 的取整，$118$ 对应冲冠目标带）。

注意两个不同层级的随机性：

| 层级 | 分布 | 已知离散度 |
|---|---|---|
| **本地单场** $X$ | 机器状态混合分布（时段/负载相关，**非 i.i.d.**） | 冠军族 sd ≈ 7.7s，p100M-96M 子集 sd ≈ 12.7s |
| **官方同配置** $S$ | 配置确定性 + 官方复测噪声 | 同配置官方极差 0.6–0.85s（v1/v1b、S4 复测口径） |

官方 $S$ 的离散度比本地小一个数量级——**这决定了用本地下尾拟合去预测官方极值分布必然过宽**，后文定量展示。

## 二、极值收敛定理（最小值方向的 Weibull–III 域）

**定理（Fisher–Tippett–Gnedenko，最小值方向 / type-III）。** 设 $X_1,X_2,\dots$ i.i.d.，分布函数 $F$ 的下端点 $x^*=\inf\{x:F(x)>0\}$ 有限，且在端点附近呈多项式行为

$$F(x)\;\sim\;c\,(x-x^*)^{\alpha},\qquad x\downarrow x^*,\quad c,\alpha>0 .$$

则样本最小值 $X_{(1)}=\min(X_1,\dots,X_n)$ 满足

$$\boxed{\;P\!\left(X_{(1)} > x^* + z\,n^{-1/\alpha}\right)\;\xrightarrow[n\to\infty]{}\;\exp\!\big(-c\,z^{\alpha}\big)\;}$$

即规范化最小值收敛到 Weibull 型（type-III）极值分布 $W_\alpha(z)=1-\exp(-cz^\alpha)$。

**证明梗概**（三步，均标准化）：

1. **尾估计**：由 $F(x)\sim c(x-x^*)^\alpha$，对 $x_n=x^*+z n^{-1/\alpha}$ 有 $F(x_n)\sim c\,z^\alpha/n$。
2. **最小值恒等式**：i.i.d. 下 $P(X_{(1)}>x_n)=\big(1-F(x_n)\big)^n=\Big(1-\dfrac{c z^\alpha+o(1)}{n}\Big)^{n}$。
3. **Poisson 极限**：$n F(x_n)\to c z^\alpha$ 且「落入 $(-\infty,x_n]$ 的次数」渐近 Poisson，故 $(1-F(x_n))^n\to e^{-cz^\alpha}$。∎

**推论 1（收敛速率）**：$E[X_{(1)}]\to x^*$，且 $E[X_{(1)}]-x^*=O(n^{-1/\alpha})$——极小值以多项式速率贴向下确界，**斜率由尾指数 $\alpha$ 决定**。

**推论 2（有限 n 的 Poisson 近似）**：对任意有限 $n$ 与小尾概率 $F(x)$，

$$P(S_{\min}\le x)=1-(1-F(x))^n\;\approx\;1-\exp\!\big(-n\,F(x)\big).$$

本文全部概率计算使用**精确恒等式** $1-(1-F)^n$（n=5 时 Poisson 近似误差 < 0.1%，可忽略）。

**适用性红线（必须声明）**：
- 定理要求 i.i.d. 且 $n\to\infty$。本赛题 $n=5$ 距渐近区极远，有限 n 修正项主导；下文所有概率以精确恒等式 + 经验/参数拟合给出，**不以渐近定理本身代替数值**。
- 端点行为 $F(x)\sim c(x-x^*)^\alpha$ 中 $x^*$ 未知且不可由 n=5 估计——这正是本报告用多模型交叉而非单模型定论的原因。

## 四、决定性因素：官方均值的敏感性（本地→官方断层）

冠军构型**从未有过官方成绩**（10 条官方记录全部为 leak/tb 常规构型），其官方均值 $\mu_{\text{off}}$ 未知。固定官方同配置噪声 $\sigma_{\text{off}}=0.7$s（实测 0.6–0.85），则

$$P(S_{\min}\in[107,118])=F_\Phi\!\Big(\tfrac{118-\mu}{\sigma}\Big)\text{ 的 5 发合并}\;-\;F_\Phi\!\Big(\tfrac{107-\mu}{\sigma}\Big)\text{ 的 5 发合并}$$

| $\mu_{\text{off}}$ (s) | $P(S_{\min}\le118)$ | $P\in[107,118]$ | $E[S_{\min}]=\mu-1.163\sigma$ |
|---:|---:|---:|---:|
| 116 | 100% | 100% | 115.19 |
| 117 | 100% | 100% | 116.19 |
| **118** | **96.9%** | **96.9%** | **117.19** |
| **119** | **32.9%** | **32.9%** | **118.19** |
| **120** | **1.1%** | **1.1%** | **119.19** |
| 121 | 0.005% | ≈0 | 120.19 |
| 125 | ≈0 | ≈0 | 124.19 |
| 131 | ≈0 | ≈0 | 130.19 |
| 134 | ≈0 | ≈0 | 133.19 |
| **141.25（leak 锚定外推†）** | ≈0 | **≈0** | 140.44 |

† leak 锚定外推：champ 族分文件中位数和 138.93s × (1+δ)，δ 取 leak 36/40 的本地→官方偏差 +1.67%（官方 133.086 / 本地中位和 130.90）→ **$\mu_{\text{off}}\approx141.25$**。若采用此校准，$P\approx0$。

**悬崖结构**：目标窗口 $[107,118]$ 的概率对 $\mu_{\text{off}}$ 呈 2 秒宽的悬崖（118→96.9%、119→32.9%、120→1.1%）。**整个问题等价于一个问题：冠军构型的官方均值到底在 118–119 还是在 120 以上。** 本地数据（两个假设之间相差 20s）无法裁决——这正是今晚 Shot 1（在途旁路探针）+ Shot 2（冠军构型首投）存在的意义：它们不是冲榜额度，是**分布定位器**。

## 五、对「106.597s 信封」的极值论审计（重要）

全局理论下确界 106.597s = 六个分文件**历史最优**之和（20.912 + 27.651 + 58.034），而这三段分别来自**不同构型、不同场次**的单场最小值。极值论视角下的严格表述：

- 分文件最小值 $m_k=\min_{r,k} X_{r,k}$ 的和 $\sum_k m_k$ 是**跨构型 min-of-mins 复合量**，不是任何一个可提交构型的抽样分布支撑点；
- 单场同时逼近六个分文件各自最优的联合概率 ≈ $\prod_k P(X_k\approx m_k)$，在每文件尾部概率 ~1–10% 量级下联合 ≪ 10⁻⁶（champ 族 31 场的实际最低总和为 128.352，距信封 21.8s）；
- 因此 **$[107,118]$ 的下段（<112.3s，历史本地极小值以下）在任何可信模型中概率为 0**；窗口概率实质集中在 $[116.5,118]$ 若且仅若 $\mu_{\text{off}}\approx118$。

## 六、结论

1. **$E[S_{\min}]=\mu_{\text{off}}-1.163\sigma_{\text{off}}\approx\mu_{\text{off}}-0.8\text{s}$**（σ=0.7）：**5 发抽极小值最多带来 ≈0.8s 的期望红利**——极值收敛速率由官方复测噪声决定，不由本地 7–13s 的散布决定。冲榜的本质是压低 $\mu_{\text{off}}$（换构型），不是多发几次（换手气）。
2. $P(S_{\min}\in[107,118])$：
   - 若 $\mu_{\text{off}}\approx118$（旁路假设完全成立）：**≈97%**；
   - 若 $\mu_{\text{off}}\approx119$：≈33%；若 $\mu_{\text{off}}\ge120$：**≤1%**；
   - 全部本地校准模型（Weibull MLE、champ 自举、正态近似）：**≈0–0.5%**；唯一给出大概率的是 p96 单孤立样本自举（41%，置信区间 [0.5%,45%]，不得单独采信）。
3. **数学收敛性**（定理部分）是严格成立的：i.i.d. + 端点多项式尾 ⟹ min-of-5 → Weibull-III → $x^*$。但 $n=5$ 处「渐近」尚未接管，$[107,118]$ 概率由 $\mu_{\text{off}}$ 的位置决定，而 $\mu_{\text{off}}$ 当前不可辨识。
4. **可证伪条件**（今晚自动裁决）：Shot 2（champ 首投）官方出分 $S_2^{off}$ 即 $\mu_{\text{off}}$ 的首个观测——若 $S_2^{off}\le120$ 则 5 发窗口概率进入可用区间；若 $S_2^{off}\ge124$（同配置噪声上限外）则本报告 §4 的 leak 锚定外推（≈141）被证实，$[107,118]$ 概率归零。

import json, math, random, statistics as st
rows=[json.loads(l) for l in open("runs/results.jsonl",encoding="utf-8") if l.strip()]
V=[r for r in rows if r.get("valid") is True and not str(r.get("tag","")).startswith("load-")]

random.seed(1107); N=200000; c=0
for _ in range(N):
    m=min(random.choice(champ) for _ in range(5))
    c += 107<=m<=118
print("P(min5 in [107,118]) champ-bootstrap =", c/N)
# official-noise sensitivity
Phi=lambda z:0.5*(1+math.erf(z/math.sqrt(2)))
for mu in (118,119,120,121):
    f=lambda x: Phi((x-mu)/0.7)
    p=(1-(1-f(118))**5)-(1-(1-f(107))**5)
    print("mu=%d -> P=%.4f"%(mu,p))
