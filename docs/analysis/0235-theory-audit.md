## 1. 结论摘要（先读）

1. **时序无关性定理成立**：本竞赛中各队出分由官方评测环境独立生成（队间无资源竞争、无出分耦合），榜单取全周期累计最好成绩。因此任何一队的 P(top1) 只取决于各队能力 (μ, σ) 与发数 n，**与发车时刻向量无关**。发车时序是「收益不变维度」：任意时序组合（含「Catnet 00:00 抢跑 × 我方 00:05」）都是纳什均衡，不存在针对我方时序的反制收益。蒙特卡洛 5×5 发车收益矩阵行/列极差（0.221/0.116 pp）落在 4×SE 噪声带（0.650 pp）内，验证通过。
2. **「任意对手抢跑下期望收益 ≥95%」的诚实拆解**：
   - **口径A（时序支配率）**：我方 00:05 逐发自适应在全部 5 个对手抢跑/延后情景下收益两两无差（且早发车在预算落袋上严格占优）→ **D = 100% ≥ 95% ✔**。这是该命题唯一成立的口径。
   - **口径B（P(top1) 绝对夺冠率）**：当前能力池下 **P(top1) ≈ 11%（固定构型）/ ≈18%（自适应搏分）**，对手进步情景 ≈15%，方差敏感性区间 1.8–24.9%。**远达不到 95%，且换任何发车时刻都不会改变它**。夺冠瓶颈在能力（μ/σ），不在时序。不粉饰。
3. **真实的反制通道只有三条二阶通道**，全部量化完毕（§4.2）：响应窗口（多日赛程下价值=0）、预算损耗（早发车期望多落袋 0.05–0.18 发）、后动信息（理性高方差反制使我方 P(top1) 从 11.5% 降至 9.3%，**集中在奇迹分支**）。
4. **闭环自适应是真实存在的收益来源**：模拟对照 17.84% vs 固定构型 10.98%（+62.5% 相对，E[best] +0.75s）；真实锚点是 11/07 shot1 探针 143.561 后自适应切换 leak 40/36 轰出 **124.3683（真实官方出分）**，单日闭环真实改善 ≥19s。

### 2.3 能力反推方法

由 best-of-n 观测反推单发能力：E[min of n] = μ + cₙ·σ，cₙ = E[min of n 个标准正态] < 0，故

**μ = best − cₙ·σ = best + |cₙ|·σ**

即单发能力均值必然**比历史最好成绩更差**（best-of-n 统计的基本方向）。cₙ 由 200 万次蒙特卡洛标定（c₁₅≈1.736、c₁₉≈1.815、c₇≈1.352）。

## 3. 博弈形式化与时序无关性定理

### 3.1 博弈要素

- **参与者**：我方 + 各对手队（建模 top-5：光明未来、Catnet、hashkimi、我也不想写实验报告、大肥鱼）。
- **策略空间**：每队每日 5 发预算；纯策略 = (发车时刻向量, 每发构型选择)。
- **收益**：P(top1) = P(我方当日新最好 < min(117.0257, 全部对手当日新最好))。
- **信息结构**：出分公示延迟 ~45–60min，榜单 30min 刷新；各队可读榜。

### 3.2 定理（时序无关性）

> 各队出分 X_ij 独立同分布且分布参数不依赖发车时刻 t_ij；榜单收益函数只依赖 (X_ij) 的实现值集合。则对任意时序剖面 t 与 t'，各队收益相同：
>
> u_i(μ, σ, n) = P( min_j X_ij < min(117.0257, min_{k≠i, j} X_kj) )，与 t 无关。

**推论（纳什均衡）**：时序子博弈中任何剖面都是 NE（无有利偏离）；博弈的全部策略内容在**构型菜单选择**（μ/σ 权衡）上。特别地，「Catnet 凌晨抢跑」对我方无可利用之处，「光明未来延后防御」对我方无可损伤之处——除非经由 §4.2 的三条二阶通道。

### 3.3 自适应策略模型（落后换高方差）

追逐远尾目标（需 min-of-5 < 117.03 < μ）时，P(X < T) = Φ((T−μ)/σ) 在 T < μ 时随 σ 递增，故闭环自适应的理性动作是：**落后 → 换高方差构型搏尾部；逼近门槛 → 中方差；达标 → 低方差巩固**。模拟策略严格只读「自己的」历史出分（与 00:05 逐发自适应一致，不读对手榜）。

## 6. 模型假设与局限（诚实清单）

1. **正态假设**：单发出分用 N(μ, σ) 建模。真实分布可能右偏重尾（11/07 我方有 155.16 的离群）。这主要影响 E[best] 的绝对值，对「时序无关性」（解析性质）无影响。
2. **对手 σ = 4.5s 为点假设**：依据是顶部梯队提交轨迹平滑（11/05 光明未来单日 5 连发未刷新当日最好，`runs/leaderboard/monitor.md`）。已做 σ ∈ [3,7] 敏感性（§4.5）。
3. **单观测家族**：fallback（leak 40/36）官方仅 1 发真实出分，μ/σ 粗估；不影响主推 champ 口径的核心结论。
4. **静态能力假设**：反推 μ 不含对手学习/进步；已补「对手进步 2s」情景（15.46%）。
5. **无时段效应假设**：假设官方评测环境不存在随时刻变化的系统差异（官方固定拓扑与背景流，且未观测到时段相关出分模式）。若存在时段效应，结论需按实测重估——但按合规红线，任何按时段「挑选」评测条件的做法本身不可取。
6. **蒙特卡洛噪声**：各实验 n=4 万–20 万，95% CI 已随表给出；所有情景间比较均以 CI 重叠判断，未引用单次最小值。
7. **本文件所有模拟分数（E[best]、P(top1) 等）均为模拟值**，与真实官方成绩严格分离；真实数据仅 §2 引用的榜单与出分记录。
