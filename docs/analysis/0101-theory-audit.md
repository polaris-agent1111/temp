## 五、结论边界（本审计最重要的部分）

### 5.1 功效模拟：n=4/5 的 Shapiro-Wilk 几乎没有检出力

按 M1 残差量纲标准化、α=0.05、N=4000 次蒙特卡洛：

| 备择分布 | 拒绝率 |
|---|---|
| 正态（基准，应≈5%） | 0.052 |
| t(3) 重尾 | **0.070** |
| lognormal（σ=0.55）偏态 | **0.088** |
| 均匀（短尾） | 0.060 |

即使真实误差是 t(3) 或 lognormal，本检验也只有 **7%~9%** 的概率拒绝。因此本审计的结论只能是「**未发现拒绝正态性的证据**」，在任何意义上都不构成「误差为 i.i.d. 正态」的证明。要达到 80% 功效检出 lognormal 级偏态，n 需约 40+ 发官方出分——超出台规单日 5 发额度，只能跨日累积或改用本地重尾建模。

### 5.2 与既有 σ 估计的一致性

M1 残差 sd=9.13s 与 0084 的官方单发噪声 σ_d≈7.0s、同日校准漂移 ±7.4s 相容：残差方差 ≈ 本地池方差贡献 + 官方单发噪声。M1 均值 −0.45s ≈ 0 亦与 0084「同日官方 ≈ 真本地 +2.5±7.4s」的中心偏移在 1 个标准误（9.13/√4≈4.6s）内相容。**两条独立证据链交叉自洽。**

### 5.3 独立性破绽（必须向复测门禁声明）

- Shot 4/5 同构型复测 → M1 残差共享同一预测值，两残差正相关，有效 n<4；
- 五发在 80 分钟内连续打出，共享同一天的服务器状态（00:05–01:24），跨日方差成分未被采样；
- M2/M3 残差继承同一组官方出分，三组检验不独立，不能联合声称「三重验证」。

### 5.4 对官方「重复多次取平均 + top 复测」门禁的含义

1. **预测区间加厚**：即使接受正态近似，n=4 估计的 sd=9.13s 自身有巨大不确定性（χ²(3) 下 95% CI 约 [4.7s, 40s]）；复测门禁应按 t(3) 分布给出预测区间（如单发 95% 区间 ≈ mean ± 3.18×9.13 ≈ ±29s），而非正态 ±1.96σ。
2. **禁止极值红利**：M1 残差含 +11.6s 与 −10.2s 两个近对称大偏离——同一构型两发可差 15.1s（Shot 4 vs 5），复测排名波动 ≥1 个名次是常态，选型必须按均值/中位数（AGENTS.md 口径），本审计数据再次实证该纪律。
3. **建议**：复测合规评估用**自助法**（对 M1 残差 bootstrap 10⁴ 次）替代正态分位数推断；该结论对 0091（复测抽样效能）与 0097（Bootstrap 方差估计）构成输入。
