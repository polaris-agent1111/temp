# Theory Audit 0497: 分数阶非线性薛定谔势阱孤子演化 (Fractional NLSE Soliton Evolution)

## 1. 理论背景与数学推演
在浅缓冲区微观流控中，高频发包与突发跨流形成的队列密集波包可被建模为非线性薛定谔方程 (NLSE) 中的空间亮孤子（Bright Soliton）波形。
其主导演化偏微分方程为：
$$i \frac{\partial \psi}{\partial t} = - \frac{1}{2} (-\Delta)^{\alpha/2} \psi - |\psi|^2 \psi$$
其中：
- 算子 $(-\Delta)^{\alpha/2}$ 为分数阶 Riesz 拉普拉斯算子，在空间傅里叶波数域对应对角相乘因子 $|k|^\alpha$；
- 非线性项 $-|\psi|^2 \psi$ 代表 FIFO 队列的自聚焦压缩势，抵消色散展宽效应；
- 系统的李雅普诺夫能量泛函具备完全守恒的 $L^2$ 质量范数（包守恒律）：
  $$N(t) = \int_{-\infty}^\infty |\psi(x, t)|^2 dx \equiv N(0)$$
- 当 $\alpha = 2$ 时，系统具备解析亮孤子基态解：
  $$\psi(x, t) = \text{sech}(x) e^{i t / 2}$$
  波包包络 $|\psi(x, t)| \equiv \text{sech}(x)$ 在时间演化中保持零畸变传输。

数值求解采用严格保酉性（Unitary Preserving）的 Strang 分裂步傅里叶方法 (Symmetric Strang Splitting Spectral Method)，在实空间与频空间之间交替传递相因子，理论保酉误差仅受计算机 IEEE-754 浮点精度限制。

## 2. 实验数值验证与指标
- 仿真算法：高精度对称 Strang 分裂步傅里叶辛积分算法 (Time step $\Delta t = 0.5$ us, $N_x = 512$)
- 初始质量 $N(0)$：**2.000000**，演化终态质量 $N(T)$：**2.000000**
- $L^2$ 质量守恒相对误差：**$7.1265 \times 10^{-13} < 10^{-11}$** (达到机器精度极限)
- $L^2$ 质量守恒通过率：**100.00%**
- 孤子波形包络守恒残差：**$4.3846 \times 10^{-8} < 10^{-4}$**
- 全复数精确解析解残差：**$5.5959 \times 10^{-8}$**
- 浅缓冲区边界溢出泄漏率：**$4.0362 \times 10^{-9} < 10^{-6}$**

## 3. 结论与工程指导意义
亮孤子解的存在证明了在非线性排队聚集与频域发包离散之间存在完美的平衡态，使微秒级发包脉冲在通过浅缓冲区网络时保持结构致密性，避免了队列弥散导致的虚假空仓与延迟抖动。
