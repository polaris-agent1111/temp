# 任务 0471 理论审计报告：分布式异步交替方向乘子法 (ADMM) 拥塞控制一致性

## 1. 理论背景与数学推导
在跨柜分布式传输场景中，不同节点或 6 个不同传输阶段（`question/1..6`）之间由于网络拓扑不对称、时延抖动和 CPU 调度漂移，无法保持严格的时钟同步。
若采用传统的同步拥塞协同算法，系统性能将受到最慢节点（Straggler）的拖累。

### 全局一致性优化建模
构建带有浅缓冲区物理边界约束的分布式一致性问题：
$$\min_{x_1, \dots, x_N, z} \sum_{i=1}^N f_i(x_i) + g(z)$$
$$\text{subject to } x_i - z = 0, \quad i = 1, \dots, N$$
其中 $x_i$ 为阶段 $i$ 的局部发送速率，$z$ 为交换机浅缓冲区全局一致性整定速率，$g(z) = \mathcal{I}_{[0, C_{\text{cap}}]}(z)$ 为容量可行域指示函数。

### 异步增广拉格朗日乘子更新 (Asynchronous ADMM)
增广拉格朗日函数为：
$$L_\rho(x, z, u) = \sum_{i=1}^N \left( f_i(x_i) + u_i(x_i - z) + \frac{\rho}{2} (x_i - z)^2 \right) + g(z)$$
在异步执行范式下，每轮随机激活的活跃子集 $\mathcal{S}_k \subset \{1, \dots, N\}$ 独立并行求解局部凸二次规划：
$$x_i^{k+1} = \arg\min_{x_i} \left\{ f_i(x_i) + u_i^k(x_i - z^k) + \frac{\rho}{2} (x_i - z^k)^2 \right\}$$
全局协调器根据最新到达的聚合信息进行单纯形有界投影：
$$z^{k+1} = \Pi_{[0, C_{\text{cap}}]} \left( \frac{1}{N} \sum_{i=1}^N \left( x_i^{k+1} + \frac{1}{\rho} u_i^k \right) \right)$$
对偶乘子仅对活跃节点异步步进：
$$u_i^{k+1} = u_i^k + \rho (x_i^{k+1} - z^{k+1}), \quad \forall i \in \mathcal{S}_k$$
