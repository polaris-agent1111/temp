## 1. 方法（脚本 `zcode/scripts/acf0313_score_series.py`，numpy/scipy 自实现）

1. **ACF**：r_k = c_k/c_0，95% Bartlett 带 ±(1.96/√n)·√(1+2Σ_{i<k} r_i²)；
2. **PACF**：Durbin-Levinson 递推，95% 带 ±1.96/√n；
3. **Ljung-Box** Q(K)，K = ⌊n/4⌋ = 3，χ²_K；
4. **AR(p) 定阶**：条件最小二乘 AIC/BIC + **留一交叉验证（LOO-CV）仲裁**
   （n≤15 时 AIC/BIC 的 ln(n) 惩罚不足，必须 CV 防过拟合）；
5. **随机游走检验**：ADF（手工 OLS，MacKinnon 小样本近似临界值，如实标注）+
   增量白噪声检验（RW 零假设下 Δy ~ WN）；
6. **MC 校准**：20 万次白噪声重放给出 P(max|r_k|) 95% 分位；成对 bootstrap（5 万次）
   给 r_k 95% CI。

## 2. 结果：断点后主口径（n=13，mean=140.800，std=7.513）

| lag | ACF | Bartlett 95% 带 | PACF | ±带 |
|-----|------|------|------|------|
| 1 | −0.194 | ±0.544 | −0.194 | ±0.544 |
| 2 | −0.031 | ±0.564 | −0.071 | ±0.544 |
| 3 | −0.355 | ±0.564 | −0.392 | ±0.544 |

- 所有 ACF/PACF 系数均在 95% 带内；Ljung-Box Q(3) = 3.087，p = 0.378 → **不拒绝白噪声**；
- MC 校准：观测 max|r_k| = 0.355 < 临界 0.557；bootstrap 95% CI 全部含 0
  （r₁ [−0.529, +0.365]、r₂ [−0.505, +0.377]、r₃ [−0.479, +0.369]）；
- 定阶：AIC/BIC 选 AR(4) 为**小样本过拟合伪影**（n_eff=9、参数 5）；
  LOO-CV 仲裁 **AR(0)**（预测 MSE：66.9 < 80.4 < 141.6 < 309.1 < 406.0，p=0→4）。

## 3. 结果：全序列口径（n=15）与随机游走检验

- 全序列 r₁ = +0.478，Bartlett 带 ±0.506 未过带；Ljung-Box p=0.231；MC 临界 0.531 >
  观测 0.478。LOO-CV 选 AR(2)（MSE 410.7 < AR(0) 1990.5），但该优势完全来自 v1
  断点的区域编码（AR(1) 训练 MSE 爆炸至 2.3e6），**不是平稳过程记忆**；
- ADF(lag=1) t = −13.07 的「强拒绝」是断点污染（Perron 效应：断点使单位根检验过度
  拒绝），不作为平稳性证据；
- 增量检验（RW 零假设）：断点后 Ljung-Box Q = 5.582，p = 0.134 → **增量不可拒绝
  白噪声，随机游走假设未被拒绝**；ADF 断点后 lag=0 边际拒绝（t=−3.44）、lag=1 不能
  拒绝（t=−2.10），结论随 lag 翻转 → n=13 下「固定均值白噪声」与「带漂移随机游走」
  不可判别，两者运营含义等价。

## 4. 审计结论（按证据强度分级）

1. **【强】断点后出分序列无显著自相关**：95% 置信门槛下无任何 lag 显著（Bartlett、
   bootstrap、Ljung-Box、MC 四法一致）。任务目标「自相关系数置信度 ≥ 95%」的如实
   回答：**没有自相关系数通过 95% 显著性门，AR 阶数 = AR(0)**。
2. **【强】上一发官方分对下一发没有可利用的预测信息**（r₁ = −0.19，CI 含 0）。
   自适应逐发策略只能依据配置先验与本地校准选点，不能依据官方分序列外推；
   与 0105「共同噪声 + 加性 δ̂」信道模型一致。
3. **【口径警示】跨 regime 合并出分序列做时序建模必须先断点检测**：v1 断点
   （p = 9.4e-14）使 AIC/BIC/ADF 全部失真。
4. **【低功效区】所有「不拒绝」应读作「未能检出」**（n=13–15，检出功效上限约
   |r|≈0.5），而非「证明不存在」。
5. 榜单背景（描述性，`runs/leaderboard/ledger.csv`）：Catnet 126.9647 期间恒定，
   光明未来 153.633→132.5727——对手序列同样非平稳，进一步削弱按历史出分轨迹
   预测对手的可能性。
