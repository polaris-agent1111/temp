## 一、问题设定

官方测评流程第⑦步「重复多次取平均，更新排行榜」+ 公平条款「排行榜 top 提交将统一复测，防止针对特定随机种子的过拟合」。任务问题：**复测抽样几轮，才能以 99% 功效识别真实优劣？**

形式化：两支队伍的真均值 m₁ < m₂（m₁ 更快），差 Δ=m₂−m₁；每轮单发成绩噪声 σ_d。复测 n 轮后比较均值，问 n 多大时以功效 1−β 检出 Δ。

## 四、逆问题：固定轮数下的最小可分辨差（MDE）

$$\text{MDE}(n) = (z_{1-\alpha/2}+z_{1-\beta})\,\sigma\sqrt{2/n}$$

| n（每方） | MDE@80% | MDE@90% | MDE@99% | MDE@99% ÷ 榜头全宽 15.6s |
|---:|---:|---:|---:|---:|
| 1 | 27.8 | 32.2 | 42.6 | 2.72× |
| 2 | 19.7 | 22.8 | 30.1 | 1.93× |
| 3 | 16.1 | 18.6 | 24.6 | 1.57× |
| 5 | 12.4 | 14.4 | 19.0 | 1.22× |
| 8 | 9.8 | 11.4 | 15.0 | 0.96× |
| 10 | 8.8 | 10.2 | 13.5 | 0.86× |
| 20 | 6.2 | 7.2 | 9.5 | 0.61× |

**判读**：n=3（官方最可能的复测轮数之一）时 99% 功效 MDE=24.6s > top-10 全宽 15.6s；要到 n≈8 才勉强覆盖全宽、n≈50 才能分辨头部集群内部（2~5s）的差距。**官方「重复多次取平均」在现实轮数下的统计功能是压方差、防单发抽签，而不是分辨头部名次。**

## 六、敏感性

### 6.1 噪声与语义（基准：榜首 vs Catnet，Δ=2.8036s，n@99%）

| 情景 | 等效 σ(s) | n@99% |
|---|---:|---:|
| σ_d 后验 = 7.02 | 7.02 | 230 |
| σ_d CI 下界 = 3.8 | 3.80 | 68 |
| σ_d CI 上界 = 12.4 | 12.40 | 719 |
| 官方内部 k=3 次取平均（σ/√3） | 4.05 | 77 |
| 官方内部 k=5 次取平均（σ/√5） | 3.14 | 46 |
| 本地测试床单发（s=11.35） | 11.35 | 602 |

**重要**：若官方单条榜单成绩本身已是 k 次内部重复的均值（σ_eff=σ_d/√k），所需轮数按 k² 缩减——k=5 时 46 轮仍是剩余赛程不可达的量级。**σ_d 的 CI 端点只把 n 在 68~719 之间移动，不改变「不可实现」的定性结论。**

### 6.2 设计结构（Δ=2.8036s，99% 功效）

| 设计 | n |
|---|---:|
| 双样本（σ_d=7.02） | 230 |
| 配对同日复测 ρ=0.0（σ_Δ=9.93） | 230 |
| 配对同日复测 ρ=0.5（σ_Δ=7.02） | 115 |
| 配对同日复测 ρ=0.8（σ_Δ=4.44） | 46 |
| α=0.005（top-10 两两 45 组 Bonferroni） | 330 |
| Mann-Whitney（ARE=3/π≈0.955） | 241 |
| 符号检验（ARE=2/π≈0.637） | 362 |

配对设计（同日、同窗口交错）最多省一半（ρ=0.8 时）；Bonferroni 与非参数惩罚都是 +30~60% 量级。**没有任何现实设计把 top-5 内的 99% 功效分辨拉进剩余赛程。**

## 七、对决策的含义

1. **「最佳样本量」的直接回答**：以 99% 功效识别 top-5 级真实优劣所需的 n（34~9452 轮/方）在赛程内不可实现；现实复测轮数（n≤10）下，官方只能分辨 ≥13.5s 的差距。**榜头排序在统计上不可证明，只能按期望名次优化。**
2. **我方「统计可证明登顶」的门槛**：对榜首保持 ≥13.35s（1.9σ_d）官方口径差距 → 同日语义（官方≈真本地+2.5s）折算真本地 **X ≤ 101.2s**——与 0084 独立推出的「P≥95% 破榜首需 X≤101.2s」完全一致（两个不同的统计框架收敛到同一数字，互为验证）。
3. **合规策略推论**：
   - 瞄准「分布左移」而非「纪录抽签」（与 0084 §七、AGENTS.md 反过拟合纪律一致）；
   - 我方内部选型的统计口径同理：本地 s≈11.35s 下，n=3 的 99% 功效 MDE=39.8s、n=10 也有 21.8s——**本地 <10s 级的配置差异在合规样本量下同样不可分辨**，这正是 AGENTS.md 要求 ±1 邻域稳定 + n≥3 起步的统计根源；配置选型应优先「机制证据」（如 0085 的突发惩罚定律）而非小差值排名。
4. **复测方案设计红线（若 Lead 有机会影响或预判官方复测）**：n 必须预先定死。「复测到显著为止」的自适应停机在 H₀ 为真时把假阳性率从 5% 膨胀到 20%+（可选停止效应）；同样，我方自己不得用「多次投同配置抽低分」制造显著假象（红线 4 + min-of-N 纪律）。

## 八、结论

1. 双样本等 n 设计：top-5 名次差 0.44~5.38s 需 34~9452 轮/方（99% 功效、α=0.05）；配对设计最好省一半，Bonferroni/非参数再加 30~60%。
2. MDE 逆问题：n=3 → 24.6s、n=10 → 13.5s；现实复测只能分辨 ≥13.5s 级差距，top-10 全宽 15.6s 直到 n≈8 才可覆盖。
3. 蒙特卡洛验证公式表偏差 <0.15pp；σ_d CI 与「官方内部取平均」语义只移动 n 数量、不翻转定性结论。
4. 统计可证明登顶需官方口径差距 ≥13.35s → 真本地 X≤101.2s（与 0084 收敛）；否则按期望名次优化（分布左移）。
5. 复测 n 必须预先固定，任何序贯「做到显著为止」都是假阳性放大器。

## 九、风险与未决

- σ_d 后验来自 10 条官方出分（两战役），CI 宽（3.8~12.4）；官方每新增一批同构复测对，本表应重算（脚本参数化）。
- 「官方内部 k 次取平均」的 k 未知：本审计按 k∈{1,3,5} 敏感性覆盖；若官方公开口径（如每条成绩=3 次平均），n 表按 k² 缩减。
- 检验假设正态单发噪声；0085 的重尾突发（load-* 污染样本）意味着 σ_d 的重尾成分会让非参设计的优势大于 ARE 估计，n 表是下界口径。
- 本审计不涉及任何提交动作；额度与复测策略由 Lead 决定。
