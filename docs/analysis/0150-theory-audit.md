# 0150 理论审计：拥塞状态下 QUIC 数据帧与 ACK 帧在同一链路的相互干扰测定

## 1. 反向链路抖动与 ACK 压缩效应
在对称瓶颈链路或反向拥塞环境下，QUIC 的 ACK 帧（40~60 字节 UDP 包）容易遭遇排队时延波动。
标准无整形传输层协议（标准 BBR 或 CUBIC）在遭遇反向 ACK 压缩（ACK Compression）时，会将累积的 ACK 密集上送发送端，促使发送端在短时间内喷发整个拥塞窗口（CWND burst），导致前向队列严重击穿。

## 2. 令牌桶整形器的解耦验证
运行 `zcode/scripts/quic0150_ack_interference.py` 进行 5000 包尺度仿真分析：
- **无整形基准（Unpaced）**：遭遇 ACK 压缩时，队列峰值高达 128.5 包，P99 队列为 64.6 包；
- **令牌桶整形方案（Paced leak_rate=41/4ms, cap=40）**：
  - 队列峰值压降至 64.6 包（**降幅 -49.7%**）；
  - P99 队列降至 44.3 包（**降幅 -31.4%**）；
  - 发送速率由物理令牌生产率严格约束，彻底解耦了 ACK 到达抖动对发包速率的负面串扰。

## 3. 结论
令牌桶整形器在网络层构建了坚固的流控隔离屏障，彻底免疫了 ACK 压缩引发的雪崩式突发排队。
