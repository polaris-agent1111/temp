- `origin`/`precise` 族样本少（各 10）且多为早期探索场，中位 154.8/146.6 s 不能作为模块优劣判定。

## 9. 理论综合：利用率天花板的三层分解

对「为什么全场利用率卡在 ~42–47% 而不是 50%+」给出三层分解（与既有审计对齐）：

1. **公平份额层（结构性，约 −8 pp）**：背景目标接收速率 100 Mbps 与瓶颈同量级，重尾 websearch 流长
   使背景在 ≥95% 时间片上至少占一席。我方稳态可期望份额 ≈ 50%，实测 6.bin 中位 36.2% + 慢启动/恢复
   空窗 ≈ 与 50% 公平份额的差距来自第二、三层。
2. **自排队与定时器层（约 −4 pp）**：96 Mbps 档 pacing 的 M/D/1 自排队底噪 E[D_q]≈1.25 ms/RTT（ρ_q=0.96，
   E[N_q]=11.52 包）；官方容器定时器唤醒迟滞 Δt≈0.8–1.2 ms 使 4000 µs 泄放周期拉长至 4.6–5.2 ms
   （有效速率 77–87% 折），长文件段因此被迫保守定价。
3. **碰撞恢复层（约 −2–4 pp，重尾驱动）**：30 MB 巨流碰撞事件（0051 一阶代价模型：每条 2.24 s 饥饿
   + 96 ms 满队列恢复 + κ×RTT 反应停顿）以 λ_g·ρ·T_win 的期望频次打断稳态，方差由此而来。

三层合计给出会话利用率期望 ≈ 42–46%，与最快 8 场的 43.7–46.0% 和 Catnet 的 42.0% 完全同量级；
EVT 下界 47.3% 对应「碰撞层被幸运相位压缩到下四分位」的极端实现。**榜首差距的本质是方差管理，
不是天花板突破。**

## 10. 结论与可执行杠杆（按预期收益排序）

1. **唯一主杠杆 = 5/6.bin 稳态利用率**（r=−0.807/−0.599，字节占比 76.2%）：目标把 6.bin 中位从 36.2%
   推到 40%+（≈ Catnet 42.0% 会话锚点）。手段已验证：非对称构型（1–4.bin 前猛 40 包/4ms、5–6.bin
   96 Mbps 级平滑或 36–38 包/4ms 安全区）。
2. **1–2.bin 不再投入**：|r|<0.2，启动税结构性存在；激进 1–2.bin 只会增加碰撞面。
3. **模块选型维持 leak_bucket 为主线**：长文件段利用率优势 +3–3.7 pp 有 N=210 vs N=88 的池化证据。
4. **池化口径**：H3 证明无时段漂移，全部历史 valid 场次可并入同一统计池；按均值/中位数选型、n≥8–10
   报告 CI，遵守 `docs/analysis/overfitting-and-selection.md` 门槛。
5. **合规核验通过**：全场 0 样本触及 90% validity 边界（H2 最后一行全 0），无 min-of-N 提分痕迹；
   本报告全部结论基于均值/分位，不使用单场最小值作预期。
