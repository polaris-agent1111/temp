# 复现说明（题目一：六载穿柜）

本文档给出从零复现本团队提交配置与评测结果的完整步骤。所有操作在竞赛云主机桌面（`/home/openlab/Desktop/`）完成；命令与目录名均勿改动，否则无法正常运行。

> ⚠ 提交前先读赛题须知：**不要点击「提交试卷按钮」**（会销毁云主机）。本文的「提交」均指 `local_send_client` 上传配置。

## 1. 提交目录结构

```
question/
├── 1/
│   └── pacer.txt        ← 第 1 次下载前生效；缺失则用平台默认（origin 全默认值）
├── 2/
│   └── pacer.txt        ← 第 2 次下载前生效；缺失则沿用上一份配置
├── 3/                   ← 目录 3–6 同理；不需要换配置的目录留空即可
├── 4/
├── 5/
└── 6/
```

规则要点：

- 目录名不带前导零（`1`…`6`）；每个目录**至多**放一个普通文件 `pacer.txt`，不得有子目录或其他文件。
- `pacer.txt` 为 UTF-8 编码、三行、行首行尾无空白，格式固定：

```
[timestamp:N]
pacer_mode:origin
pacer_config:burst_tokens=10,max_pacing_rate=1000
```

- 第 1 行 `[timestamp:N]` 的 N **必须等于所在目录名**（目录 2 必须是 `[timestamp:2]`）。
- 第 2 行 `pacer_mode` 只能取五值之一：`token_bucket` / `coarse_grained_rate_based` / `precise_rate_based` / `origin` / `leak_bucket`。
- 第 3 行参数用英文逗号连接；留空（`pacer_config:` 后无内容）= 用该模块默认值。参数大小约束（如 `burst ≥ tokens`、`bucket_cap ≥ leak_rate`）必须满足，否则配置无效。
- 配置在下载间**不重置**：目录 N 无 pacer.txt 时沿用上一份已生效配置。

## 2. 格式检查

```bash
cd /home/openlab/Desktop
./format_check_client              # 终端输出全部不符合项
./format_check_client ./check.log  # 可选：同时把日志写到 ./check.log（覆盖写，上级目录自动创建）
```

检查通过（无不符合项）后才进行评测或提交。**任何一次改过 pacer.txt 都要重跑本步。**

## 3. 本地评测

```bash
cd /home/openlab/Desktop
sudo ./competition_question1 \
  --output-dir ./results \
  --result-json ./results/evaluation_results.json \
  --format-log-dir ./results/logs
```

- 程序自动读取 `question/` 下 6 份配置并依次仿真 6 次下载；配置写入时间不计入耗时。
- 产物：`./results/` 内的过程日志（`*.log`）、结果文本（`*.txt`）、汇总 `evaluation_results.json`（六文件耗时与总时间的机器可读来源），以及 `./results/logs/` 格式检查日志。
- 单次评测约 4–5 分钟；六文件必须全部成功，否则该次无成绩。
- 六次耗时之和 = 本题用时；与基线对照：默认 origin 配置实测 167.663 s。

## 4. 提交（由 Lead 执行）

```bash
cd /home/openlab/Desktop
./local_send_client --token <团队GUID>     # <团队GUID> 为 16 位值，见团队后台，绝不写入本文档
```

- 发送前程序会先做一次格式检查，通过才会上传；**无论提交成败，只要连上服务端并识别到团队就消耗当日提交次数**。
- 每日提交限额见竞赛细则（当前为 5 次/天）；超限继续提交可能被封禁。故务必先 `./format_check_client` 再提交。
- 每次成功提交后桌面会留下 `日期时间.log` 与 `日期时间.tar.gz`（该次提交的快照），建议留存回溯。

## 6. 常见失败原因速查

| 症状 | 原因 | 处理 |
|---|---|---|
| 格式检查不过 | timestamp 与目录号不符 / 参数名拼错 / burst<tokens / bucket_cap<leak_rate / 行首尾有空白 | 按提示逐项改正，重跑 §2 |
| 评测中途下载失败 | 配置导致传输异常（如限速过激） | 回退到上一版配置，单因子排查 |
| 评测结果异常慢 | 速率单位写错（B/s 与 bit/s 混淆） | 核对 max_pacing_rate：12.5 MB/s = 12500000 B/s |
| 提交消耗次数但未上榜 | 未先跑格式检查 / 已达当日限额 | 提交前必过 §2；关注剩余次数 |
