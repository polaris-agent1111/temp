## 4. 额度安全规则

1. **每日硬上限 5 发**，额度不结转；当天用满即停（今日已 5/5）。
2. **跨日不连发**：单日提交集中在 08:00–22:00，不在 23:50–00:10 边界突击（额度归属与出分归属跨日易混乱）。
3. **格式检查失败也消耗额度**（连上服务端即计数）→ 每次提交前双检：本地 `python tools/validate_pacer.py <question>` exit 0 → 云主机 `./format_check_client` 通过。
4. **同配置 60 min 内不重复投**（出分延迟 10–60 min，见 0010）；重复投必须有明确假设（如校准/方差估计）。
5. **每笔记账**：提交即在本表 §1 追加一行（Lead 或 zcode 下轮 0010 自动补官方成绩），状态=待出分/已出分/失败。
6. 探索与打榜配比按 §3 执行；**任何一发投出前自问：这发要回答什么问题？**答不出→不投。
