## 选用说明（诚实性）

1. **复核/答辩复测请用 4 ms 两个配置之一**：`leak-36-40-4000` 有官方实测背书（133.086），`leak-24-50-4000` 本地最好但官方未投。
2. `leak9-rate9`/`leak8-rate8` 是 **1 ms 陷阱样本**：本地快（~124–126）但官方 244–246——保留它们是为了让复核方能复现「定时器粒度」发现本身（`docs/knowledge/timer-granularity.md`），**不是推荐配置**。
3. 本地噪声 sd≈6.5–8 s：n<3 的点估计（含 119.59 单次最好）不作排序依据；`24/50/4000` 官方值待 11/06 探测后回填本表。
4. 全部配置满足 `bucket_cap ≥ leak_rate`、`leak_interval_us ≥ 4000`（推荐档）等约束。
