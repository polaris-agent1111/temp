## 选用说明（诚实性）

1. leak 两族本地最优但**官方已实测 ~2× 劣化**，保留在此作为「本地成绩证据」与「跨环境差异样本」，不作为官方推荐配置。
2. `tb-100-200-20` 本地比 leak 慢 ~10 s，但该差异在统计上不显著（噪声内），且具备官方环境鲁棒性设计（标称余量 ≥4× + 有旁路，见 0006 §2.4）。
3. n<3 的一切点估计（含 114.64 s 单次最快）不列为候选——方差惩罚选型，不追单点。
