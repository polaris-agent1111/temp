# 每小时工作报告（hourly/）

本目录用于**每小时**记录一轮：上一小时做了什么、关键数据、项目当前进度、下一步。
由 Lead（DSH Agent）维护，每个整点后写一份。

## 约定

- 文件名：`YYYY-MM-DD_HH00.md`，`HH00` 表示该报告覆盖的起始整点。例如
  `2026-11-05_1500.md` 覆盖 **15:00–16:00**。
- 每份报告固定五节：
  1. **本小时做了什么**（按时间线，只写事实 + 结果）
  2. **关键数据**（本地评测 / 官方成绩 / 榜单变化，带数字）
  3. **当前进度**（排名、提交额度、处于哪个阶段）
  4. **下一步**（可执行清单，最多 5 条）
  5. **需要用户手动做的事**（通常为「无」）
- `INDEX.md` 始终保存**最新一小时的进度快照**（排名表 + 关键指标），看它即可知道现在什么状况。
- 报告只写结论和证据，不写过程废话；数字必须能在 `runs/results.jsonl`、
  `runs/submissions.jsonl`、`intel/raw/leaderboard_*.json` 里对上。
